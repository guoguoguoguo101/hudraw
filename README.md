# 灵狐绘符 · 固定站位自由绘符战斗

在现有 TypeScript / PixiJS / Vite 项目上改造。狐狸、三类敌人、背景、图集、剪纸装饰与环境动效保留，鬼王复用赤面鬼美术。

## 运行

本机已含依赖及正式构建。需要 Node.js 22.12+。

```powershell
cd D:\ui\linghu-draw
npm run preview:lan
```

同一 VirtualNet 网络：http://10.202.19.61:4173/ 。同一局域网：http://192.168.1.12:4173/ 。本机：http://127.0.0.1:4173/ 。IP可能变化，保持服务运行。这些是局域网链接。

开发模式：`npm run dev`，访问 http://127.0.0.1:5173/ 。重新构建：`npm run build` 。测试：`npm test` 。完整关卡模拟：`npx tsx scripts/simulate-combat.ts` 。平台边界检查：`npm run check:platform` 。新电脑先运行 `npm ci`。

## 怎么玩

狐狸固定站在中央。观察敌人的位置与蓄力线，在战斗区按住并自由画符。进入40%速度符境；手指、笔迹、预识别与UI保持真实速度。最多绘制4秒现实时间，松手或超时自动释放。

符纸每5秒战斗时间恢复一张，上限3张，初始2张。有效施法消耗一张；短误触不消耗。有效但不成形的涂鸦只触发8基础伤害的弱散墨符。暂停与升级三选一会完全冻结战斗及符境，不耗绘制时间。

普通试炼目标180秒，初始100生命。90秒入门模式减轻受击伤害，鬼王在60秒出现；普通模式90秒出现。胜利需要达到目标时间并击败鬼王；到时鬼王未死则进入决胜，不再普通刷怪。鬼王召唤仍需处理。修行加成只作用于已有局外等级，新存档初始100生命。

### 六种符术

- 一字斩：直线，起点到终点为方向；60基础伤害，宽70，射程500，穿透3敌。
- 圆形护阵：圆或椭圆；以狐狸为中心半径200、30范围伤害，并获得20护盾，持续4秒。
- 三角破甲：三角形；沿突出顶点方向索敌，110单体基础伤害，25%破甲3秒，可打断精英与鬼王蓄力。等边三角的近似等距尖角以绘制顺序稳定选取。
- 五角星阵：自交五角星或星形外轮廓；五个角决定星芒方向，每道32基础伤害，同一目标最多命中两次。
- 折线雷符：Z形；指定扇区优先索敌，首跳45伤害，最多4敌，逐跳衰减15%，后续跳跃范围280。
- 螺旋旋风：由内向外或反向绕画螺旋；保留旋向，在威胁方向生成半径150旋风，持续3秒、每0.5秒12伤害，吸附普通敌人，最多同时2个。

质量由形状结构、模板匹配或几何特征计算；基础伤害按80%–100%质量系数修正。法宝与修行可继续强化。复杂度不按路径长度升级。

## AI、鬼王与波次

墨团妖40HP / 35速度 / 10接触伤害；纸鸦30HP / 75速度 / 8接触伤害；赤面鬼240HP / 22速度 / 20伤害、普通击退降低30%。敌人具有出现、接近、预告、攻击、恢复、受击与死亡状态；纸鸦绕行并在蓄势后短冲，敌人恢复期间会后退。轻量分离减少堆叠。狐狸受击后1.2秒无敌。

普通敌人上限35，赤面鬼上限3，鬼王上限1。威胁预算每30秒阶梯增长：0.35 / 0.55 / 0.75 / 0.95 / 1.15 / 1.35每秒；墨团妖、纸鸦、赤面鬼权重1 / 2 / 6。达到目标时间后停止普通刷怪。

鬼王1800HP，前三阶段：100%–70%有40%减伤护甲，三角直接破甲，其他攻击逐渐磨掉；70%–35%召唤墨团妖与纸鸦；35%以下血月蓄力6秒。破甲可打断蓄力，蓄力期间累积280实际伤害也可打断，护阵减伤可用于防御。预告、执行与恢复分离，战斗不要求移动闪避。所有主要参数在 `src/gameplay/config.ts`。

## 局内法宝与局外修行

击杀获得灵气并自动吸收。升级暂停战斗，三选一选择法宝；重复选择可强化相应参数。

- 朱砂灵笔：增加35%伤害并追加红色第二层笔迹。
- 镇妖古印：闭合符留下持续阵纹与周期伤害。
- 照妖古镜：方向攻击追加横向镜像；护阵额外25%伤害。
- 聚风葫芦：吸附/击退强化60%，旋风半径增加25%。
- 引雷铜铃：雷符附加2秒感电，每秒12伤害，并显示感电纹。
- 灵狐尾羽：每3次有效施法追加45伤害追踪狐火。

同一个Modifier接口同时产生逻辑参数与视觉字段，不通过复制SVG图层多算伤害。示范组合截图包含星+灵笔、星+古印、斩+古镜、旋风+葫芦、雷+铜铃。

每局结算积累灵玉，开始页显示余额；100灵玉提升一阶修行，上限10阶，每阶+4生命和3%伤害。存于浏览器本地，不同同事设备各自保存进度。

## 实现结构

- `src/input/recognizer.ts`：GestureRecognizer，去噪、平滑、64点重采样、归一化、旋转与逆向匹配、交点/闭合/半径特征、质量与散墨降级；多笔扩展入口保留。
- `src/input/controller.ts`：单指采样、2秒超时、实时预识别；`coordinates.ts` 统一CSS像素到720×1280世界坐标。
- `src/gameplay/clock.ts`：CombatClock固定1/60秒模拟，真实时间与战斗时间独立，敌人位置使用插值渲染维持完整画面帧率；SpellChargeSystem仅用战斗时间。
- `src/gameplay/spells.ts`：TalismanSpellFactory与六符伤害结算；命中集合、多次命中上限、周期伤害均在逻辑层。
- `src/gameplay/target.ts`：SkillTargetResolver，射线/扇区/连锁及接近度、蓄力、精英/鬼王权重。
- `src/gameplay/ai.ts`：EnemyAI与BossController。
- `src/gameplay/director.ts`：SpawnDirector，可注入关卡配置，预算、刷新时点与上限。
- `src/gameplay/modifiers.ts`：六件法宝与通用Modifier。
- `src/rendering/talisman.ts`：ProceduralTalismanRenderer，把玩家原始比例、倾角、顶点、折点、旋向演化为红金符形。
- `src/rendering/rigs.ts` / `environment.ts`：保留既有白狐、敌人和环境美术动画。

每次符术最多缓存64采样点和20组纸雕装饰；同时最多12个符术视觉，192个复用粒子、6个额外狐火、24个灵气吸收光点。符形在施法时构建一次，逐帧只改变变换、透明度与少量预告线，不逐帧解析SVG；所有PNG/图集仍只在加载时读取。

## 检查与限制

30组测试通过，覆盖六符标准/逆向/旋转/缩放/抖动、自交与外轮廓星、短笔与涂鸦、2秒→0.4战斗秒、30/60/120FPS、充能、单指/超时、375/390/430画幅坐标、各符伤害与去重、感电、无敌与死亡清理、AI、Boss三阶段、六件法宝、升级与胜负。

完整关卡模拟使用普通符术、正常符纸充能与三选一法宝，验证180秒通关。实际浏览器检查并截图保存六符、符境、鬼王、升级卡片与五种组合；还实际鼠标拖动验证一字斩扣纸，点击法宝验证恢复战斗。详见 `QA-REPORT.md` 与 `screenshots/combat-upgrade/`。
