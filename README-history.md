# 灵狐画符

可玩的竖屏 2D 山海剪纸小游戏。TypeScript + PixiJS 8 + Vite，720×1280 逻辑画布。独立目录，不覆盖《山海·灵狐》动画项目。

## 运行

需要 Node.js 22.12+。本机交付已含依赖与 `dist` 成品。

```powershell
cd D:\ui\linghu-draw
npm run dev
```

开发试玩：<http://127.0.0.1:5173/>。美术预览：<http://127.0.0.1:5173/art-preview.html>。

生产版试玩：`npm run preview`，打开 <http://127.0.0.1:4173/>。

在新电脑首次运行：`npm ci`。重新生成美术：`npm run art`。构建：`npm run build`。测试：`npm test`。平台兼容性源码检查：`npm run check:platform`。

## 玩法

鼠标拖动或单指在中央战斗区画符。直线沿落笔方向释放剑气；圆形对附近妖怪造成伤害并击退；Z 字雷咒连锁最多五个目标。允许不规则圆、斜线、反向画法和合理笔迹偏差，短误触与普通乱画不会触发。施法有短暂共用间隔。

狐狸固定在中央，妖怪从四边靠近。3 点生命，受击有短暂无敌。坚持 60 秒获胜，生命归零失败。0–15 秒墨团妖；15 秒加入纸鸦；30 秒加入赤面鬼；45 秒后更密集。教学模式不扣生命。

右上角暂停；Escape 暂停/继续；D 显示采样点、归一化轨迹与识别反馈；M 切换音效。开始页和暂停页可切换精致/轻盈画质，最佳分数保存在浏览器本地。

## 美术与动画

`scripts/build-art.mjs` 生成 33 个独立 SVG（含完整灵狐预览）、透明 PNG、固定图集和竖屏山水。`art.config.json` 配置统一色板及各素材缩放。素材均有唯一名字、320×320 固定画布及中心锚点；场景为 720×1280。`public/art/manifest.json` 记录尺寸、锚点、描述与参数。

生成流程：SVG 源文件 → 独立预览 → PNG 纹理 → `atlas.png / atlas.json` → 游戏启动加载。画面运行期间不生成 SVG，也不反复上传纹理。`public/art-preview.html` 可独立查看所有重要素材。

狐狸按 head、torso、四足、三尾、左右耳朵、眼睛、scarf、bell 拆层。父子关系为 root → body → head → ears/eyes。施法有压低重心、抬前爪、恢复和三尾跟随；受击后仰闪烁；胜利跳跃展开九尾；失败消散为剪纸烟云。纸鸦双翼独立扇动。

`src/animation/timeline.ts` 提供 easing、delay、duration、sequence、parallel、repeat 与 cancellation。`motion.ts` 集中角色动作参数。粒子、碎纸、技能临时对象和敌人视图采用对象池；伤害判定与视觉动画分离。逻辑固定 1/60 秒更新，渲染独立更新。

## 代码结构

| 目录 | 职责 |
|---|---|
| src/core | 世界参数、状态类型、开发视觉检查 |
| src/gameplay | 敌人、伤害、分数、技能、生成与胜负 |
| src/input | Pointer 采样、平滑、归一化、手势识别 |
| src/rendering | Pixi 场景、分层角色、技能和对象池 |
| src/animation | 时间轴与动作参数 |
| scripts + public/art | 程序化 SVG、PNG、图集及资产清单 |
| src/ui | 菜单、教学、HUD、暂停、结算 |
| src/audio | WebAudio 合成拨弦、法术、打击音效 |
| src/platform | 输入、资产加载、声音、存储和生命周期接口 |
| tests | 识别、输入管线、战斗、胜负、暂停及时间轴测试 |

### 继续编辑美术

1. 在 `scripts/art-upgrade.mjs` 中修改部件路径或环境层；角色局部原点是画布中心，所有部件为 320×320。
2. 在 `src/rendering/rigs.ts` 调整组装坐标和动作；实际资源名称保持一致可直接替换，不需要改战斗逻辑。
3. 新增环境层时同时更新 `main.ts` 的加载名称及 `environment.ts` 的前后景顺序。
4. 运行 `npm run art` 重新生成 SVG、PNG 和图集，然后 `npm run build` 更新正式版。打开 `art-preview.html` 或游戏检查。

正式预览仍然是 `npm run preview` → http://127.0.0.1:4173/。如浏览器保留了旧画面，按 Ctrl+F5 刷新。不能双击根目录的 `index.html` 启动 TypeScript 项目。


### 背景动效追加

- 红日：0.25% 范围的缓慢呼吸缩放、不到 1 像素的轻微升降与三层淡金轮缘。
- 山谷：远山最多 1.6 像素、河谷与神社最多 0.7 像素的分层视差；战斗石台与判定位置不移动。
- 花枝：从前景中分离到 `environment/branches.svg/png`，轻微随风摆动；岩壁保持静止。
- 旗幡：由运行时 Graphics 重画曲线，下摆随风变形，顶部固定。
- 河流：流动的横向高光；瀑布：下落的亮水丝及脚下细小水纹。使用水道遮罩，亮线不会穿到岩石和石台上。
- 地面阵纹：每次成功施法时短暂亮起，再渐渐收束；在角色与技能层后方。
- 天空纸纹、建筑轮廓和石台主体仍为静态素材，保持纸雕质感与游戏可读性。

所有新增背景运动均由同一个环境时间驱动。暂停时冻结，恢复时连续衔接。实现集中在 `src/rendering/environment.ts`，不修改游戏玩法。
