# 画灵打击反馈增强

2026-10-24。本轮增强画灵已有伤害事件的视听反馈，伤害判定与技能数值沿用现有实现。

- 命中：短促米白接触亮点、沿最近普通笔势展开的朱砂切痕与金色断弧。较大伤害适当加粗，普通攻击维持轻反馈。
- 纸妖：受击后横向压缩感与纵向回弹、轻旋转和短暂浅色闪亮。使用已有受击计时，暂停与对象复用自动沿用原有生命周期。
- 击杀：更大范围的米白/朱砂碎纸、较长消散、断开的冲击环和稍强震动。活动闪光最多 16 组、碎屑最多 96 片。
- 音效：画灵专用 paperHit / paperBreak，以滤波噪声模拟切纸和撕纸，叠加快速下降的三角波提供触感重量；轻击短，击杀尾音更厚。轻微随机音高减少重复感。
- 密集命中：轻击最短间隔 45 毫秒、击杀 75 毫秒、最多六组发声；击杀独立限频。噪声缓存复用，结束断开节点，静音时不创建新声音。其余模式继续原音效。

验证入口：`node scripts/check-hualing-impact.mjs`。通过真实伤害事件截图，使用离线音频渲染确认音效有声、单声峰值不削波、轻重能量有区别、同时 30 次触发合并、静音不新增声音、播放后释放计数。截图、音频样本和验证数据保存至 `screenshots/hualing-impact/`。自动验证不能替代耳机听感和微信真机扬声器验收。

现有画灵浏览器检查覆盖 375/390/430 画幅、连续挥笔、三种绘物、重开及旧模式隔离；本轮已通过。尚未逐项添加画龙、推山、裁纸和四种场景奖励各自的专属释放音色。

## 听感与镜头修订

按用户反馈关闭画灵的画面震动，命中与击杀只保留敌人局部受击动作、切痕与碎屑。命中噪声改低通并大幅降低音量，厚重下坠的三角波改为轻柔短促的正弦木击；击杀尾音缩短。连斩改为较低音区的轻双音，降低音量、拉开音符间隔并缩短尾音。纸音同时最多四组，轻击间隔 75 毫秒、击杀 110 毫秒，减少密集战斗的音效堆积。修订后自动检查命中和击杀的镜头偏移均为零，并检查纸音单次输出峰值低于 0.1；实际听感仍由用户试玩确认。
