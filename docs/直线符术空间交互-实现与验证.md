# 直线符术空间交互 · 实现与验证

2026-10-16，原型版本。设计依据：[方案核对稿](直线符术空间交互-方案核对稿.md)。

## 试玩

主菜单新增「符术交互 · 试验画境」，原「演武画境 · 自由试符」继续保留。

新场地提供留痕一字斩、圆形护阵、九霄雷诏、追踪符箭、三才符。默认无限灵墨、小怪持续刷新、玩家不受伤；可切换有限灵墨。下方保留等级选择、试放、画笔设置，并新增「清空残痕」，方便重试。两种三角各自有独立按钮；选择其名称或试放，会切换后续手画闭合三角的技能。默认三才符。

先画一条线，再穿过淡金残痕画第二条，交点会闪切。三笔分别画三角的三条边，允许边向顶点外延伸；围合后轮廓亮起、轻旋转，内部切割，最后中心爆闪、碎金飞散。无需点选组合。成形后的可见窗口和整段动画统一为约 2.2 秒，爆炸阶段仍保留完整三角，末尾 0.12 秒渐隐，不再提前收缩消失。

「三角折射」是默认开启的可选试验机制，下方有开关。窗口存在时，再画一道触及三角的直线，会以当时正在旋转的三条边为轴，各生成一道镜像斩击。原直线与镜像播放后消失，均不生成残痕；三角本身继续原来的寿命。关闭开关即可比较原玩法。

推荐先用 Lv1 试组合，再比较高等级。交点和三角即使没有敌人也有特效和音效。三线共点目前只按普通两线关系处理，没有专属第三种组合。

- `src/gameplay/interaction-line.ts`：独立实验直线入口；复用旧版已经验证的普通斩击与素材，不修改旧版斩击规则。
- `src/gameplay/line-interaction-config.ts`：原型数值、时序、容量和视觉预算。
- `src/input/line-interaction-geometry.ts`：有限线段相交、角度门槛、裁剪、端点容差、三角面积和敌人碰撞圆与三角区域相交。
- `src/gameplay/line-interactions.ts`：轻量残痕、组合选择、关系去重、寿命、延迟结算、命中去重及独立伤害来源。

- `src/rendering/line-interactions.ts`：批量程序化残痕与组合渲染入口。
- `src/rendering/line-interaction-art.ts`：参考图风格的层叠刀锋、朱砂符纸、金色顶点符、角部卷纹、三角内部裁剪刀光、中心爆炸和确定性碎金；没有新增 PNG 序列帧。
- `src/gameplay/game.ts`、`spells.ts`、`core/types.ts`：实验模式分流、技能限制、手绘三角选择和组合伤害/反馈事件。
- `src/bootstrap.ts`、`input/controller.ts`：入口、重开和退出、未减速时间、随屏幕适配的有效绘图区边界。
- `src/ui/interface.ts`、`practice.ts`、`gameplay/practice-cast.ts`：五符界面、两种三角切换、清空残痕与原练习场共存。
- `src/rendering/view.ts`：独立实验直线渲染池和组合图层。实验场关闭追踪符箭 Lv4 的整体镜头缩放，保证绘制、残痕和组合位置一致；原场地保持原镜头行为。

## 几何、时间和伤害

残痕直接取主斩线段，即有效付费手绘端点距离的 1.5 倍，以手绘中点居中，两端各延伸原长度的 25%。在实际战斗区域内裁剪后，显示与判定共用同一份坐标。最多 8 世界单位的端点容差会显示短连接，不能凭无限延长线形成组合。镜像、追加斩和绘卷不额外产生残痕。

只在新线创建时检测新增组合。每笔最多一个三角，优先较大有效区域；其本次两个交点不再同时追加十字伤害。此前发生的交点伤害保留。每笔最多三个普通交点。两线爆发保留残痕；三线围合立即移除参与的三条残痕，消耗的新线不再追加其他交点组合，无关残痕保留。窗口使用独立几何快照继续完成动画及伤害，不额外扣墨。

残痕和组合使用运行时真实时间，绘制减速和命中停顿不延长寿命；暂停及切后台冻结。原战斗模拟仍使用现有帧预算，不为大卡顿补算多秒敌人动作。残痕单独收到未截断的时间增量，避免卡顿时异常续期。

交点半径 60，命中时刻为触发后 0.05 秒，额外伤害为新线主斩伤害快照的 40%。三角总伤害预算仍为新线主斩伤害快照的 120%，分为 0.70 秒的区域切割（预算的 40%，即主斩的 48%）和 1.60 秒的末段爆炸（预算的 60%，即主斩的 72%）；1.60–2.20 秒为碎金、朱砂符纸和刀芒向外飞散。每敌每段至多一次，使用各段结算时敌人的位置，边缘接触也可命中。区域不会因演出收缩而缩小判定，也不会使用外接圆误伤。飞散粒子为视觉表现，不扩大伤害范围。

伤害经 `Game.damage` 进入原护甲、受击、死亡和伤害事件流程，来源保留为触发的新线施法；不重复乘等级/质量/修行倍率，不递归触发法宝或生成新残痕。原施法对象退出技能列表后，已触发的组合仍可完成；重开、清空、退出场地取消待结算事件。

折射判定取实际斩击的有限线段，接触可见旋转三角的边或进入内部均可触发；延长线穿过不算。每次施法最多选中一个窗口，多个重叠时优先最近生成的窗口。镜像是将整段斩击关于每条边所在直线做几何对称，保持长度后裁剪至场地，并非追踪敌人的弹射。原斩伤害保留，三道镜像各为原斩快照伤害的 50%，宽度为原斩的 65%，在 0.10 秒各结算一次，表现共 0.55 秒；同一敌人可分别被不同镜像命中。镜像不递归触发折射、组合或新残痕，不额外扣墨，也不刷新三角寿命。开关仅影响后续新施法。

## 配置位置

统一调整 `src/gameplay/line-interaction-config.ts`：

- `lifetime=3`、`fade=0.5`、`capacity=6`：残痕寿命、渐隐和上限。
- `traceOpacity=0.16`、`tracePulseOpacity=0.10`、`traceWidth=1.2`：低亮细线残痕，取消持续光晕、白色亮芯与亮端点。
- `minAngle=20°`、`endpointTolerance=8`、`minArea=3000`、`minSide=40`：几何门槛，单位为逻辑世界单位/平方单位。
- `crossDamage=0.4`、`crossRadius=60`、`crossHitAt=0.05`、`crossDuration=0.48`：交点伤害与表现。
- `triangleDamage=1.2`、`triangleHoldUntil=2.2`、`triangleHitAt=1.6`、`triangleDuration=2.2`：窗口停留与动画总长相同，爆炸不提前结束窗口。
- `triangleRotation=π/8`：内层三角刀锋和顶点符纸绕中心轻转，最大22.5°；原始淡金轮廓与伤害范围固定，不额外增加伤害次数。
- `triangleCutAt=0.7`、`triangleCutShare=0.4`：中段范围切割时刻及其占总伤害的份额。
- `refractionDuration=0.55`、`refractionHitAt=0.10`、`refractionDamage=0.5`、`refractionWidthScale=0.65`：临时折射的独立参数；`LineInteractions.refractionEnabled` 为场地开关。
- `triangleParticleMin=18`、`triangleParticleMax=60`、`triangleParticleFullArea=70000`：粒子随面积递增，低画质数量减半；`fragmentBudget=192` 限制同一帧全部组合的飞散粒子总量，低画质减为96。
- `maxCrosses=3`、`maxEffects=24`：每笔交点上限与同时绘制的组合视觉预算。伤害队列独立保留，视觉预算不吞伤害。

暂不开面积增伤。开发预览可按 D 或在暂停页开启手势调试，显示残痕端点、剩余时间、组合计数/判定提示和窗口边界；正式构建不显示该组合调试层。

## 验证

新增 `tests/line-interactions.ts`，18 组专项覆盖有限相交/容差/裁剪、五等级 1.5 倍线段、交点与三角延迟伤害及去重、窗口优先、三线消耗/无关线保留/动画伤害独立完成、区域内外与边缘接触、结算前敌人进出、V 字/共点/仅两交点、过期、绘制减速与暂停、空场反馈、长时间容量与关系清理、五符限制、两种三角、有限灵墨、旧模式隔离与清理。

`tests/triangle-refraction.ts` 增加 8 组专项：三类镜像轴、有限线段接触、旋转与原几何隔离、三边反射与不留痕、可见边框一致性、镜像伤害去重、2.2 秒窗口寿命、关闭/暂停/清空。命令为 `npm run test:triangle-refraction`。浏览器脚本增加约 2 秒时真实第四笔折射、三道镜像无残痕、消失清理和实际点击开关后恢复普通留痕的检查。

已通过项目原有 `npm test` 与 `npm run test:practice`。专项命令为 `npm run test:line-interactions`；浏览器命令为 `npm run test:line-interactions:preview`，默认访问 5175 端口的开发预览（`?qa=1`），可通过 `LINGHU_PREVIEW_URL` 改地址。

浏览器通过真实鼠标拖画检查新增入口、两线交叉、三线围合、两种闭合三角选择、暂停/过期、375×667 / 390×844 / 430×932 三种画幅以及返回旧场地，未出现页面异常或 WebGL 错误。阶段截图和检查记录在 `screenshots/line-interactions/`，包含窗口显形、收缩、爆闪、余光和隔离几何层。

浏览器正式构建、微信小游戏构建均通过。微信测试使用浏览器模拟 wx 环境，检查正式包启动、原模式及新增入口触摸释放三条直线、WebGL 和成长隔离；这不等于微信真机性能验收。

三才符仍沿用此前的无伤害表现原型，没有在本次顺带补完其伤害。普通斩击完整复用旧版行为，实验功能单独封装和分流，没有复制整套游戏或改写旧直线模块。
