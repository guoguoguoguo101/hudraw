# 画灵精英 · 落日妖谷

实现日期：2026-10-24。

## 测试入口

进入画灵的落日妖谷，画符卡片下方有「召唤 · 伞姬」「召唤 · 灯主」「清除精英」。同类重复召唤会替换旧怪，方便反复测试。正常战斗首次约35秒出场，此后间隔55秒，两种交替，有存活精英时不会继续叠加。

## 赤骨伞姬

朱红纸伞、象牙色骨架、破纸裙摆。靠近后收伞蓄力，地面出现冲刺预警。蓄力时划过前方四根伞骨中的任意两根，即可打断冲刺，获得2.5秒破绽，期间伤害提升。未打断则沿预警方向冲刺，每次冲刺只会对狐狸造成一次伤害。

## 吊魂灯主

鹿骨灯架悬挂三盏纸灯。中央灯罩承受三次有效笔击后破开，露出火芯并进入2.5秒破绽。灯主还会释放三盏小魂灯，先预警再追逐狐狸，可以用一笔扫灭多盏；本体死亡会清除所属魂灯。

## 击败奖励

精英死亡留下可描画的残影，沿轮廓补画即可领取一次奖励。伞姬残影激活12秒画符，灯主残影激活12秒雷符。两种精英始终可以直接用画笔伤害，部件交互用于制造更好的输出时机。
