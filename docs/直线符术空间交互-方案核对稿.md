# 直线符术空间交互 · 独立试验场方案核对稿

日期：2026-10-16。状态：核心体验已确认，原型已实现。本文保留设计依据，实际交付及验证见 [实现与验证](直线符术空间交互-实现与验证.md)。

最新试玩修订：按用户补充的四张参考图升级交点与三角视觉；三角改为中段区域切割、末段爆炸和面积递增的飞散粒子，演出延长至 1.2 秒，总伤害维持原预算并分两段结算。下文初始动画分镜作为设计历史，当前时序、伤害拆分和粒子配置以实现文档为准。

## 1. 以本次讨论为准的任务边界

目标是让连续画线从“每笔打完就结束”，变成“出刀 → 留痕 → 利用旧痕再出刀 → 空间组合爆发”，增加落笔位置与顺序的乐趣，保持按住画符、松手释放的操作。

本次聊天中的要求优先于粘贴任务书：

- 主菜单保留现有「演武画境 · 自由试符」，另加「符术交互 · 试验画境」（暂名）。
- 新场地使用独立的新版直线；旧直线、旧试符场、正式战斗继续走原有行为。
- 新场地提供五种符术：新版直线、追踪符箭、三才符、圆形护阵、雷电。两种三角技能同时保留，便于对比验证。
- 组合先做两项：两线相交的交点爆发；三线围合的三角窗口。
- 三线共点的独立组合、直线与圆/雷电的组合均后置，仅预留事件扩展接口。
- 本轮交付文档并讨论；确认后再按文档实现。附件内“直接完整编码”“不加新入口”“改造旧直线”等指令不作为本轮执行要求。

爽感目标：第一次出刀就有打击反馈；第二笔让交点明显爆发；第三笔围出区域，出现比两线组合更强的收束反馈。组合不依赖点选，也不要求交点里先有敌人。

## 2. 已核对的工程现状

当前项目为 TypeScript + PixiJS 8 + Vite，已有微信小游戏适配，不是任务书中假设的 Cocos Creator。沿用项目现有 Pixi Graphics、渲染层与平台适配，不引入 Cocos、网页 DOM 特效或另一套示例工程。

关键接入点：

- `src/ui/interface.ts`：主菜单入口及动作类型。
- `src/bootstrap.ts`：开始/重开/返回菜单、输入、每帧时间与练习界面的组装。
- `src/ui/practice.ts`：现有八种练习技能、等级选择、试放、无限灵墨开关。
- `src/gameplay/game.ts`：施法校验、技能创建、练习模式、伤害、暂停与清理。
- `src/gameplay/slash.ts`：旧一字斩等级配置、主斩线段、命中与追加攻击。
- `src/rendering/slash.ts`、`slash-basic.ts`、`slash-evolution.ts`：可参考和复用的直线视觉。
- `src/input/controller.ts`、`recognizer.ts`：有效付费轨迹、识别、松手与超时成符。
- `src/input/coordinates.ts`：转换到 720×1280 逻辑世界；实际适配仍要核对浏览器/微信输入路径。
- `src/gameplay/clock.ts`：真实时间与减速战斗时间分离；`ink-config.ts` 管理当前灵墨。

当前直线已经按有效手绘的起终点定位；`attachSwipe` 将主斩总长扩展为手绘端点距离的 1.5 倍，两端各多出原长度的 25%。并非所有线都从狐狸中心发出。Lv3 追加斩、Lv4/Lv5 绘卷另有原有时序及范围。

当前资源是灵墨，不是旧 README/任务书里描述的按张消耗符纸；绘制上限为 3 秒，绘制时战斗速度为 50%。新场地沿用当前代码，不照搬过时说明。

“三角”已有两套：`triangle` 为追踪符箭；`sancai` 为最近的三才符，小三角飞刃、大三角成阵。三才符当前为表现原型，`damage=0`，尚未接入伤害。选用它不等于本次顺便补全其战斗逻辑。

## 3. 新入口与隔离方式

建议复用现有背景、狐狸、刷怪、暂停、返回菜单、等级选择、画笔设置和灵墨开关，新增明确的模式标记，例如 `interactionPractice`。新入口可正常在浏览器与微信版本打开，不只存在于开发参数中。

新场地无玩家受伤、无局内升级打断、无通关计时；延用练习场刷怪。默认无限灵墨以便连续试组合，仍可切换有限灵墨测试真实操作节奏。进出/重开均清空残痕、组合、待结算攻击及特效，试验不写入正式成长成绩。

五种符术均有独立的等级选择与试放入口，底部布局按可读性安排，不强行挤在一排。新版直线暂名「留痕一字斩」，独立于旧「一字斩」配置和组合状态；其普通攻击先保持旧版对应等级的伤害、宽度、时序与视觉。保留 Lv1–Lv5 便于比较，首先在 Lv1 验证组合清晰度，再检查高等级绘卷是否遮挡残痕。

两种三角按钮分别标明「追踪符箭」「三才符」，不能都只写“三角”。为让同一种手画三角能验证两套技能，建议以最近选择的三角技能决定手绘三角的释放类型，默认三才符；各自的试放按钮始终释放自身技能。该选择只影响直接画出的三角符，不影响三次直线自动围合；无需靠不同画法猜测玩家想测试哪一个。

优先独立复制/封装直线行为与表现入口；静态素材、基础数学、稳定渲染辅助可复用，避免复制整个游戏。新模式独有的修改不能改变旧版默认参数和行为；如需调整共享辅助，必须补旧版回归验证。

技能限制同时作用于底部按钮、手绘识别结果和快捷试放。隐藏其他按钮不等于限制成功。画出范围外符术时显示「本场暂不支持此符」，不发技能、不生成残痕；灵墨按现有拒绝施法流程退回，不临时变成另一种技能。单条连续笔画的闭合三角仍属于三角技能；只有三次成功释放的直线才能生成三线窗口。

## 4. 出刀与残痕：建议方案

普通直线攻击照常发生；成功成符立即登记一条可交互残痕，失败笔迹、干笔余痕、镜像斩、追加斩与绘卷均不额外产痕。

已确认残痕使用**当前主斩的 1.5 倍手绘线段**：以有效付费手绘端点的中点为中心，两端各延伸原长度的 25%，总长为原端点距离的 1.5 倍。残痕直接取主斩计算出的线段，确保出刀、留痕和交互范围一致。保持长度随有效付费轨迹变化，不引入固定长射线，也不把干笔轨迹算进去。持久残痕的端点必须清晰可见，可用轻量收尖/端点亮粒帮助玩家搭形。

所有残痕、交点、窗口、伤害区域统一使用战场逻辑坐标，同一份几何数据用于显示和判定。有效场地应取实际可绘制且未被 HUD/底栏占用的战斗区域，不能直接把整个 720×1280 画布当可交互区域。跨边界线段先裁剪，再用于显示和交互；尺寸适配不改变世界中的残痕位置。

每条残痕保存唯一 ID、施法 ID、两个端点、来源/等级、创建与到期时间、该次伤害快照、有效标记。只保留两点，不为残痕长期保存整条采样路径。

已确认首版：持续 3 秒，最后 0.5 秒渐隐，最多 6 条；超过上限先移除最旧一条，再用保留的线检测。创建残痕不额外扣墨，不随出刀动画结束而提前消失。当前是原型阶段，参数集中配置，后续按试玩反馈调整。

残痕采用“游戏处于运行状态时累计的真实时间”：按住绘制减速时仍正常流逝；暂停、切后台冻结，恢复后不补扣后台时间。需用未减速的时间增量，不能直接挂在技能 `age` 或当前被帧预算截断的模拟时间上。

**节奏风险：**当前单笔最多可画 3 秒，若第一笔后慢慢画两次，3 秒残痕可能等不到第三笔。首版建议先用 3 秒测试快画；不好凑形时优先调到 4–5 秒，不能暗中用慢动作延长寿命。时长统一配置。

## 5. 两线相交：交点爆发

新线与尚有效的旧线在有限线段内相交，交点位于有效场地，就自动触发。不要求垂直；平行、重合、近乎平行、仅延长线相交、过期线均不触发。

夹角按较小夹角计算，初始门槛建议 20°。近端点容差建议先设 8 个世界单位，且必须在视觉上补齐可见短缺口，让显示与判定一致，不能隔空起爆。同端点出发、只形成 V 字而没有穿越的两线不算交点奖励；线段中部真实穿过狐狸位置可以正常触发，不设置“狐狸周围一律失效”的盲区。

同一对 ID 最多触发一次，每次新线最多 3 个交点爆发；超过时按离新线起点的距离排序，ID 打破平局。保留残痕以便后续围合，不因两线爆发直接消耗它们。

参考图：[交点爆发设计参考](references/line-interaction-cross-reference.png)。参考其“相交位置集中爆亮、两条原方向贯穿、符纸点缀”的表现，不照搬横向构图、全屏光束和多条放射线的攻击范围。

建议演出约 0.25 秒：交点白金闪光 → 沿两条线方向的短促剑气扩张 → 碎金和少量朱砂消散。交叉角度跟随实际线段，不固定画成垂直十字。可配一声短促重击和轻微局部震动，避免每个交点叠加长时间停顿。

交点小范围额外伤害：建议半径 60 世界单位，敌人碰撞圆与范围相交可命中；在爆发帧结算一次，每敌每事件最多一次。伤害建议为**新线该次主斩伤害快照的 40%**，已包含等级/质量等原修正，不再二次乘算；仍经现有 `Game.damage` 处理护甲、受击与死亡。

## 6. 三线围合：三角窗口

已确认“窗口”是三条残痕围出的一次收缩绞杀。必须有完整的显形、停留辨形、收缩、爆闪和渐隐动画，不能触发后立刻消失。它不承担持续周期伤害或传送玩法。

只有第三条新线加入后，三条有限线段两两相交，三个交点互不重合，才能形成有效窗口。允许线段超出三角顶点，不要求三笔首尾准确相连。三线共点、共线、只存在两个交点、仅延长后围合均不产生三角窗口。

初始防误判建议：面积至少 3000 世界平方单位，最短边至少 40 世界单位；三角判定也沿用 20° 交角门槛。面积/边长/容差集中配置，最终通过手绘实测调整。三角三个顶点及内部应在有效场地内。

每组三个 ID 只触发一次；每次新线最多一个窗口。出现多个候选时优先面积较大的有效窗口，同面积按残痕 ID 排序。已按试玩反馈调整：围合时立即移除参与的三条残痕，新线也一并消耗，不再与其他残痕追加本次交点组合；无关残痕继续保留。窗口独立完成显形、收缩、爆闪和渐隐。

必须先完成三线候选选择，再发布本次两线事件。形成所选窗口的本次新增交点，不再同时播放或结算十字斩；以前已发生的两线伤害保留。新线已被窗口消耗，不再与其他未参与窗口的旧线触发交点爆发。被窗口替代的两线关系记为已处理，不能之后补发。

建议演出总长约 0.9 秒，作为原型初值；重点是先让玩家看清围合形状，再收缩绞杀，余光自然退场：

1. 0.00–0.10 秒：三个交点同时亮起，三条边提亮。
2. 0.10–0.35 秒：明确勾出三角轮廓并短暂停留，内部透出淡金薄光与少量交错刀痕，让玩家看见“围起来了”。
3. 0.35–0.60 秒：边缘向中心快速收束，内部出现切割反馈。
4. 约 0.60 秒：中心白金爆闪、结算一次区域伤害。
5. 0.60–0.90 秒：保留短暂的切割余光与少量碎金，逐渐消退；参与围合的原残痕已移除，仅保留窗口动画的余光；无关残痕继续按原寿命渐隐。

几何边界始终由触发时三个交点锁定；收缩只是视觉演出，伤害仍使用已展示的原三角窗口。结算时检查敌人当时的碰撞圆是否与原三角区域相交：区域内、碰到边或顶点均可命中，区域外不得因外接圆/矩形误伤。移动到外面的敌人可躲开，新进入的可命中。演出中原痕过期不取消已经触发的窗口，重开/退出必须取消。

基础额外伤害建议为新线伤害快照的 120%，每敌每窗口最多一次。首版建议**先不开面积增伤**：更大区域已经覆盖更多敌人；保留配置接口，后续如开启，上限不超过额外 30%。不额外添加破甲、持续控制或自动续期。

围合窗口使用刀痕、边缘收束和一次闪切；直接画三角的技能保持自身飞刃/法阵或追踪符箭表现，避免看成同一个技能。

## 7. 三线共点的边界

本次不做三线共点的专属爆发、倍率、特效或技能名称，也不把面积近零的三交点硬算成窗口。第三条线穿过已有交点时，默认仍按普通两线规则处理与旧线的关系，可能在附近出现两个普通爆发；专属共点奖励后置。若该反馈过亮，可只合并视觉亮度，不擅自增加伤害。

## 8. 实现职责与扩展边界

建议新增独立交互配置、轻量残痕管理、纯几何判定、组合事件和渲染模块，具体文件名在编码时确定。

一次施法流程：识别与灵墨校验 → 新版普通直线生成 → 取得有效手绘几何及伤害快照 → 清理过期/超限残痕 → 登记新残痕 → 优先选三角 → 处理剩余交点 → 发布不可变几何事件 → 特效和伤害分别消费。

事件保存来源施法、残痕 ID、触发时间、固定几何、伤害与命中集合；来源技能从最多 12 个技能列表移除后，已触发组合仍能独立完成。额外伤害通过现有伤害接口，并明确来源，不能误记到最后一个更新的技能，也不递归触发新的出刀/残痕/法宝追击。

只在新线登记时枚举新增关系；过期/容量淘汰时清理记录。最多 6 条线，每次至多检查 5 对与 10 组三线候选；不每帧枚举全部组合。少量 Graphics/节点复用、固定粒子预算，低画质减少装饰而保留端点、交点和窗口边界。

未来圆/雷电可通过带 `kind` 的残留物和交互事件接入，但首版只有直线残痕，不为未来需求建立完整通用规则引擎。

## 9. 实现验收与回归

- 两笔交叉：普通攻击均执行，原位额外爆发一次；平行、重合、延长线相交、纯共同端点不触发。
- 三笔围合：松手立即识别，显示与伤害几何一致；圆角不相关，因为每笔仍需先被识别为直线。
- 三线共点、瘦长小区域、两交点、过期线不误报窗口；端点容差有明确边界测试。
- 窗口优先与两线去重有效，同一帧、重复更新均不能重复扣血；一次新线最多一个窗口、三个普通交点。
- 交点外/窗口外敌人不受额外伤害；边缘碰撞、移动进入/离开、敌人死亡与护甲正常。
- 快画超过 6 条不无限留痕，连续尝试不造成特效/关系记录增长；所有线同时为空后相关记录可释放。
- 暂停、切后台、绘制减速、不同帧率、长宽屏适配下，寿命和几何一致。
- 五符限制通过按钮和手绘都有效；两种三角技能能分别选择、手绘和试放，切换不影响自动三线围合；新版直线的试放也提交有效几何。可在开发检查中提供固定交叉/围合样例，经真实识别施法流程运行，不能只靠随机试放证明可玩。
- 窗口有可辨识的显形停留、收缩和消散动画，不一闪即灭；残痕几何与 1.5 倍主斩一致（场地边界按统一裁剪规则处理）。
- 从新场地退出、重开、切回旧场地后，无残留视觉/伤害/技能限制。
- 旧入口仍提供原技能列表，旧直线 Lv1–Lv5 的主斩长度、伤害、追加斩/绘卷和墨水行为保持现状。

编码后执行：几何/时钟/伤害专项测试、`npm test`、`npm run test:practice`、`npm run build`、`npm run build:wechat` 及适用的微信测试；浏览器实际拖画验收交叉、围合和旧场地回归。真机触控、帧率、音效/震动强度需单独试玩，不用自动测试替代。

## 10. 已确认的体验选择与原型初值

1. **三角窗口：** 一次收缩绞杀，不能立刻消失，必须有完整动画。本文据此将初始演出建议设为约 0.9 秒，包含轮廓短暂停留和尾部渐隐；具体时长可在试玩中调整。当前图片只提供交点爆发参考，窗口美术按本文先做原型。
2. **三角技能：** 追踪符箭与三才符都保留供验证，新场地共五种技能。三才符沿用当前原型行为，本次不额外补完其伤害。
3. **残痕长度：** 采用当前出刀的 1.5 倍手绘长度，与主斩线段一致，优先保证组合容易搭出、操作爽快。
4. **残痕寿命和数量：** 3 秒、最多 6 条，已接受作为原型初值，后续可调。

其余数值作为首轮试验默认建议：40% 交点伤害、120% 窗口伤害、暂不开面积增伤、默认无限墨。这些是可调初值，不代表已试玩验证或最终平衡值。两种三角的手绘切换方式为本文补充的实现建议，无需增加组合确认操作。
