# 随笔划斩 · 实现与验证

2026-10-16。已按[方案评审](随笔划斩-保底攻击方案评审.md)接入「符术交互 · 试验画境」。

## 怎么体验

在新试验场画一条弯曲笔迹或未成符的折返笔迹，松手后出现「随笔划斩 · 沿笔迹切割」。刀光约0.12秒沿原笔迹掠过，约0.35秒退场。它自动发生，不增加第六个手势选择按钮。

五种正式技能仍优先释放，不追加保底。弧线、波浪等未在本场地开放的符形，会按普通笔迹保底，不释放对应的其他技能。旧试符场和正式战斗继续保持此前未成符消散规则。

## 实际规则

- 固定30基础伤害、24世界单位命中宽度；同一笔每个敌人最多命中一次。正常处理护甲、受击、死亡和场内击杀。
- 画完后攻击，绘制中没有预先伤害。碰撞只沿曲线及其宽度，不用起终点弦线、包围盒或狐狸发出的射线。
- 只使用已付墨的笔迹前缀，最大1080世界单位，保留折返点；显著拐弯过多时只取前64点，不跨过遗漏拐弯补线。
- 路径长度至少50.4、跨度至少38世界单位。短触、微抖、无墨起笔、UI操作和系统取消不生成攻击。
- 保底不增加正式成符次数，不返还成符灵墨，不触发法宝，不创建直线残痕、不参加交点或三角组合。
- 灵墨仍在绘制过程中扣除，保底不另收费。松手、超时各只结算一次；超时后等待原手指抬起，不能继续攻击。
- 保底推进和余光采用战斗时间，下一笔绘制时随战斗减速；暂停冻结。重开、返回菜单清空全部保底状态。
- 同时最多6个对象，优先回收已完成攻击的旧余光。如果极端合成输入让6个攻击都还在推进，新输入安全拒绝并按既有流程撤销未结算费用，不丢弃已有待结算攻击。

## 主要接入与配置

- `src/gameplay/fallback-slash-config.ts`：伤害、宽度、长度/跨度、路径预算、点数、推进/退场时间与容量。
- `src/gameplay/fallback-slash.ts`：有界真实路径、场地裁剪、折返保护、低帧率连续扫掠、单笔去重和生命周期。
- `src/rendering/fallback-slash.ts`：与碰撞共用路径的短促金白/朱砂笔痕；按画笔皮肤配色，外观设置不改变实际命中宽度。
- `src/input/controller.ts`：仅在模式允许时采集额外的1080长度前缀，避免原输入降采样丢掉早期折返；收笔先交给正式/保底分流，再一次结算灵墨。
- `src/input/recognizer.ts`：增加可选保底结果字段，正式手势识别阈值和分类规则保持原样。
- `src/gameplay/game.ts`：仅对新场地的手绘输入启用保底；独立对象不进入正式技能工厂，也不重新启用全局 `ink` 攻击。
- `src/bootstrap.ts`、`core/types.ts`、`rendering/view.ts`、`ui/practice.ts`：模式开关、专属音画事件、渲染、提示与诊断计数。

## 验证

新增15组专项测试：有效失败笔和未开放曲线符形、正式技能优先、曲线内外目标、松手前无伤害、低帧率扫掠与击杀、折返去重、四皮肤与等级伤害一致、灵墨成本/零成符返还/统计隔离、短触和微抖、UI/取消/暂停/无墨、超时去重、干笔截断、1800点压缩输入的真实前缀、裁剪空隙、容量和退出清理、极端并发拒绝退款与已接受攻击保留、独立渲染。

真实浏览器指针检查覆盖430×932、375×667、390×844三种画幅：曲线上目标240→210，弦线位置目标保持240；验证有限灵墨无返还、短触免费、折返、正式直线优先和旧场地仍消散。截图与结果位于 `screenshots/fallback-slash/`。

验证命令：`npm run test:fallback`、`npm test`、`npm run test:fallback:preview`、`npm run test:line-interactions:preview`、`npm run build`、`npm run build:wechat`、`npm run test:wechat`。预览脚本默认连接5175端口开发服务。

微信检查通过浏览器模拟原生触摸验证新增场地的弯笔保底及渲染；实体手机触控、帧率和最终手感仍需试玩，30伤害等数值为原型初值。
