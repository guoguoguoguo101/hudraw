# 阔锋：展锋 / 横扫 / 重锋 / 一笔破空

Lv4 为正常画笔的笔迹撕开虚空。裂隙完全采用实际输入折线，直线、弧线、转折、回环均跟手；没有额外向前伸出的斩击，也不会用首尾连线替代玩家笔迹。无内置冷却，无蓄力要求。

| 等级 | 基础笔宽 | 主笔伤害 | 特点 |
| --- | ---: | ---: | --- |
| 0 | 16 | 30 | 原始画笔 |
| 1 展锋 | 26.4 | 36 | 宽笔与朱砂墨色 |
| 2 横扫 | 34.4 | 44 | 更宽笔迹与锋口 |
| 3 重锋 | 42.4 | 52 | 墨刃跟手，扫过半径38，普通怪轻推 |
| 4 一笔破空 | 49.6 | 60 | 笔迹张开深色虚空，金白亮边、冷蓝薄边、星云流带与星流内爆 |

裂隙主体半宽44（起收笔除外），带轻微不规则边缘，主体全宽约78–98，超过Lv3重锋的76扫过直径。内部有三层蓝紫星云流带、错落星点和横穿裂口的短促收束光，所有元素沿实际笔迹生成，低画质减少装饰数量。

每段笔迹约0.065秒展开，保留约1.1秒，末尾0.38秒逐段收拢。持续绘画时，旧笔迹逐渐闭合，新笔迹继续张开。保留毛笔和笔尖，不产生独立飞行物、碎纸或喷射墨滴。首次升满短暂显示“一笔破空 / 笔过之处 · 虚空裂开”。

每段真实笔迹分两次判定：0.045秒后裂开，半径44、伤害180；0.32秒时星流内爆，半径38、追加96伤害，并短暂停顿和轻拉普通存活怪靠向该段中心。每笔每敌各阶段最多一次；走进裂隙内的怪也能赶上第二段。长笔迹的后续区域也继续各自进行两阶段判定，下一笔立即重新计算。内爆后不再持续伤害。普通主笔原有伤害间隔与判定保留，两段次生伤害均不递归触发其他技能。判定沿实际分段并裁剪到画布，不补连中断部分、不延长端点、不跨越弯线内部。精英和首领不强制打断。

资源上限：六条可见笔迹，每条96个路径采样、12个命中切痕。已接受笔迹的待判定队列独立于显示上限，快速连续落笔不会丢失伤害。局部光晕沿真实路径采样，使用共享64×64纹理和复用精灵，不使用全屏模糊。低画质减少光层和内部微光，挥笔声音限制同时四个声部。

验证：`npm run test:brush-upgrades`、`node scripts/check-brush-rift.mjs`。浏览器检查涵盖真实鼠标的直线、S线、圆圈、直角，连续九笔显示预算、无冷却、逐段消退、低画质、小屏、GL与音频。截图位于`screenshots/brush-rift/`。
