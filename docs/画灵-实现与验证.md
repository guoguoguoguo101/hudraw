# 画灵 · 独立绘物测试场

## 当前玩法（2026-10-24）

- 普通画笔不识别直线、圆或其他符形，移动笔尖经过纸妖时立即造成 30 基础伤害，无需松手。同一敌人有 0.35 秒受击间隔，跨笔保留；停住与旧墨迹不会持续伤害。伤害沿实际采样线段扫掠，距离容差 24 世界单位，不沿起终点连线补伤。
- 画灵始终正常速度运行，取消绘画减速、符境暗层、识别预览和普通画笔的单笔时限。沿用试验场无限墨与演武免伤。
- 移除「补虎」「补鹤」卡片、专属补画流程与表现，底部保留「画龙」「画山」「裁纸」。选中这三张卡时仍使用各自绘物规则，退出后恢复普通画笔。
- 封印与场景虎影保留沿笔迹补亮；锁链改为直接沿笔迹划断；妖火改为笔尖接触收集，五团收齐后凝成焰聚符，不再要求画圆。
- 场景符卡拖放、跨阶段库存、暂停和重置继续保留。改动限定画灵，旧试验场和正式战斗继续使用各自原规则。

验证：26 组画灵逻辑测试；实际浏览器鼠标检查即时命中、按住超过原时限、正常时间、三卡绘物、三种手机画幅及旧模式隔离。截图保存在 `screenshots/hualing-brush/`。

## 画符 · 剪纸枫舞（2026-10-24）

由粉桃花雨调整为与现有秋山一致的细小剪纸枫叶：朱红、橙赭为主，少量淡金，带五裂叶形、折面和细叶脉。底部第四张「画符」点按使用，持续 12 秒；再次使用刷新为 12 秒，不叠加时间。当前试验场可反复试用，无掉落/养成接入。

普通画笔每行进约 29 世界单位落下一片枫叶，沿实际笔迹发射，停笔不持续发射；松手后已有花瓣继续下落、摇摆、翻转并淡出。朱红、橙赭与少量淡金，单片尺寸约为旧版一半，存活约 1.3–1.86 秒，上限 72 片，低画质减半绘制。全部程序化绘制，不加载概念图。

花瓣暂为视觉附笔，不增加伤害或改变原有笔痕寿命。选中画龙、画山、裁纸时不生成花瓣。暂停冻结持续时间与花瓣；重置、重开、菜单清理状态。三种手机画幅的真实点击、拖画、暂停与清理已检查；脚本 `node scripts/check-petal-brush.mjs`，截图 `screenshots/maple-brush/`。

## 雷符 · 银雷随笔（2026-10-24）

按 `assets/concepts/thunder-brush-v2/a-ice-blue.png` 的方向实现。底部第五张「雷符」点按使用，持续 12 秒，可反复刷新但不叠时。暂为视觉附笔，不增加伤害、连锁或控制。

使用期间隐藏普通朱红墨面，替换为银白主雷脉、淡暖金边与灰绿暗缘，全条最多两处细分叉；笔杆为灰黑银色，去掉笔尖放射电网。主雷脉带轻微明暗流动、一处移动暖金亮点与偶发微电花。轨迹取真实有效笔迹，每段电弧约 0.32 秒内散去；划过敌人时追加局部接触电弧，不对分叉范围额外判伤。上限 120 段、16 处接触效果，低画质减少分叉。无屏幕压暗或全屏频闪，不切换山水背景。

雷符和画符可共存；画龙、画山、裁纸仍使用原独立绘物输入。暂停冻结效果与时长，重开/重置/退出清理，到期恢复普通画笔。专项脚本 `node scripts/check-thunder-brush.mjs` 检查真实鼠标点卡、普通墨面隐藏、短残留、暂停、到期恢复及 375/390/430 布局；截图在 `screenshots/thunder-brush/`。

雷符音效：启用时短促充电，行笔达到距离门槛时播放低音量电流脉冲，命中追加轻放电；不新增循环音源。行笔/命中分别限频，并限制最多 3 个合成声部。沿用静音设置与浏览器/微信音频适配。离线音频渲染验证有限样本、低峰值、静音无输出与连续调用限流。

## 画笔命中修正（2026-10-24）

普通画笔按「笔宽的一半 + 怪物身体半径」做线段扫掠碰撞，划过身体边缘也计入命中。原版本只检查笔迹到怪物中心的距离，基础半宽 8，造成身体重叠时视觉上划过但实际漏判。不同纸妖、普通怪、精英和首领分别使用身体范围，不包含长翅膀、流苏、阴影及特效。

同一笔可命中所有相交怪物，单怪死亡不会打断其他怪物结算。保留逐怪独立 0.35 秒间隔；新目标不受其他怪物间隔影响。同步有效输入最小采样距离，修复 2.5–3 世界单位的慢速笔画段被战斗层忽略的问题。只调整画灵主笔接触，副墨滴仍遵循原单目标投射规则。

专项测试 `tests/brush-contact.ts`，真实鼠标复现 `node scripts/check-brush-contact.mjs`，记录与截图 `screenshots/brush-contact/`。

## 画卷共鸣 · 第一部分：补亮封印

进入画灵即在场景中出现一处残缺封印，不需要选符、切模式或从指定起点开始。它独立于下方五张原有绘物预览；选择旧卡时暂时隐藏封印，退出旧卡后保留原进度。

- 观察实际被画笔接受的轨迹段，经过哪段纹路就点亮哪段；判定容差 16 世界单位，离散纹路间距不超过 7 单位。正反描画、从任意位置开始、分多笔和不按顺序均有效；重描不重复计数。只自动闭合两端都已亮起的极小内部间隙，不跳过整条分支或未经过的端点。
- 不接管画笔、不自动吸附，原来的直线、圆阵、随笔路径攻击照常发生。UI、错指、干笔和超时等待抬手阶段不提供有效描画段；取消与暂停保留已经点亮的纹路。
- 全部补亮后播放复原与收符动画，0.9 秒后在三格符匣的中格收入一张「破印符」。每次试验只产一张，不随机刷新，不做符纸材料、自由符号识别或北斗七星。
- 从成品符卡拖向战场时预览半径 135 的范围；松手释放一次 120 基础伤害冲击。普通怪与精英受击退，鬼王不位移。点按原位、拖回符匣、画布外松手、取消或暂停保留卡牌；用后不能再次释放。
- 「重现封印」仅重置本原型的纹路、卡牌和未结束冲击，不重置整场战斗；「重置画境」、重开与返回菜单清理全场状态。该事件的位置及符匣随手机画幅调整，局部纹路进度不随布局变化丢失。

验证：`npm run test:hualing` 包含新增 5 组场景事件测试；`npm run test:hualing-resonance:preview` 实际鼠标验证反向补画、跨段续画、重描、普通及随笔攻击并存、暂停、收符、取消拖放、范围伤害去重、重置与 375/390/430 布局。预览服务可通过 `LINGHU_PREVIEW_URL` 指定，默认 `http://127.0.0.1:5175`。截图与记录在 `screenshots/hualing-resonance/`。

## 大动作原型：断链 / 收火 / 虎影

画灵底栏顶部四个试验按钮为「封印 / 断链 / 收火 / 虎影」，旁边按钮重现当前事件；下方原有五张绘物预览不变。切换试验时清除当前事件的进度、成品卡、拖放、召唤兽及未完成伤害，保留正常战斗与基础手势。它们是分别比较手感的固定测试事件，不是正式的随机刷新系统。

- **断链 · 一笔横断**：三条长锁链横跨场景，每条约 460—580 世界单位。只有成功释放的一字斩才按原始笔迹覆盖链身，容差 22；未识别的随笔、圆和单纯移动画笔不切链。允许分次反向斩断，重复位置不计数；破链时出现短暂斩光和有上限的链节碎片。三链全部斩开后收成「裂空符」。拖放时预览 520×130 横扫范围，释放造成一次 160 基础伤害与击退。
- **收火 · 大圈收势**：场上固定五团妖火。成功释放圆阵后，以手绘闭合多边形而非技能半径、包围盒或狐狸位置判断圈住哪些火焰，边界容差 8。空圈不消耗事件；圈到至少一团就旋转收拢，产一张「焰聚符」，该次事件结束。小圈一火、大圈五火可分别重现比较，不需要先凑满五团。卡牌强度保留收火数量 N：释放半径 115+18N、一次伤害 60+30N；拖放预览使用相同半径。没有额外的符形识别或预选类型。
- **虎影 · 巨兽补灵**：在山河上显出原纸虎造型放大的虚影，缺少两道舒展的背脊、卷尾灵纹。任意付费有效笔迹碰到就逐段补亮，容差 26；不锁起点、不吸附、允许反向和分笔续画。完整后虚影升起、凝成「山虎符」，不会自动出战。拖到合法地面后复用现有纸虎的十二秒自动寻妖与跳扑伤害；该场景虎与旧「补虎」预览的纸虎各自独立。边界取消保留卡牌，暂停冻结召唤。

本轮新增 6 组逻辑测试；画灵专项共 20 组。浏览器脚本增加真实切换按钮、三道长斩、小圈与大圈、收火强度、长轮廓续画、虎符收集与召唤实伤、切换清理及三种手机尺寸截图。仍属于参数未平衡的可操作原型。

## 山河流转 · 落日、起风、夜色

2026-10-23。画灵进入时自动演示一段 90 秒的山谷光景。天空、山体切面、岩纹、河流、瀑布、楼阁、鸟居、枫枝、灯笼及庭院均由矢量形状绘制，不加载 AI 参考图作为运行背景。三个相同地形的静态配色层预先缓存，交叠渐变；水纹、云雾、落叶、风线、星光、灯火与萤火保留实时矢量动画。正式战斗和旧测试场继续使用原环境。

- 0—26 秒：丹霞落日，暖纸天空、朱砂日轮、金色河光。夕阳缓慢下沉。
- 20—34 秒开始过渡到起风，山体由赭红转灰青，云海横移，枫叶与风线横过画面。32 秒显出收火事件。
- 49—65 秒进入夜色：天空转靛蓝，月轮、星光、银色水流、窗灯和萤火逐渐亮起。64 秒浮出虎影；补全后山间留下微弱的星痕。
- 达到 90 秒后停留夜色，云雾、水流和环境动画继续。按真实游戏运行时间推进，不受画符慢动作和定格妖潮影响；全局暂停会冻结光景及互动。
- 战场上方提供「自动 / 落日 / 起风 / 夜色」小按钮。三个阶段按钮直接预览并停住时间进度，环境动画仍持续；「自动」从当前时刻继续。不会移动狐狸、敌人或修改手绘坐标。
- 跨阶段保留每种场景的已补纹路与已获得卡牌，回到阶段可以续补；旧成品卡在三个符位里始终可见、可拖放使用。满匣时新奖励等待空位，不覆盖库存。画笔或符卡正在拖动时自动事件切换延后到松手，避免一笔中途换目标；暂停会取消所有阶段的拖放并保留卡牌。
- 下方「封印 / 断链 / 收火 / 虎影」仍用于手动重现单个原型，选择后停止自动替换事件，背景时间继续。按阶段按钮可重新回到场景关联事件；重置画境恢复完整时间线并清理所有库存和进度。

AI 氛围参考及原始提示词归档在 `assets/concepts/hualing-landscape/`，运行时未加载。新增 6 组时序/库存测试，画灵专项共 26 组；`npm run test:hualing-landscape:preview` 检查真实按钮、自动过渡、暂停、跨阶段续补与用卡、375/390/430 画幅及主页隔离。截图和本机渲染采样在 `screenshots/hualing-landscape/`；采样不代表实体手机帧率验收。

## 五张灵符（原有预览）

- **画龙 / 一笔游龙**：选符后出现淡金建议路径。自由画一条最多 1100 世界单位的路径，松手后剪纸龙沿原路线展开冲阵；对真实路径附近的敌人造成一次 160 基础伤害，重描不重复命中同一敌人。不是动物外形识别。
- **画山 / 落笔成山**：画横向、有高低的山脊；跨度至少 130、高低差至少 22。最多维持两座纸山，持续 16 秒，普通怪和精英受到阻挡，鬼王不受地形位移。点「推山」向前倾倒，扫过区域造成一次 120 基础伤害。绘制轮廓、纸山主体、地形和推倒伤害使用同一份路径；当前推倒方向固定朝画面上方。
- **裁纸 / 裁纸开天**：自由划线，裁口跟随原笔迹；松手后蓄势 0.72 秒，沿原轨迹造成一次 180 基础伤害，播放矢量纸缘翻起与狐爪撕开。不以包围盒或起终点连线判伤。
- **补虎 / 补灵·纸虎**：纸虎缺少卷尾，从亮点沿淡线修补；完成后复用现有纸虎模型、折叠动画、自动寻妖和跳扑伤害，活动 12 秒。没有另造一只不一致的老虎。
- **补鹤 / 补灵·纸鹤**：纸鹤缺一侧翅膀，沿翼缘修补；完成后起飞，展开扇形风浪，实际吹退前方普通怪，精英减弱，鬼王不位移；不额外造成伤害。

以上伤害是首版预览参数，不表示完成平衡验证。

## 输入与界面

普通状态直接认直线、圆。点选灵符后完全接管画布输入，不同时触发基础符，也不消耗普通灵墨。结束或取消自动回到基础状态。自由画的短误触不释放，保留选符供重画；越出绘图区松手取消本笔。多指只由已捕获指针驱动；非有限坐标拒绝。

原五卡中的补虎、补鹤仍只检查当前进度附近的下一小段，允许偏差，不按整图相似度打分。偏离不推进；抬手、暂停、切后台保留已补进度，换符、取消和重置清除进度。六秒单笔上限只取消当前输入，不自动放大招。场景封印采用前述独立的自由覆盖规则。

底部五张纸符始终可见。说明、剩余笔长/修补进度、起笔光点和实时预览一起提示。提供「示范」「取消/补充敌人」「重置画境」「定格妖潮」；成山后示范位切换成「推山」，选中其他符时仍优先示范该符。定格只停敌人自主行为，己方技能和击退可继续预览。顶栏暂停菜单负责返回主页。
