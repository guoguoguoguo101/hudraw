# 画灵 · 精英全卷交锋

本版本替代旧的「身体附近涂三个弱点」。四章二十只精英全部使用整张战斗画卷的攻击物、路线或波纹，当前简洁剪纸造型与章节配色保留。

测试：切到测试界面，选择章节，点击底部精英全名按钮。约 2.7 秒后开始首轮全卷出招。每轮都有预警，普通攻击物通常预警 0.8 秒，珍珠 1.7 秒，大印 2.5 秒。成功反制累计后，精英失衡 2.5 秒、伤害倍率 1.6；每次局部反制已经产生击飞、碰撞、反伤或清场效果，不需要等全部完成才领奖励。未完成也正常进入下一轮，不锁进度。

画笔仍可直接攻击身体，但完整的反击与失衡收益来自画卷中的出招。反打物会伤及沿路小怪；切断、引导、碰撞、清雾、落印都与真实伤害管线连接。反制配有短音效、飞散纸片、回流光路和提示文字，沿用已有声音素材。

练习场保留免伤，底部显示本轮演武受击次数。暂停、定格与成长选择冻结全卷计时；清怪、死亡、切章和返回菜单会移除该怪的攻击物、雪幕、冰面和待生守卫。每轮攻击物数量有限，三精英同场运行时最多保留 48 个攻击物、80 个短效果。

技术入口：`src/gameplay/elite-field.ts` 是世界坐标攻击与反击物理；`src/rendering/elite-field.ts` 是对应剪纸效果。可见长线与圆弧使用同一组几何数据做命中，移动反打物使用扫掠碰撞，避免低帧率穿透。

验证：`tests/elite-roster.ts` 的 14 组测试包含二十只自然反制、碰撞/引导/回血/反射/截招、30/60/120fps 一致性、持续战斗容量及清理。`scripts/check-elite-roster.mjs` 使用二十个实际召唤按钮和鼠标操作，确认所有精英的全卷攻击可交互，另验证完整回旋伞反打与失衡、暂停、小屏布局和 JS/WebGL 错误。截图和记录位于 `screenshots/elite-field/`。
