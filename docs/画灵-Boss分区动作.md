# 画灵 Boss 分区动作

2026-10-26。四章本体采用分区关节和连续网格蒙皮，每个 Boss 使用 37 × 37 顶点。矢量原稿及运行数据不变：在进入章节时将原生矢量绘制结果缓存为一张本地生成纹理，再由 GPU 网格显示关节变形；不加载设计 PNG，不新增逐帧图片或外部动画素材。

| Boss | 活动部位与动作 |
| --- | --- |
| 衔日狐王 | 五组尾部区域、头颈、胸腔和前后足；待机错相摆尾，蓄势伏身收尾，出招抬头甩尾，反制后头部后仰，露心时颈部低垂 |
| 镇潮蜃君 | 上壳、下壳、左右裙边、珠眼；待机轻启，聚潮时张壳与珠眼前伸，放浪时合壳回压，受击时壳体错位震颤，虚弱时展开 |
| 司辰傀帝 | 星盘、头部、双臂、左右袖摆、下摆；双臂抬升聚星，发射时挥袖下压，袖摆有跟随运动，反制时双臂失衡、低头，虚弱时垂臂 |
| 缚梦霜魇 | 头与鹿角、颈部、鬃毛、前后腿和飘带；聚霜时抬头提蹄，释放时低头踏地，鬃毛与飘带跟随，受击扬颈，虚弱时垂首 |

动作从真实攻击对象的 `age / charge` 读取蓄势，实际越过发射时点才进入出招；蓄力到释放平滑衔接，随后衰减收势。提前反制的星束会取消蓄势，切到反制动作。入场、普通命中、狂化、恢复、露心都有相应姿态。胜利或失守后本体继续显示约 1.2 秒的下坠／退场，而非立刻消失。

动作只读取模拟时间，不自己累计时钟；暂停和定格不会偷偷播放，也不会在多次渲染时越变越形。关节影响权重只在建模时计算一次，每帧只更新顶点坐标，不重复构建矢量轮廓。切换章节时释放旧网格、生成纹理与显示节点。

实现：`src/rendering/boss-motion.ts`、`src/rendering/boss-puppet.ts`、`src/rendering/hualing-bosses.ts`。原有攻击判定、反制收益与音效发射事件不改。

验证：`tests/boss-motion.ts` 检查蓄势／释放／取消时点、多部位运动以及各动作有限、受控的变形；`scripts/check-boss-motion.mjs` 在浏览器检查四章 48 帧姿态、暂停渲染幂等、反复切章释放资源与 WebGL 错误；可通过 `LINGHU_MOTION_WEBGL1=1` 使用现有微信纹理适配补丁检查 WebGL1 与原生三参数顶点上传。原四章真实鼠标攻防回归通过，网页与微信构建通过，微信包约 3836 KB，未验证手机真机帧率。

预览：`screenshots/boss-motion/boss-motion-preview.gif`，由实际游戏动作网格导出并排合成，循环展示待机 → 蓄势 → 出招 → 反制受击 → 虚弱。各章帧图及验证结果也保存在同目录。
