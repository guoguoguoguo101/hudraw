# Codex 开发任务书：《灵狐绘卷》单弧符——揽月狐尾

## 一、任务目标

在现有《灵狐绘卷》项目中，新增一个完整的基础符术：

**技能名称：揽月狐尾**

**技能类型：弧线符 / 远程光波 / 攻击与控制**

核心玩法：

玩家用手指在屏幕上画出一段明显的弧线，例如 `(`、`)`、`⌒`、`∪`。

当玩家松开手指，系统识别为有效弧线后：

1. 扣除对应墨水。
2. 小灵狐播放甩尾施法动作。
3. 从小灵狐身边生成一道弯月状的白金色狐尾光波。
4. 光波沿指定方向向外飞行。
5. 命中敌人造成伤害和击退。
6. 光波到达最大射程或生命周期结束后自然消散。

**特别注意：光波必须从角色身边发射，不能直接在玩家画符的位置生成攻击。**

本次必须完成：手势识别、墨水结算、技能生成、飞行、碰撞、伤害、控制、Lv1–Lv4 等级效果、视觉表现和必要测试。

不得只实现演示动画。

---

## 二、开发边界与现有项目兼容

项目为竖屏2D、自由画符施法、Roguelite 妖潮生存游戏。

目前的美术方向为：

- 国风剪纸矢量插画
- 山海绘卷
- 朱砂符箓
- 象牙白、朱砂红、暖金、墨黑
- 角色为白色灵狐

请先检查现有工程的：

- 游戏主循环与时间管理
- 触控采样与手势识别
- 墨水能量系统
- 角色朝向与技能发射逻辑
- 技能注册与升级系统
- 敌人碰撞、生命值及击退系统
- 特效渲染与对象复用机制

**在现有代码架构内实现，优先复用现有接口。不得另起一套平行的战斗、输入或升级系统。**

如果使用 Cocos Creator，遵循现有 Cocos 版本及项目渲染方案。若目前是 JS/TS 程序化路径绘制，应优先使用现有 Graphics、Mesh、缓存纹理或自定义渲染方式。

SVG 可以用作形状设计，但不要假定微信小游戏运行时支持完整浏览器 DOM SVG 动画。

不要生成 PNG 精灵图来替代主要的狐尾、月刃和符纹效果。主要特效尽量使用程序化矢量路径、可变形几何或项目现有图形绘制组件。

## 三、单弧符手势识别

### 3.1 支持的手势

允许玩家画：

- 左弯：`(`
- 右弯：`)`
- 上弯：`⌒`
- 下弯：`∪`
- 倾斜的单段弧线
- 弯曲程度适中的自由曲线

不要求玩家画标准半圆。

只要轨迹存在明显、连续、方向基本一致的弯曲，即可判定单弧符。

### 3.2 识别核心原则

**只判断玩家是否画出有效单弧，不按弧线大小改变光波尺寸。**

不要将玩家画出的轨迹直接复制为攻击路径。

识别过程：

1. 获取原始触控点。
2. 去除距离过近的重复点和明显采样噪声。
3. 平滑并按固定路径间距重采样。
4. 计算有效轨迹长度。
5. 计算起终点弦长。
6. 计算轨迹相对弦线的偏离程度。
7. 计算累计转角和曲率方向一致性。
8. 判断是否属于有效单弧。
9. 返回手势类别、方向、长度和置信度。

### 3.3 建议识别条件

以下均为初始调试参数，不是强制最终值。

使用设计分辨率下的统一逻辑坐标，而不是直接使用设备物理像素。

- 最小有效长度：约60–80逻辑像素。
- 最小弯曲程度：最大偏离量 / 弦长达到约0.12–0.18。
- 累计有效转角：约25°–170°。
- 曲率整体保持同一方向。
- 不允许明显闭合。
- 不允许多个明显反向弯曲段。

实际阈值应结合项目已有的直线、圆形、折线、螺旋识别器共同调试。

曲率转角必须经过平滑和噪声过滤，不能因为轻微手抖就识别失败。

特别注意：当弦长极小时，不得直接进行不安全除法；需要优先检查闭合形状和其他符形。

### 3.4 与现有符形的冲突处理

现有符形包括直线、圆形、折线、螺旋等。

要求：

- 接近直线的轨迹仍优先归类为直线。
- 明显闭合、接近完整一圈的轨迹优先归类为圆形。
- 多次绕转的轨迹优先归类为螺旋。
- 具有明显尖角的折线不能轻易识别为弧线。
- 连续反向弯曲的 S 形本次不识别为揽月狐尾。
- 不得因为新增单弧符导致已有符形识别准确率明显下降。

建议沿用现有候选打分机制；如果没有，则在共享识别器中统一比较候选类型，不允许新增独立识别逻辑抢占其他符形。

### 3.5 输出数据

建议生成：

```ts
interface ArcGestureResult {
  type: "single_arc";
  confidence: number;
  pathLength: number;
  chordLength: number;
  curvature: number;
  bendSide: -1 | 1;
  center: Vec2;
  aimDirection: Vec2;
}
```

具体类型命名可以符合现有工程。

## 四、光波生成与飞行

### 4.1 最重要的规则

玩家画好弧线后，角色释放一枚标准化的弧形光波。

**手势是施法指令，不是光波本身的世界坐标。**

例如：

玩家在屏幕右侧画 `)`：

- 系统识别弧线。
- 小灵狐朝右侧准备施法。
- 从小灵狐身边发射一道右侧弯月形光波。
- 光波朝右侧向外推进。

### 4.2 发射方向

建议优先使用：

**玩家绘制轨迹的中心相对于角色的位置方向。**

例如：

- 在角色右侧绘符，向右发射。
- 在角色左侧绘符，向左发射。
- 在角色上方绘符，向上发射。
- 在角色下方绘符，向下发射。

如果项目已有成熟的手势瞄准方向算法，优先复用已有规则，保持不同符术操作一致。

当笔画中心与角色位置过近，无法稳定确定方向时，使用现有瞄准方向或最近一次有效朝向回退。

不得发生方向随机跳变。

### 4.3 光波姿态

光波是一个横向展开的弯月形攻击体。

要求：

- 光波的宽度方向垂直于飞行方向。
- 光波整体沿飞行方向推进。
- 保持明显弯月轮廓。
- 使用白金锋刃和红白狐尾外层。
- 左右或上下发射时自动正确旋转。

不要将光波做成笔画沿线移动的小光点。

也不要把光波做成一整面矩形激光。

### 4.4 技能从角色身边出生

出生点应基于角色位置和朝向，增加小幅前向偏移。

需要避免光波出现在角色身体内部并瞬间遮挡角色，也要保证贴身敌人可以被正常命中。

### 4.5 飞行与命中

光波生成后：

- 按固定速度向前飞行。
- 可以穿过并攻击多个敌人。
- 每个目标在同一波光波中默认只受到一次伤害。
- 命中目标后不立即销毁光波。
- 到达最大射程、生命周期结束或其他明确的边界条件后消散。

建议使用已有战斗更新机制，确保不同帧率下运动距离与伤害判定稳定。

高速飞行时使用扫掠碰撞检测，避免穿过敌人而漏判。

## 五、光波尺寸：本次固定，不随笔画长度改变

这是已经确定的核心规则。

同一技能等级下：

- 短弧和长弧释放相同尺寸的光波。
- 画得更弯，不增加光波宽度。
- 画得更大，不增加射程。
- 画得更长，不增加单体伤害。
- 画得更复杂，不额外生成光波。

玩家画出任何有效单弧，只会释放一道该等级对应的标准光波。

### 5.1 技能参数

建议按等级配置：

```ts
interface MoonTailLevelConfig {
  damage: number;
  waveWidth: number;
  travelDistance: number;
  moveSpeed: number;
  hitThickness: number;
  knockback: number;
  staggerDuration: number;
  visualScale: number;
}
```

这些字段需要映射到项目已有配置，不必机械照搬类型名。

### 5.2 建议初始成长

以下为相对倍率：

| 属性 | Lv1 | Lv2 | Lv3 | Lv4 |
|---|---:|---:|---:|---:|
| 主光波宽度 | 1.00 | 1.15 | 1.25 | 1.40 |
| 飞行距离 | 1.00 | 1.05 | 1.10 | 1.15 |
| 基础伤害 | 1.00 | 1.30 | 1.55 | 2.00 |
| 控制能力 | 轻击退 | 中击退 | 回卷 | 强收束 |

最终绝对数值参考一字斩和其他当前技能，不要直接按这些倍率造成强度失衡。

注意视觉外层允许比真实命中区域稍宽，但两者应保持合理一致。

## 六、墨水机制

### 6.1 设计目标

鼓励玩家使用简洁、准确的笔画。

让熟练玩家逐渐学会更省墨的施法方式。

但是，不允许极短手势无限低成本施法。

### 6.2 推荐墨耗公式

```text
实际墨耗 =
max(
    最低施法墨耗,
    有效笔画长度 × 每单位长度墨耗
)
```

例如：

```text
最低施法墨耗：10
单位长度墨耗：0.1

有效笔画100 → 消耗10
有效笔画150 → 消耗15
有效笔画220 → 消耗22
```

这些仅为示例，最终参考项目现有墨水刻度。

### 6.3 和已有墨水系统衔接

必须首先检查现有墨水系统是如何在绘制过程中扣费的。

如果是实时扣墨：

- 继续实时扣墨。
- 新技能不要重复扣除。
- 识别后只结算已有的墨水账本。

如果是松手结算：

- 在确认有效符形后扣除墨水。
- 不允许出现先扣一次绘制费用，再扣一次技能费用的问题。

如果现有机制已有墨耗下限和长度限制，优先复用，不要重复叠加。

### 6.4 长弧处理

玩家可以画很长的单弧，但不会获得更大的光波。

这是有意设计的规则，不是功能缺失。

玩家应该逐渐理解：

**画符讲究准确与熟练，不是画得越大越厉害。**

为了避免玩家误解，可在技能图鉴中说明：

“精准绘出弧符即可施法，冗长笔画只会增加墨耗。”

## 七、Lv1–Lv4 完整技能效果

### Lv1：揽月

**玩法：**

- 一道基础弧形光波。
- 命中造成伤害。
- 附带轻微击退。
- 攻击多个敌人。

**美术：**

- 主体为细而明亮的象牙白弧刃。
- 边缘暖金色。
- 少量朱砂红弧形拖尾。
- 狐尾轮廓很轻，不出现巨大完整尾巴。
- 命中有短促白金闪光。

**动画：**

起势 → 发射 → 飞行 → 命中 → 淡出。

整体强调锋利、快速、干净。

### Lv2：狐尾扫月

**玩法：**

- 增加光波宽度和伤害。
- 击退更明显。
- 更适合多目标扫击。

**美术：**

- 主光波仍保留清晰的白金锋刃。
- 外侧出现明确的白色狐尾形轮廓。
- 狐尾末端略微飘散。
- 朱红色流线围绕尾尖。
- 少量金色符纸随光波运动。

不允许仅放大 Lv1 图片。

### Lv3：双尾揽月

**玩法：**

- 第一段仍为一枚向前飞行的主光波。
- 主波命中产生伤害与击退。
- 主波经过后，在已命中的目标附近触发一次较弱的回卷控制。
- 回卷将敌人轻微牵引到主波经过的中轴附近。
- 同一目标的主波伤害只结算一次。

**注意：Lv3 仍然只需要玩家画一个单弧。**

**美术：**

- 第一条狐尾表现斩击。
- 第二条较细的狐尾虚影表现回卷。
- 第二条尾巴可以沿主波后方形成内收动作。
- 使用少量弯曲卷带、朱砂纹和淡金气流。
- 不允许第二条尾巴直接复制第一条并旋转。
- 回卷效果必须有明确的敌人位移反馈。

### Lv4：九尾揽山河

**玩法：**

- 仍然是一笔单弧触发。
- 召唤巨大狐灵虚影。
- 发射一枚强化主光波。
- 狐尾随主光波向外展开。
- 命中敌人后进行短暂收束。
- 在主光波的有效攻击区域触发一次山海卷镇压伤害。
- 最后朱砂狐印爆发。
- 所有额外效果只触发一次，不得因同一敌人反复进入区域而无限结算。

**美术结构：**

1. 白狐虚影显形。
2. 狐尾张开。
3. 白金弧形主光波向前飞行。
4. 红白卷带跟随。
5. 狐尾收束形成短暂弧形山海绘卷。
6. 卷内出现远山、云海、楼阁剪影。
7. 朱砂狐印落下。
8. 绘卷撕裂、尾影消散。

**视觉限制：**

- 不要做成全屏持续发光。
- 不要产生巨大白色实心区域遮住所有敌人。
- 不要把整张画卷做成普通矩形。
- 不要让狐尾、卷面、符纸全部同时达到最大亮度。
- 主要光波应始终可辨认。
- 巨狐虚影只用于短暂的高级演出，不应长时间遮挡玩家视野。

## 八、技能动画时间轴

以下是建议的视觉时间，最终可以微调。

### Lv1

```text
0.00s 角色尾部起势
0.08s 白金弧光生成
0.12s 光波发射
0.12s+ 光波持续飞行并命中
结束时 尾影自然淡出
```

### Lv2

```text
0.00s 狐尾亮起
0.08s 狐尾虚影展开
0.14s 狐尾光波向前推出
飞行中 保留流动的狐尾轮廓
结束时 尾尖拉细并散开
```

### Lv3

```text
0.00s 起势
0.12s 第一条狐尾光波发射
0.12s+ 主波飞行与命中
命中后 第二条狐尾执行短促回卷
回卷完成 朱砂流线消散
```

### Lv4

```text
0.00s 地面弧纹亮起
0.10s 巨狐虚影显形
0.22s 主狐尾展开
0.32s 白金主光波发射
飞行中 狐尾和绘卷流线伴随
命中后 回卷收束
收束后 朱砂狐印镇压
随后 绘卷撕裂与余辉消散
```

游戏伤害事件必须根据实际命中进行，不要把视觉演出时间直接当作固定伤害判定时间。

大招演出需符合现有慢动作、暂停和游戏时间系统，不允许出现因为绘符慢动作而导致技能持续时间异常。

## 九、程序化特效设计

### 9.1 主光波

推荐使用可变形的弧形 Mesh 或 Graphics 路径生成。

基本结构：

- 外侧朱砂色低透明轮廓。
- 中层暖金色主体。
- 内层象牙白高亮锋刃。
- 尾端细长的流动线条。

主光波尽量少用复杂粒子。

### 9.2 狐尾轮廓

推荐使用动态曲线生成轮廓。

要求：

- 有尾根、宽大中部、收细尾尖。
- 狐尾表现柔软而有力量。
- 尾巴不是规则月牙或粗圆管。
- 飞行时有轻微尾端摆动。
- 边缘可有少量剪纸式分叉毛束。

### 9.3 回卷尾影

Lv3 开始加入：

- 第二条独立曲线路径。
- 从主波外沿回收。
- 朝敌人收束中心运动。
- 可以根据命中位置生成局部回卷效果。

### 9.4 山海卷

Lv4 的山海卷必须分层生成：

- 弧形卷面。
- 远山剪影。
- 云气。
- 少量楼阁。
- 朱砂纹理。
- 金色边线。

可以使用预先缓存的矢量路径资源与动态变形组合。

不要每帧重新解析复杂SVG文本。

### 9.5 性能优化

- 使用现有对象池。
- 尽量减少新对象分配。
- 复用路径数据和材质。
- 限制尾影细分段数。
- 粒子设置合理上限。
- 多个 Lv4 同时存在时减少装饰粒子和次级云纹。
- 保证低端手机中光波运动及命中反馈稳定。

## 十、与现有系统集成

### 10.1 技能注册

将揽月狐尾加入现有技能注册表。

需要包含：

- 技能ID
- 技能名称
- 符形类别
- 技能等级
- 描述
- 等级数值
- 特效引用
- 伤害类型
- 击退控制配置

命名建议：

```text
moon_tail
```

但以项目实际命名规范为准。

### 10.2 Roguelite 升级

揽月狐尾应能够：

- 在符术候选中正常出现。
- 从 Lv1 升级到 Lv4。
- 在局内正确读取当前等级。
- 更新伤害、范围、特效和控制效果。
- 在技能图鉴中显示四级能力。

如果项目还没有完整图鉴，不要因此重建大型图鉴系统；只接入已有相关接口或配置。

### 10.3 敌人反馈

命中时：

- 结算伤害。
