# 灵狐降灵 · 绘卷法衣

旧 Lv4 追踪、绕身长大后冲出画布的实现已撤下。Lv1–3 仍然是追踪符箭；Lv4 变为守护降临仪式。

## 四张关键帧

| 时间 | 构图与动作 | 镜头 |
| --- | --- | --- |
| 0.22 s · 起势 | 小狐狸在中心；金红符环亮起，符纸聚拢，狐灵还未出现 | 近景聚焦角色和法阵 |
| 0.69 s · 钻出 | 巨大狐首从左侧后方探出；弯曲颈身、前肢随后出现；红白长卷由身后带出 | 轻推并上摇，形成侧后方切入 |
| 1.14 s · 盘旋 | 灵狐沿圆弧绕中心一圈；带状狐尾铺出漩涡；角色保持中心锚点 | 小幅摆动与拉远，展开前后景层次 |
| 2.16 s · 法衣定格 | 狐灵俯身守护；九条卷带收成肩部披帛、前襟、腰环和画卷衣摆 | 角色、狐灵和法衣形成英雄构图，停止大幅运动 |

完整阶段：起势 0–0.3 s；钻出 0.3–0.8 s；盘旋 0.8–1.4 s；法衣成形 1.4–2.0 s；守护定格 2.0–2.4 s；收招 2.4–3.0 s。

概念帧的背景使用简化红日、山峦和神社轮廓；游戏实际预览沿用现有场景。PNG、GIF 用于展示和录制，游戏没有读取这些图片播放技能。

## 矢量与动画结构

- **角色本体**：游戏保留原小狐狸，并张开前肢、微微抬头；Canvas 概念预览使用小型矢量角色。
- **法阵**：同心椭圆、符号刻度，轻微旋转与亮起。
- **灵狐**：尖耳、白红狐面、狐眼、额印、连接的曲线躯干和折收前肢，固定路径与局部变换。狐首先出现，躯干和尾卷延迟展开。
- **九条尾卷**：每条由两段三次 Bézier 中轴和独立宽度曲线生成卷面；边缘朱红织带，内侧金线。展开、绕身与法衣阶段使用同一片卷面。
- **法衣结构**：曲线控制点逐渐插值到肩部、腰部、裙摆的目标形态；三片卷面渐渐交接到角色前方。连接的领口、披肩、前襟与金扣让衣片组成法衣。
- **绘卷装饰**：云纹、山海纹、神社、花枝按卷面切线定位，跟随形变。少量重复图样，避免噪音。
- **点缀**：默认十张符纸、六朵卷云、十二片小花瓣、三条金线。每组独立位置和延迟循环，不堆写实粒子。
- **镜头**：围绕施法中心做 2D 缩放、轻微上摇、平移及小角度旋转；HUD 不跟随镜头。结束后恢复原坐标和缩放。

## 代码入口

`src/gameplay/fox-guardian.ts`：

```ts
playFoxGuardianSkill(skill, {
  foxScale: 1.48,
  orbitRadius: 145,
  scrollWidth: 1,
  paperCount: 10,
  patternOpacity: 0.72,
  cameraStrength: 1,
  phaseDurations: [0.3, 0.5, 0.6, 0.6, 0.4],
  fadeDuration: 0.6,
});
```

`guardianTimeline()` 返回阶段与进度，`guardianPose()` 返回连续环绕轨迹，`guardianCamera()` 返回镜头参数。游戏更新循环负责推进技能年龄。默认在完整定格结束后获得 80 护盾、持续 4 秒，并在 320 范围内净化一次；伤害维持 Lv4 ×3.5 的等级倍率。修改五阶段时长会同步改变实际释放时间。

`src/rendering/fox-vestment-scene.ts` 是独立的矢量场景生成器：

- `buildGuardianScene()`：后景、角色、前景的路径数据，颜色、透明度与变换。
- `drawGuardianCanvas()`：直接使用 Canvas 2D 和 `Path2D` 绘制，可接小游戏 Canvas 更新循环。
- `guardianSceneSvg()`：导出同一组矢量路径的 SVG 关键帧。

`src/rendering/fox-vestment.ts` 用 Pixi `GraphicsPath` 将同一组路径接入现有游戏，静态路径不每帧重建。九条卷面独立形变，符纸、云气和纹样独立更新。
