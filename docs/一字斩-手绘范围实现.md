# 一字斩手绘范围

2026-10-14：主斩从等级固定长度改为有效手绘起终点距离的1.5倍，中点保持不变，两端分别延伸原距离的25%。各等级没有额外长度上限；长笔迹消耗更多灵墨，但不会增加每个敌人的基础伤害。

升级仍沿用原来的伤害、命中宽度、符纸、云纹、山海波和绘卷效果。主斩范围内的敌人全部命中，每个敌人主斩只结算一次。Lv3原有追加伤害与反馈保留。Lv4、Lv5绘卷的尺寸、原范围、释放时序和独立命中记录保留，主斩长度不再缩放绘卷。

明显回描和折返判为未成符，允许少量手抖。长度使用起终点直线距离，不累计来回画的路程。灵墨耗尽时，只采用付费轨迹最后一点；干笔余痕不增加攻击长度。密集采样保留最终收笔坐标。

验证：主测试包含60组各等级、长度、方向的渲染几何检查，12敌同时命中去重，绘卷范围不随主斩长度变化，回描失败和密集采样端点；灵墨测试校验付费96单位笔迹产生144单位主斩。另通过80组斩击时序测试、动画测试、演武画境测试，以及浏览器和微信构建、微信模拟启动和渲染测试。

浏览器效果检查：运行本地开发预览后执行 `node scripts/check-slash-length.mjs`，检查五个等级的100／400单位手绘长度，截图存于 `screenshots/slash-length/`。微信生成目录为 `wechat-game/`。iPhone真机效果仍需扫码验收。
