# 狐狸跟随画笔与绘物施法

2026-10-24。画灵专用局部角色动画，不移动角色的战斗坐标，也不增加镜头抖动。

- 普通画笔：按笔尖相对位置朝左/右转身，抬爪、注视、摆尾和摆动围巾；落笔轻提身，收笔轻回落，动作渐入渐出。
- 画龙：扬身引导、抬爪和展开尾部。
- 画山：沉身蓄力，身体略压低。
- 裁纸：身体前倾，较大幅度挥爪。
- 花符/电符：行笔时在手边与脚下保留少量对应色的花瓣/电纹和局部灵光，限制数量和透明度。
- 暂停与升级选择时冻结动画时间；重开与返回菜单清理；其他游戏模式继续原动作。

`node scripts/check-fox-response.mjs` 验证真实鼠标左右朝向、手臂变化、固定世界位置、三种施法动作、暂停稳定和菜单清理。截图与记录在 `screenshots/fox-response/`。
