# 焚山煮海 · 测试场原型

入口：主菜单「符术交互 · 试验画境」，下方右侧「焚山煮海 · 开启」。原有五种符术保留，技能栏改为两行三列。此阶段通过按钮反复试招，暂不接入掉球、能量和正式关卡成长。

四笔外观已接入：朱砂灵笔对应朱砂金焰，狐火灵笔对应青碧狐焰，金纹御笔对应白金御焰，山海墨笔对应山海墨焰。在「画笔 / 特效」中选择现有画笔即可切换，现存火痕会同步变换配色和形态。四笔的伤害与时间规则相同。四张 AI 参考图、提示词和实现说明见 `assets/vfx/burning_sea/`。

开启后获得四秒现实时间的绘火窗口，不限落笔次数与普通灵墨。狐狸保持固定站位，按住绘制立即留下火痕，可松手再画，整次窗口不会重新计时。期间不识别符形、不扣普通灵墨、不触发普通符术或失败划斩，也不触发普通画符的减速。到期时若仍按住，等待这次松手，再恢复普通画符。

所有火痕持续保留，四秒绘制结束后进入两秒共同蓄势，再在同一时刻沿所有轨迹爆炸。绘制与蓄势阶段不造成持续伤害，爆炸时每敌只结算一次基础伤害 180，重叠与反复涂画不叠加。爆炸判定宽度 84，使用爆炸时敌人的位置。爆炸动画持续 0.8 秒后统一清理，期间不能再次开启。参数集中于 `src/gameplay/burning-sea.ts`。

火痕不再有逐段过期或 768 段停笔限制。绘制轨迹全部保留；渲染仅限制装饰与细丝数量，保证长笔迹仍完整显示和参与伤害。四种画笔各自的轮廓、冲击环与碎片在爆炸时同时展开，伴随一次震动和音效。

暂停和切后台冻结火焰及窗口；取消输入会结束当前笔画，恢复后可以重新落笔。清空残痕、重开、退出测试场清除火焰及待结算伤害。旧练习场和正常战斗不提供此技能。

验证命令：

- `npm run test:burning-sea`：九组逻辑检查，涵盖爆炸前无伤害、四秒绘制加两秒统一爆炸、重叠去重、先后笔迹同时保留、长帧只爆一次、按爆炸时位置命中、暂停与清理取消、超出旧容量继续画，以及四笔伤害一致。
- `npm run test:burning-sea:preview`：已有开发服务 `http://127.0.0.1:5175/?qa=1` 上的真实鼠标测试，包含菜单入口、技能按钮、三种画幅、蓄势与统一爆炸、暂停恢复、到期、普通符术恢复及旧场地隔离。可用 `LINGHU_PREVIEW_URL` 修改地址。

截图和浏览器验证记录位于 `screenshots/burning-sea/`。浏览器检查不代表实体手机性能验收。
