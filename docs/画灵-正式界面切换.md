# 画灵正式界面预览

画灵右上角提供「正式界面 / 切回测试」按钮。只改变界面布局，不重开游戏；记住上次选择，重新打开后仍使用该布局。

正式界面保留章节、击杀、计时、生命条、暂停，以及底部游龙符、画符、雷符和场景符匣。隐藏示范、章节试演、场景重现、画笔自定义等级等测试入口；正常成长选择仍可操作，成长弹窗内不显示自定义测试按钮。绘画区域随布局扩大，隐藏按钮不再拦截笔迹。

画山、裁纸已移除；右上角连斩及一笔统计缩小为原布局的 65%，减弱背景与入场动效。

此版本是现有战斗玩法的正式界面预览，尚未更改符的获取经济或增加大招能量机制。

验证：`npm run build`、`npm run build:wechat`、`npm run test:hualing`；`node scripts/check-hualing-play-ui.mjs` 检查 375 / 390 / 430 像素宽屏幕、切换状态保留、隐藏按钮区域落笔、游龙释放、画符激活、暂停恢复、成长选择、连斩大小及布局偏好持久化。实机截图保存在 `screenshots/hualing-play-ui/`。
