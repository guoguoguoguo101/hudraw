# 镇山纸虎 Lv1 · 测试服原型

2026-10-21。已接入「符术交互 · 试验画境」，尚不加入正式关卡或局外养成。

## 操作与当前参数

- 原灵宝栏上方新增纸虎栏，无需装备。按住纸虎卡片拖到地面，松手召唤；无效落点、原地点击和取消触摸不扣次数，不消耗灵墨，也不生成符形。
- 每局两次，同时一只，存活十二秒；结束后有短暂折回纸形的退场动画，期间不再攻击。右下「重置」同时恢复纸虎次数与现有三件灵宝。
- 自动优先寻找画境内已经入场的普通怪，小怪清空后攻击精英或 Boss。没有目标时留在原地观察。没有血量，不要求玩家保护它。
- 动作包括展开、蓄势、跳扑、落地抓击、收势。单次最大跳距 260，落地只攻击距离 66 内的一个实际目标，伤害 48。当前普通小怪基础生命为 30～40，因此扑中能击杀；目标躲开落点则不会隔空受伤。
- 自动攻击循环约一点五秒，不带二阶追扑。目标在蓄势阶段死亡会重新找怪，起跳后不会瞬间转向追踪。
- 存活期间可再次从卡片拖动指令，或按住地面上的纸虎拖向指定位置。覆盖下一次扑击目的地；不刷新存活时间、攻击间隔或召唤次数。腾空时可使用卡片指挥。
- 纸虎以未暂停的现实时间推进，不因普通绘符减速延长十二秒。沙漏停敌时仍可跳扑；暂停、切后台和回魂时不消耗时间。
- 结束、重开、返回菜单、重置时清理实体、预览和未完成拖动。原自由试符、正式试炼不显示纸虎入口。

## 视觉

参考 `assets/vfx/auto_relics/concepts/auto-relics-c-folded.png` 的折纸虎轮廓，以及 A 版朱红镂空纹样。以游戏原生 Graphics 重绘，不把整张概念图贴进游戏。

朱红纸身、米白腹部和脸颊、墨绿连通虎纹、宽眉与王字额纹、短獠牙、卷尾。构件保留折线与深浅纸面，避免毛发、金属和持续光晕。头、尾和四肢独立运动；跳起有纵向弧线、地面阴影、少量纸尾迹，落地压身并甩出三道短爪痕及纸屑。入场从薄纸撑开，离场折回纸面。

静态部件创建后复用，逐帧只更新变换与少量效果，不逐帧新建完整老虎。

## 验证

- `npm run test:paper-tiger`：七组核心测试，涵盖拖放取消、多指、实际伤害与奖励、普通怪优先、目标死亡和躲开、指令跳距、暂停回魂、停时配合、真实时长、长帧和次数清理。
- `npm run test:paper-tiger:preview`：从真实菜单进入试验画境；390×844、375×667、430×932 三种画幅下通过鼠标拖放验证展开、蓄势、腾空、落地击杀、指挥、普通画符共存、沙漏和暂停、到时消失及重置，无页面或 WebGL 错误。截图和状态记录在 `screenshots/paper-tiger/`。
- `npm test`：完整技能、功能灵宝、几何交互、进度与灵墨回归。
- `npm run build:wechat`、`npm run build`：微信包和网页构建。
- `npm run test:wechat`：浏览器 wx 模拟触摸拖出纸虎并保存展开、捕猎截图，随后重置并继续原有灵宝与画符回归。此项不能替代实体手机手感和性能测试。

关键实现：`src/gameplay/paper-tiger.ts`、`src/rendering/paper-tiger.ts`，通过现有功能灵宝生命周期和输入路由接入。
