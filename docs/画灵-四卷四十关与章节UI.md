# 画灵：四卷四十关与章节 UI

## 入口与结构

首页“入画山海”打开选关地图，也可直接打开 `/?mode=mountains`。四章各 10 关，当前全部开放；已完成关卡记录本地印记。每关独立重置成长、墨量和生命。

关卡分成五段：起笔定势 → 泼墨破围 → 锋试精英 → 成势狂潮 → 落印守关。第 5、10 关为本章 Boss，其他关以精英守关，第 9 关中段双精英。所有章节使用已有本章小怪、五种精英、身体连招 Boss，不再由原测试场随机刷出场外怪。

## 两个独立界面

- 选关页只出现章节、关卡路线、当前关卡说明和“落笔入画”。
- 局内获得悟道机会时，暂停战斗，弹出独立三选一笔法卡。选完返回战斗。
- 升级只从喷墨、阔锋、双毫、留墨中选择，均为 Lv1–Lv4。每次真实展示 3 个未满级选项，优先保留已拥有笔法的后续等级。
- 每局共 8 次悟道，包含开局一次；中段与最终段补足成长。专注选择两种技能，可以两门 Lv4；也允许玩家自己选择更多笔法的组合。
- 中段精英后的灵符奖励单独弹出，不占 8 次笔法升级。虎符、蟹符可拖动召唤；枫舞、雷符可重复激活；归元恢复生命。

## 首轮数值

基础笔伤 30，阔锋递升到 36 / 44 / 52 / 60。主笔命中同一目标共享 0.35 秒冷却，短距离反复擦同一点不会无限叠伤。普通怪约 24–134 血，按怪型和关卡词缀变化；原普通怪攻击为 8 / 10，精英与 Boss 沿用其可反制攻击数值。生命上限默认 100，已有修行加成继续生效。

开场前三只按 1.45 秒间隔逐只出现；随后同路双怪；第二段 1.4 秒一批双路夹击；第四段每 1.25 秒出现 3–4 只合围。普通怪同屏上限按词缀为 7–11，只数到顶暂缓补怪，击破后继续；该段敌人清空才会进入下一段。底部符匣区域留出空间，普通怪不会被符卡遮挡。

墨量 100。画笔墨耗为原资源成本的 65%：超过最短有效长度后，起笔成本 3.9，每 720 像素再耗 9.75。抬笔后延迟 0.35 秒，以每秒 12 墨恢复。清普通段补 25 墨，18 秒内清段回 6 生命。游龙消耗 18 墨、冷却 14 秒。已经形成攻击的笔迹取消时仍支付已用墨，避免拖出界外退款而保留伤害。

升级、支援选择、暂停期间，敌人与资源计时冻结。关卡失败、重试、返回首页清理运行状态；原画灵测试入口保留自定义等级与无限墨。

数值集中在 `src/gameplay/mountain-run.ts` 的 `MOUNTAIN_BALANCE` 和关卡词缀表，画笔数值沿用 `brush-upgrades.ts`、各笔法配置。
