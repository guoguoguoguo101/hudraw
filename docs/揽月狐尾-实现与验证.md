# 揽月狐尾：基础版实现与验证

日期：2026-10-14。

## 2026-10-15 手势边界调整

按用户要求，箭头收紧为明确尖角和两条较直的边；揽月狐尾放宽浅弧、局部不规整和轻微手抖。先检查严格箭头，再检查宽松单弧；箭头同时检查转向集中程度、每条边的平均/最大偏差和绕行长度，避免圆弧仅凭两线近似通过。单弧增加粗采样去抖，降低弯曲与方向一致性门槛，仍排除集中尖角、交叉、闭合和明显反向曲线。

回归样本覆盖浅弧、不完整圆弧、圆角顶点、标准及不等长尖角、弯曲箭头边，包含旋转、倒序、缩放、采样密度和手抖变化。千叠月暂时保留；用户表示后续可能删除，尚未执行删除。

### 开放曲线规则（随后确认并实现）

用户澄清重点是“一笔没有闭合”，并确认狐尾应作为明确符形之后的宽松开放曲线判定。当前先保留三角、雷法/千叠月/多圈、直线、严格箭头及圆的识别，再检查狐尾。狐尾不要求标准半圆或固定转角，允许先直后弯、弯曲不均匀和更长的开放弧。保留最低有效笔长和尺寸，排除近闭合、交叉、集中尖角、反复折返及过量绕行；额外在粗略弧线平滑前检查尖角，防止方形U被抹圆后误释放。

新增验证：自然不均匀曲线、先直后弯和250度开放弧可释放；留小缝的圆和三角保留原识别；多个同向尖角、折返与自交不转成狐尾。真实输入中的短弧误触不生成技能且不耗墨；持续小范围乱画不生成技能，墨耗沿用原账本。

按用户最新要求，先实现简单逻辑并查看效果。本次不增加技能局内升级；四级通过练习场选择。美术为程序化基础表现，后续可以继续调轮廓和演出。

## 已实现行为

- 单笔左右、上下和倾斜弧线均可识别，包含半圆、倒序与轻微手抖。
- 直线优先保持一字斩；尖角、闭合、反向曲线和多圈不被基础单弧抢占。
- 轨迹包围盒中心相对小狐决定瞄准。中心距小狐不到48单位时，复用上一有效施法朝向；每局初始向上。
- 小狐甩尾；光波从角色前方24单位生成，不在画符位置造成伤害。
- 月刃沿固定方向飞行；宽度垂直于飞行方向，前锋采用曲面扫掠判定，覆盖贴身敌人。
- 主波穿透多目标，每敌人同波主伤害一次。到射程后消散，并保留足够时间完成已经触发的回卷/镇压。
- Lv1伤害45、宽度150、射程400；Lv2伤害58.5、宽度172.5、射程420；Lv3伤害69.75、宽度187.5、射程440；Lv4伤害90、宽度210、射程460。
- 同级短长弧尺寸和基础伤害一致，识别置信度不放大或削弱基础伤害。既有修行与法宝伤害修正仍生效。
- 实时墨耗完全复用原账本：有效起笔后基础6点，加每720单位路径15点；成符返还10%，已有上限和最低净耗保持。没有新增一次松手扣费。
- 暂停、绘符慢动作、伤害、击杀、经验、进度和对象生命周期复用现有流程。

## 四级效果

1. **揽月**：白金弧刃、朱砂细拖尾，主波伤害与轻击退。
2. **狐尾扫月**：宽度和伤害增加，增加独立白色狐尾外层，强化击退。
3. **双尾揽月**：已命中的存活目标，在命中后0.18秒开始回卷，持续约0.20秒；拉向其命中位置附近的发射中轴。回卷不另加伤害，使用第二条内收尾影。
4. **九尾揽山河**：简化九尾狐灵起势、主波与弧形山海带；回卷约0.24秒后，对主波命中的存活目标追加一次35%主伤害的狐印镇压。没有第三次狐印伤害，也不伤害主波没扫中的旁边敌人。

Boss不被击退或牵引。精英击退按0.7倍、牵引按0.5倍抗性处理。位置约束在地图范围内，目标死亡则取消其附加事件。

朱砂灵笔在主波发射时收到一次既有ray主攻击快照，其独立副笔机制保持现状；Lv4镇压不会重复发出主攻击通知。聚风葫芦影响控制强度，灵狐尾羽仍按正式施法次数触发。照妖古镜不复制第二枚主波。

## 当前简化项

- 没有技能局内升级候选，遵从用户后续统一做的决定。
- 巨狐、尾部、山海绘卷和狐印采用简化矢量表现，尚未达到参考海报的复杂细节与美术完成度。
- 没有新建持续封印罩或额外终点区域；主要验证一笔发射、真实命中、回卷和单次镇压的基础手感。
- 后续进阶符术可能把部分S形、多圈识别成其他正式技能；基础单弧仍不得错误接管它们。这是其他任务的行为变更，不是本技能追加的范围。
