# 前线画境测试服

独立本地实验入口：`http://127.0.0.1:5175/?mode=frontline`。主菜单也有“前线画境 · 测试服”按钮。沿用原项目与资源，不需要另建账号或服务器；未部署到公网。

## 玩法

- 狐狸位于底部，普通小怪由上方进入并向下进攻；中间区域自由挥笔斩妖。
- 下方提供原画灵全部十种符卡。点选卡片，再点击战场，或直接拖到落点；符纸飞行后才生效。
- 月牙符在选定位置形成三月牙巡游阵。震墨、结界、纸虎、蟹将和游龙也支持指定落点。
- 墨蝶、雷符为附笔效果，点击直接开启；归元符直接恢复生命。天狐雷劫保留全场打击。
- 画境设置提供四章节、时段、每章五种精英、四章首领、五系画笔等级和成长、补绘封印、断链、收火、自由画龙。
- 打开画境设置暂停战斗；关闭后继续。沿用画灵试验的免伤、无限符卡规则，便于测试手感；暂不接入正式关卡成绩。

## 开发与验证

运行 `npm run dev -- --port 5175 --strictPort`，打开上述入口。

`npm run test:frontline` 检查上方刷怪、底部追踪、投放延迟和位置、暂停与编辑冻结、章节内容、重置清理、旧模式隔离。`npm run test:hualing` 检查原画灵内容。`npm run build` 检查类型与正式构建。

实现主要分布在 `src/gameplay/frontline.ts`、`src/ui/frontline.ts`、`src/rendering/frontline.ts`，通过 `Game.frontlineTest` 隔离布局和投放行为。

## 章节与视角补全

- 四章切换常驻顶部：落日妖谷、鲸梦浮海、星河天宫、雪眠巨兽；切换同时使用对应完整画卷、怪物、精英和首领。
- 保留完整背景比例、时段和环境动效，取消顶部裁切、不透明地板和梯形透视。
- 五系画笔等级、击杀升级进度、画笔升级和自选等级常驻顶部。新章节初次进入先领悟一次，后续击杀自动触发升级，各章独立保存成长。

## 厚纸偶美术 V1

前线画境独立使用 15 种厚纸偶普通怪物，包含纸边、叠层明暗、统一符签、足部接触阴影，以及分离的翅膀、脚、耳朵和尾部动作。原画灵、正式山海关卡继续使用原素材；图集缓存与对象池按版本隔离。

重做前线震墨的墨浪、朱砂弧片、暖金边缘和飞散符纸；九尾结界改为九符护阵、墨底和九道尾纹；补充斩击受击碎纸、召唤落点，并统一雷笔为暖金色。游龙、月牙及召唤主体继续沿用现有资产。新层只读取真实技能时钟与命中事件，不改变伤害、碰撞范围、成长或符卡规则。

`npm run test:frontline` 同时验证十五种角色的有限轮廓、关节动画、静态几何、特效预算、暂停清理，以及绘制不修改战斗数据。

## 厚纸山海美术 V2：五项统一

- 狐狸：前线独立的正面纸偶主角，五层尾部、符衣、面具、围巾与铃铛；沿用原施法、受击、庆祝等动作控制器。
- 战场：保留四章远景，中央增加低对比纸面过渡和少量边缘石片，符卡区有独立墨色底托，场景保持平直。
- 符卡：十种统一彩绘纸符图标和叠层卡框，包含选中、生效、忙碌状态。
- 技能召唤：游龙换为纸偶龙首；月牙、纸虎、蟹将补充与动作同步的纸边和厚度；天狐雷劫使用纸狐法相；其余沿用 V1 的墨浪、结界、暖金雷笔和碎纸反馈。
- 精英首领：二十种精英使用共享关节轮廓的厚纸侧边和等级纹章；四章首领使用统一纸色、纸边和解剖部件标记，保留原拆招位置与关节动作。去掉重复首领血条，修正入场横幅与操作指令重叠。

边缘材质与原网格共享变形几何，静态召唤轮廓只绘制一次；无全屏模糊滤镜。不改变战斗伤害、碰撞和成长规则。

画境设置中的“暂停击杀升级”保留当前笔法等级，关闭自动悟道弹窗，便于连续观看技能和召唤表现；自选等级入口仍可操作。

## 九尾结界、天狐雷劫恢复与狐群冲阵

恢复原九尾结界的完整九尾狐灵、法阵和环绕小狐狸，以及天狐雷劫的天狐法相、云、卷轴、符纸与三轮落雷。新增绘制回归测试，防止美术模式将大招隐藏或替换为空壳。

前线技能栏首格新增“狐群冲阵”。点击即可从主角前方召唤九只结界同款小狐狸，短暂成形后依次向上扇形冲锋，使用连续碰撞检测，每只对同一目标只命中一次。单只基础伤害34，一波对精英最多200、首领最多8%最大生命；冷却4.2秒，测试场不耗墨或库存。暂停和升级时冻结，切章、重开、离场清空。其他模式不加入此卡，原十种符卡全部保留。
