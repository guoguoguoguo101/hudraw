# 《灵狐绘卷》进阶符术系统完整开发任务书

## 一、任务目标

在现有《灵狐绘卷》游戏工程中，一次性新增并整合三种进阶符：

1. **九霄雷诏**：连续折线雷法。
2. **千叠月**：S形及连续反向曲线狐尾攻击。
3. **缚妖咒**：连续绕圈、螺旋缠绕与束缚。

这三种技能属于全新的「进阶符」类别，与现有「基础符」并存。

要求完成：

- 进阶符统一识别机制
- 与基础符的识别兼容
- 进阶符永久解锁机制
- 沿绘制轨迹施法
- 墨水消耗与资源平衡
- 技能Lv1–Lv4成长
- 程序化矢量特效
- 战斗伤害、击退、控制
- Roguelite局内升级
- 万象符录图鉴接入
- 必要的调试工具及测试

**必须实际修改代码，不要只提供设计方案。一次性完成本次任务范围，不拆阶段。**

# 二、项目背景与技术规范

项目名称：《灵狐绘卷》

类型：

- 微信小游戏 / 抖音小游戏
- 竖屏2D动作生存
- 自由画符施法
- Roguelite随机成长
- 国风剪纸矢量插画

角色：小白狐，身有朱砂灵纹。

美术风格：

- 东方剪纸
- 山海画卷
- 朱砂符箓
- 白金灵光
- 层叠云纹
- 程序化矢量特效

主要配色：

- 象牙白：#F5EAD7
- 朱砂红：#C63F36
- 暖金：#D9AC61
- 墨黑：#20252A
- 深绛红：#7D292E

技术上必须遵循当前工程实际架构。

项目此前使用过JavaScript生成SVG/Path矢量图形，也讨论过Cocos Creator。请先检查当前代码库，不要假设目前仍然使用特定渲染方案。

优先复用现有输入、墨水、时间、战斗、技能、渲染与升级系统。

不得无故重建系统。

主要技能视觉尽量采用程序化Graphics、Path、Mesh、Shader或项目现有矢量组件，不以新增PNG序列帧作为核心实现。

# 三、符术体系分类

## 3.1 基础符

现有基础符包括：

- 直线：一字斩
- 单弧：揽月狐尾
- 箭头：箭矢符
- 圆形：护身结界

具体以代码中已实现的实际名称为准。

基础符的规则：

**识别形状 → 扣除墨水 → 狐狸施法 → 生成标准化招式。**

同等级技能的尺寸由技能配置决定，不随玩家笔迹尺寸无限变化。

## 3.2 进阶符

新增：

- 多折线雷法
- 连续曲线千叠月
- 连续绕圈缚妖咒

进阶符的规则：

**识别结构 → 保留并解析有效轨迹 → 扣除墨水 → 沿笔迹生成技能攻击或控制。**

具体而言：

- 雷法保留有效折点与路径段。
- 千叠月保留有效反向弯曲段。
- 缚妖咒保留旋转中心、绕转方向与有效圈数。

不能只识别进阶符，然后丢弃轨迹信息，最后播放一个与笔画无关的普通固定攻击。

## 3.3 全部符术均为单笔操作

游戏目前只支持一笔绘制、松手识别。

本次必须保持：

- 一次按下开始绘符。
- 连续移动采集轨迹。
- 松手表示本次绘符完成。
- 对整条轨迹进行识别。
- 根据识别结果释放一个对应符术。

不实现双笔符。

不实现多次抬手拼符。

不将一次连续画符拆成多个独立技能自动释放。

# 四、统一手势识别架构

## 4.1 总体要求

需要把基础符与进阶符纳入统一手势分类流程。

建议按照结构特征识别，而非对图片做严格模板匹配。

基础流程：

```text
玩家按下
  ↓
记录原始轨迹
  ↓
去噪 / 平滑 / 等距重采样
  ↓
特征提取
  ├── 路径长度
  ├── 起终点距离
  ├── 闭合程度
  ├── 有效尖角
  ├── 折角方向
  ├── 连续曲率
  ├── 曲率反转
  ├── 绕转圈数
  └── 自交与局部重叠
  ↓
生成各符形候选及置信度
  ↓
比较候选
  ↓
确定唯一符形
  ↓
检查解锁与施法条件
  ↓
扣除或结算墨水
  ↓
执行相应技能
```

## 4.2 不允许简单使用固定优先级覆盖一切

不能只写成：

```text
有2个折角 → 雷法
有2个弯 → 千叠月
有1圈 → 圆形
```

必须综合分析结构。

特别是：

- 折线与箭头
- 连续曲线与单弧
- 圆形与螺旋
- 螺旋与连续曲线

这些类别会存在冲突。

建议各类别分别给出识别置信度，并加入必要的几何约束。

当结果非常接近时，不要随机选择技能。

应提供明确的失败或纠错反馈，并通过自动化轨迹样本测试优化。

# 五、进阶符一：九霄雷诏

## 5.1 基本信息

技能ID建议：`thunder_edict`

类别：进阶符 / 多折线

职责：路径攻击、连锁伤害、区域压制。

操作：玩家一笔画出连续交替方向的尖角折线。

例如：

- 横向Z形
- 纵向Z形
- 闪电形
- 多个连续折角组成的锯齿线

## 5.2 识别规则

核心要求：

**至少2个连续交替转向的有效折角，构成至少3段有效直线。**

例如：

```text
左转 → 右转            有效
右转 → 左转            有效
左转 → 右转 → 左转     有效
右转 → 右转            不满足标准雷法结构
```

这里的左转、右转指相邻有向线段的转向符号，而不是笔迹在屏幕上的绝对左右方向。

识别参数建议：

- 有效折角转向幅度至少约40°。
- 折角两侧线段均需达到最小有效长度。
- 忽略微小抖动。
- 剔除过短的尾段。
- 允许线段长度不同。
- 允许整体旋转。
- 不要求完全匹配标准闪电图标。

阈值应配置化，并根据设计分辨率和实机输入调试。

### 箭头冲突

一个有效折角的 `>` 仍属于基础箭头。

两个及以上有效折角才可能归类雷法。

如果存在短尾回折、明显重叠或不合格结构，不应通过凑折角数量强行触发雷法。

## 5.3 玩法机制

玩家画完折线后，小灵狐引动雷符。

雷电沿玩家绘制的有效路径依次推进。

有效折点可以产生明显的雷击爆发。

建议规则：

1. 沿路径产生一道细锐白金雷带。
2. 雷光按玩家绘制顺序向前推进。
3. 经过敌人时造成伤害。
4. 有效折角位置产生局部雷击。
5. 同一敌人在单次雷法中受到的命中次数设置上限。
6. 最后一段雷光自然消散。

整个施法应该有沿线推进的动态感，而不是所有折点同时爆炸。

## 5.4 Lv1–Lv4

### Lv1：引雷

- 支持基础多折线路径。
- 沿有效路径释放细锐雷光。
- 有效折点产生小型雷击。
- 每次施法最多计算3个有效雷击节点。
- 以快速伤害为主。

美术：细白金雷光、少量朱砂符印，干净利落。

### Lv2：奔雷

- 最多计算4个有效雷击节点。
- 雷带宽度略微增加。
- 折点命中产生轻微连锁。
- 连锁只作用于附近有限目标。

美术：雷带外层增加少量卷云，符纸沿路径飞行。

### Lv3：雷诏

- 最多计算5个有效节点。
- 各有效雷击节点形成短暂的雷纹残留。
- 相邻节点之间可形成持续极短时间的雷链。
- 命中附带轻微麻痹或短硬直。

美术：金色符诏、朱砂印记、雷网与云气协同。

### Lv4：天狐雷劫

- 最多计算6个有效节点。
- 雷电沿路径贯穿后，引动终极雷诏。
- 巨大的灵狐虚影短暂显现。
- 山海画卷局部展开。
- 沿整条有效雷法路径发生一次强化雷击。
- 追加一次有限范围的终极爆发。

美术：

- 白金劫雷
- 金色符诏
- 朱砂边纹
- 云海卷气
- 山海画卷
- 巨大狐灵虚影

不要做成科技激光、电路板或霓虹电流。

## 5.5 节点上限

节点上限是为了防止玩家无限折线刷雷击次数。

如果玩家画出超过当前等级上限的折角：

- 不继续增加雷击节点。
- 可以适度使用路径采样或节点合并，保持整笔轨迹视觉连续。
- 超出部分不得触发无限额外伤害。
- 绘制界面应尽可能提示有效节点已达到上限。

不能通过刻意缩短多个折角实现无成本大量雷击。

# 六、进阶符二：千叠月

## 6.1 基本信息

技能ID建议：`moon_wave_chain`

类别：进阶符 / 连续曲线

职责：连续范围攻击、狐尾连击、轻度控制。

操作：玩家一笔画出S形或连续反向弯曲的波浪线。

例如：

- 竖向S
- 横向S
- 倾斜S
- 多个连续S
- 连续平滑左右摆动的波浪线

## 6.2 识别规则

核心结构：

**至少两个足够明显、方向相反的有效弯曲段。**

不能把一个单弧因为手指末端抖动就识别成千叠月。

识别建议：

1. 对轨迹做平滑处理。
2. 计算连续曲率。
3. 检测曲率符号反转。
4. 合并噪声导致的微小曲率反转。
5. 提取有效弧段。
6. 对每段检查长度和弯曲幅度。
7. 至少存在一次真正的有效曲率反转。
8. 排除明显尖角折线与围绕同一中心持续转圈的螺旋。

不要求用户画得像标准英文字母S。

## 6.3 玩法机制

一笔连续曲线，对应一次完整千叠月施法。

**多个弯曲段属于同一张符，不是多张单弧符。**

玩家画完后：

1. 小灵狐释放第一道狐尾月刃。
2. 根据有效弧段依次释放后续狐尾斩击。
3. 狐尾攻击方向依照各弧段的局部几何方向变化。
4. 命中目标造成连续伤害。
5. 最后一段可以附加轻微回卷或定向收束。

本技能与基础揽月狐尾的区别：

基础单弧：生成一道固定尺寸的弧形光波。

进阶千叠月：沿玩家实际连续曲线组织多段攻击。

## 6.4 多段攻击与墨耗

玩家画一个S，可以形成2个有效弧段。

玩家连续画两个S，可以形成4个有效弧段。

但不能无限增加攻击次数。

建议：

- Lv1最多2段。
- Lv2最多3段。
- Lv3最多4段。
- Lv4最多5段。

超过上限的有效弧段不产生额外攻击次数。

每个有效攻击段的单次伤害低于基础揽月狐尾的单次完整攻击，连段完整命中则获得较高综合收益。

但不能让所有连段都稳定命中同一个敌人并造成无上限叠伤。

## 6.5 Lv1–Lv4

### Lv1：双月连斩

- 最多2段狐尾斩。
- 依有效弧段顺序释放。
- 第二段方向与第一段形成反向弯曲感。
- 造成连续伤害。

美术：两道白金弧刃依次展开，少量红色尾影。

### Lv2：三尾逐月

- 最多3段。
- 狐尾形态更加明显。
- 后续攻击范围略微提升。
- 连续命中同一目标时附加短暂硬直。

美术：狐尾月刃、红白丝带、少量金色纸焰。

### Lv3：千叠回月

- 最多4段。
- 连续狐尾攻击后产生一次回卷效果。
- 将受击敌人轻微收向最后一道有效攻击段的中心附近。
- 回卷不应无限聚怪。

美术：多道狐尾依次出现，末段演变成红白卷带向内收束。

### Lv4：九尾千叠

- 最多5段。
- 巨大白色狐灵虚影显现。
- 依实际绘制曲线发动连续狐尾月刃。
- 最后一段转化为宽大的九尾回卷。
- 对连续命中的敌人进行一次终结打击。

美术：

- 白金狐尾弧刃
- 朱砂红流带
- 多尾分层
- 巨狐虚影
- 山海卷纹
- 终结狐印

不能把5段攻击简单做成5张相同图片依次旋转。

每段应该体现不同弧线段对应的攻击方向，同时控制视觉强度。

## 6.6 与两次基础弧线的区别

必须保证千叠月具有独立价值。

连续两次基础弧线：

- 可以分别瞄准。
- 单次伤害更稳定。
- 可以独立控制释放时机。

一次千叠月：

- 一次绘符连续发出多段攻击。
- 根据曲线组织攻击方向。
- 连续命中具有额外硬直或末段收束。
- 更适合处理沿路径分布的敌群。

进阶符的优势是攻击结构与控制价值，不应该仅仅是单体DPS翻倍。

# 七、进阶符三：缚妖咒

## 7.1 基本信息

技能ID建议：`spirit_binding`

类别：进阶符 / 连续绕圈

职责：区域限制、定身、聚怪与辅助输出。

玩家通过单笔持续绕圈形成束缚符纹。

可以支持：

- 向内螺旋
- 向外螺旋
- 连续绕转的圆形曲线

不要求玩家绘制标准的数学阿基米德螺旋。

## 7.2 识别规则

必须与基础圆形明确区分。

基础圆形：

- 一次绕转。
- 起终点接近。
- 整体轮廓接近闭合。

缚妖咒：

- 累计绕转角度明显超过一圈。
- 有足够的有效路径长度。
- 轨迹围绕相对稳定的中心持续旋转。
- 至少达到设定的最低有效圈数。

建议初始识别条件：

- 有效累计绕转至少约1.5圈。
- 绕转中心相对稳定。
- 不以局部抖动形成的微小圈数计数。
- 允许半径逐渐扩大或缩小。
- 不要求完美闭合。

具体阈值需通过轨迹测试确定。

特别注意：

**玩家画一个标准圆，应触发基础圆形符，而不是缚妖咒。**

## 7.3 玩法机制

玩家画完后：

1. 在有效旋转中心生成一枚朱砂束缚符印。
2. 沿螺旋笔迹展开金色符链。
3. 符链向中心逐步收紧。
4. 将有效范围内的妖怪轻微牵引。
5. 对普通妖怪施加短暂束缚或定身。
6. 结束时符链碎裂消散。

缚妖咒应突出控制，不是单纯把螺旋改成高伤害旋风。

## 7.4 绘制圈数与效果

圈数可以影响技能表现，但必须设置上限。

例如：

- 1.5～2圈：正常束缚。
- 2～3圈：略微扩大作用范围或延长束缚。
- 超过有效圈数上限：不再叠加控制强度。

高圈数需要消耗更多墨水。

不能通过在很小的位置疯狂绕圈来无限叠加控制。

最低墨耗应高于基础圆形符，并根据有效绘制长度结算。

## 7.5 Lv1–Lv4

### Lv1：缚妖索

- 生成一条基础朱砂符链。
- 对小范围内目标造成轻微牵引。
- 普通敌人受到短暂束缚。
- 以控制为主，伤害较低。

美术：细金线、朱砂结绳、少量符纸。

### Lv2：缠灵锁

- 增加有效控制范围。
- 符链收紧速度提升。
- 增加第二层符纹。
- 对被缠住的敌人造成少量持续伤害。

美术：双层金红符链、纸符节点、旋转云纹。

### Lv3：镇妖缚阵

- 增加束缚持续时间。
- 收紧后形成短暂镇妖符阵。
- 敌人在符阵中受到移动限制。
- 对精英怪按已有控制抗性处理。

美术：朱砂主符印、内外两层符链、山海云纹。

### Lv4：万缚镇妖

- 大型白狐虚影短暂显现。
- 多条金红符链沿螺旋方向展开。
- 将有效范围内敌人逐步向中心收束。
- 落下一枚大型镇妖印。
- 完成一次范围镇压伤害。
- 镇压结束后解除束缚并进入正常战斗。

美术：

- 巨大狐灵
- 朱砂符链
- 金色旋纹
- 剪纸符印
- 山海卷纹
- 镇妖印章

不得做成普通高科技旋涡、黑洞或持续发光的圆盘。

# 八、墨水系统统一规则

本次三个进阶符都沿用现有墨水机制。

基础原则：

**有效路径越长，消耗的墨水越多；但是输出能力不能无限增长。**

建议统一公式：

```text
墨水消耗 =
max(
  符形最低墨耗,
  有效笔画长度 × 单位长度墨耗
)
```

参数必须可以按技能类别配置。

例如：

- 雷法：按路径长度计算，并限制有效折点数。
- 千叠月：按路径长度计算，并限制有效弧段数。
- 缚妖咒：按路径长度计算，并限制有效绕转圈数。

同时必须：

- 与现有实时绘制扣墨机制兼容。
- 防止二次扣墨。
- 防止低于最低墨耗时免费施法。
- 防止重叠涂抹无限刷伤害。
- 防止超长绘制导致逻辑异常。
- 保持绘制过程的流畅性。

对于高级符，允许通过复杂手势获得独特能力，但不直接按照笔画长度无上限增加伤害。

# 九、进阶符永久解锁

## 9.1 初始状态

玩家开始游戏时默认掌握现有基础符。

新增的三种进阶符默认处于未解锁状态：

- 九霄雷诏
- 千叠月
- 缚妖咒

## 9.2 解锁规则

需要为三个进阶符提供独立永久解锁状态。

建议字段：

```ts
advancedSpells: {
  thunderEdict: false,
  moonWaveChain: false,
  spiritBinding: false
}
```

实际使用项目现有存档结构与ID约定。

必须支持：

- 未解锁
- 已永久解锁
- 本局已习得
- 本局技能等级

这四种信息不能混淆。

## 9.3 未解锁行为

识别器应能够识别未解锁的进阶符形。

但未解锁时：

- 不释放进阶技能。
- 不自动改判为基础符。
- 显示简短的“尚未习得”反馈。
- 不额外扣除技能施法费用。
- 绘制过程中已消耗的墨水按现有机制处理。

需要避免玩家明明画了S，却被错误识别为一笔普通弧线。

## 9.4 解锁入口

优先检查项目是否已经有：

- 万象符录
- 灵狐修行
- 永久成长
- 符术收藏
- 成就解锁

将进阶符解锁接入现有永久成长系统。

如果对应系统尚未完整实现，至少提供可持久化的解锁状态和可测试的解锁入口。

不要为了本次三个技能大规模重建整个局外成长UI。

## 9.5 局内获取

永久解锁代表玩家已经掌握该符形。

Roguelite局内是否习得对应符术，由现有技能获取与装备规则决定。

建议进阶符在局内随机奖励中出现，玩家获得后以Lv1开始使用，并可升级到Lv4。

对于永久解锁但本局没有装备的技能，应提示“本局未习得”，不能自动释放。

# 十、绘制期间的时间机制

当前设计为绘符期间战斗进入慢动作。

目标参数：

- 普通绘符世界速度约20%。
- 普通绘符允许约2秒真实时间。

进阶符比基础符复杂，必须测试2秒是否足够完成有效手势。

本次优先沿用现有普通绘符时间机制，不擅自延长全局慢动作时间。

如果确实需要给进阶符独立绘制时限，应采用配置项，并确保：

- 绘制状态有明确结束条件。
- 时间到不会随机释放错误符术。
- 不影响输入采样率。
- 不导致其他符术的时间规则变化。

# 十一、程序化视觉规范

## 11.1 核心理念

**SVG或矢量图负责形状，程序负责动态演出。**

三个进阶符的美术必须各有视觉特征。

### 雷法

视觉关键词：

- 锋利
- 断折
- 白金雷光
- 符诏
- 雷网

运动特点：

沿折线快速推进，在节点爆发。

### 千叠月

视觉关键词：

- 柔韧
- 连续
- 狐尾
- 月牙
- 红白卷带

运动特点：

多道狐尾沿曲线依次展开，末段收束。

### 缚妖咒

视觉关键词：

- 缠绕
- 收紧
- 朱砂符链
- 金色旋纹
- 镇妖印

运动特点：

逐步盘旋、收紧、束缚、封印。

## 11.2 Lv1–Lv4视觉成长

- Lv1：简洁清晰，主体轮廓完整。
- Lv2：新增一到两种重要视觉元素。
- Lv3：成熟的技能结构，具有完整控制反馈。
- Lv4：技能结构发生变化，加入巨大狐灵、山海绘卷或大型符印。

不能只通过增加粒子、扩大图片、提高亮度来区分等级。

## 11.3 性能要求

- 路径统一采样。
- 路径简化和缓存。
- 限制有效攻击节点。
- 复用特效对象。
- 控制绘制次数和Draw Call。
- 高等级限制粒子与符纸数量。
- 尽量避免运行时反复解析复杂SVG字符串。
- 同时施法数量多时支持视觉降级。
- 技能释放和碰撞更新保持稳定。
