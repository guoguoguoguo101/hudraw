# 《灵狐绘卷》进阶符术：确认方案与实现说明

版本：v0.2 · 2026-10-14。已按本轮确认范围实现；验证结果见末节。

## 1. 已确认范围

基础符固定四种：直线（一字斩）、圆（圆形护阵）、单折角（箭头符）、单波/单弧（揽月狐尾）。

进阶符三种：多方向交替折角（九霄雷诏）、连续反向弧段（千叠月）、多圈绕转（缚妖咒）。均为一笔操作，不需要多次抬手，不自动拆成多个基础技能。

九霄雷诏改造原有Z雷符，保留内部z标识与已有统计关联。判定不再匹配Z模板；Lv1–Lv3调整，Lv4继续使用原FoxThunderUltimate演出，巨狐、山海绘卷、落雷主体没有改动。Lv4战斗判定也沿真实笔迹，原演出会在实际折点显示落雷反馈。

本轮先做识别、战斗效果、Lv1–Lv4和验证入口。正式局内技能获取/升级、永久解锁条件/存档/门禁留到后续；当前可直接试用Lv1，不新增“未解锁”阻止验证。图鉴保留category与unlockIntegrationPending标记作为后续接入位置，不宣称永久成长已经完成。

墨水沿用已有长度账本；绘符3秒、世界0.5倍速度不变。

原始任务书：[进阶符术-原始任务书.txt](./进阶符术-原始任务书.txt)。本稿以用户后续确认优先，取代v0.1关于完整局内成长、最低费用补扣及图鉴研习入口的建议。

## 2. 已核查架构与兼容范围

TypeScript + PixiJS，共用浏览器和微信逻辑；逻辑画幅720×1280。复用InputController、Game、TalismanSpellFactory、固定战斗步长、墨水账本、程序化Graphics、图鉴与练习场。

已有一字斩和圆阵的五级不改为四级。基础揽月仍从狐狸身边发射固定月刃，按绘制位置瞄准；进阶攻击直接使用画符处的世界轨迹，二者机制不同。现圆阵包含护身/远处镇妖模式，保留固定边界与结束外推；缚妖咒主动沿螺旋收紧聚怪。

工作区原有未提交修改保留。星形遗留类型/直接测试调用保留，但没有开放手绘识别，也不是第五种基础符。

## 3. 识别边界

有限点清理、轻平滑、等距采样后，共用独立结构分析；结果保存长度、折点位置/路径进度、弧段/曲率方向、绕转中心/圈数/半径。最多192分析点，输入仍使用现有400点上限。

### 基础弧与千叠月

短弧和半圆继续归单弧；轻抖、短尾钩不增加攻击段。千叠月至少两个独立合格、平滑、反向弯曲的弧段，既要“有两个弧度”，也要方向相反，不能只是一个大弧划得更长。

初始条件：每段长度至少70逻辑单位、累计弯曲至少35°、偏离/弦长至少0.15；过滤小曲率反转、尖角和近闭合段，弧段需要覆盖整笔主要部分。浅S不强制进阶，明显乱画不截取局部凑符。

### 单折角与雷法

单尖角箭头保留；雷法至少两个方向相反的有效折角，至少三段有效线。有效臂至少28单位、尖角约40°起，联合局部转角集中程度区分尖角与平滑波浪。允许非标准Z、不等长、旋转和反向书写。同向连续折角不直接成雷。

### 单圆与缚妖

单圈闭合圆仍是圆阵。持续同向围绕一个中心、累计约1.5圈以上、有效尺度足够才成缚妖；支持内外螺旋、正反书写和重叠绕圈，不要求完美闭合。

有效半径下限30单位，排除极小绕圈；中心附近不稳定角度不计圈数；检查方向一致性和局部尖角，避免五角星的绕转被误判为束缚。圈数阈值带约0.025圈的数值采样容差。

基础识别原有置信度保留，进阶结构合格时给稳定置信度。目前采用结构排除与确定判定，没有实现全符形候选分数竞争；实机边界反馈不足时再扩展，不声称已有完整候选打分系统。

## 4. 九霄雷诏：沿线推进、节点封顶

雷光按书写顺序约0.55秒扫过整条有效原笔迹；按推进区间做线段扫掠碰撞，不根据敌人危险评分自动选择主攻击目标。折点取轻平滑后的真实几何位置，不跟随敌人移动。

Lv1–Lv4最多3/4/5/6个内部折点节点。超上限按路径分布抽取节点，整笔线仍保留，后半路线仍能命中沿线敌人。

同一敌人一次施法：路径最多伤害一次（本级伤害参数70%），节点/局部连锁合计最多一次（30%）；Lv4路径强化或末端爆发共享一次35%追加预算。多折角、重描、节点范围重入均不无限叠伤。

等级伤害参数45/67.5/99/157.5，长度和置信度不加伤害。额外笔迹可能覆盖更多不同敌人，也会增加墨耗，但不会刷同一敌人的伤害次数。

- Lv1引雷：细白金雷带与小节点符印。
- Lv2奔雷：雷带加粗、云纹；节点实际命中后，90单位内至多连锁两个邻近目标，连锁仍占节点预算。
- Lv3雷诏：节点符纹短残留、强化沿线结构；命中节点产生短硬直，Boss不受该硬直控制。
- Lv4天狐雷劫：原巨狐和山海落雷演出；实际路线强化与末端75单位小范围爆发，每敌共用一次追加命中标记。

朱砂灵笔在主路径扫完后只接收一次真实命中快照，沿用最多三目标的追加规则，不逐节点重复触发。

## 5. 千叠月：连续曲线扫掠

独立wave符形与WaveState；不是调用多次基础揽月。

Lv1–Lv4最多2/3/4/5段，按书写顺序用前N段。超过上限的笔迹不增加攻击次数，末段回卷锚点取最后有效攻击弧段的中心。

每段0.24秒依次沿真实曲线扫掠，局部切线决定命中推力，曲率方向决定狐尾带展开侧；方向反转与弧段形状直接体现在程序化曲带上。

等级伤害基准45/58.5/69.75/90；每敌每弧段最多一次，单段最多0.65倍基准，整笔基础连段共用1.3倍上限。Lv4终结额外0.35倍，整体最高1.65倍。不会因5段全部扫中同一敌人线性变成五倍伤害。

- Lv1双月连斩：两段反向狐尾带依次展开。
- Lv2三尾逐月：三段、更多分层细线；同一目标跨段连续命中时短暂限制移动。
- Lv3千叠回月：四段，末段回卷；只收束本次命中过、仍在末段120单位附近的敌人，每普通目标最多45单位位移。
- Lv4九尾千叠：五段、短巨狐九尾轮廓；末段150单位内回卷，普通目标最多70单位位移，回卷结束一次终结狐印伤害。

精英牵引/移动限制按0.5倍，Boss不位移。首段远处敌人不会被跨屏拉到末段。施法暂停、死亡清理和到期均跟随技能实例。

## 6. 缚妖咒：聚怪与短束缚

复用未开放spiral标识，替换遗留旋风执行与展示。中心取实际绘制绕转中心，不吸附优先敌人。作用半径取实际轨迹尺度与等级上限的较小值。

Lv1–Lv4半径上限120/140/160/180；有效圈数上限2/2.5/3/3；普通敌人基础束缚0.6/0.8/1.0/1.2秒。圈数在1.5圈到上限之间至多增加20%控制时长，不增加伤害。

每敌基础技能伤害预算上限12/18/24/36；实际Lv1只有30%首段低伤害，Lv2/3有少量持续伤害，Lv4末印补足剩余预算。不是高伤害旋风。

普通敌人渐进牵引速度45/55/65/75单位每秒，总位移最多50/65/80/95单位；已有聚风葫芦可增强牵引速度，但不突破总位移上限。精英控制时长与位移0.5倍，Boss不位移/定身。

捕获时设置“本次控制时长+1秒”重复控制间隔，结束后至少1秒恢复窗口；另一张束缚不能在控制中刷新本目标，防止永久锁怪。同一目标进出范围不重复首段伤害。

束缚限制移动，保留原攻击读条；低伤害不反复重置AI攻击状态。死亡目标清掉锚点。技能实例被移除后立即不再限制移动。

- Lv1缚妖索：朱砂细链、金线与中心小印。
- Lv2缠灵锁：双层收紧符链、少量符纸、低持续伤害。
- Lv3镇妖缚阵：更久束缚、强化镇妖印与目标连线。
- Lv4万缚镇妖：巨狐九尾轮廓、多层金红链、大印一次低伤镇压。

## 7. 墨水、时间、图鉴接口

不加最低费用补扣，继续实时长度收费：达到约50.4单位后，毛耗为6+15×付费长度/720；成功返还10%、最多7、净耗至少6。长轨迹更贵，能力上限固定；无二次收费。

## 11. 雷法手画容错修正（2026-10-14）

用户补充确认：至少两个方向相反的有效折角，可以更多；不要求标准Z。总长度不足，或者在很小的位置密集折线，不能仅靠折角数量触发。S目前手感合适，本次不改其弧段长度、曲率和覆盖阈值。

雷法初始门槛：平滑有效总长度至少140逻辑单位、每条有效折线臂至少28单位、整体跨度至少70单位。跨度指轨迹包围盒对角线。逻辑单位随画幅统一缩放，不是设备物理像素。

旧版逐个要求每个简化折点合格，并要求极小局部窗口内很尖，导致自然圆角、抖尾和采样差异整笔失败。现在合并短肩部、去微抖、按整笔直线段占比区分折线与连续曲线，保留至少一组方向相反的明显折角；短小肩部不能增加节点，也不会使正常折线一票否决。重描和多次自交仍排除。

雷法阈值独立配置在src/input/thunder-geometry.ts的THUNDER_GESTURE；共享advanced-geometry只调用该分支，S和螺旋分析保持原样。

新增tests/thunder-gesture.ts：150组圆角/抖动/疏密采样样例，同时经过recognize与真实InputController采样；另外检查长度不足、局部密集折线、单箭头、半圆、同向折角与S旋转样例。已加入npm test。

连续六弧段回归样例改为更舒展的曲线，符合现有曲率上限；没有为了这个样例放宽S识别参数。

本轮验证：150组样例的识别与真实InputController采样均通过，npm test全套通过；S的长度、曲率及覆盖阈值没有调整。
