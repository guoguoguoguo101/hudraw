# 画龙 · 水墨金骨灵龙

2026-10-24。按用户选定的第二版设计图 B 实现：`assets/concepts/hualing-dragon-redesign/B-ink-gold-spirit-dragon-v01.png`。

## 表现

- 米白与暖纸色的五条渐变宽度笔带组成龙身，保留真正的带间空隙，沿实际输入路径铺开，不使用原红色实心细管。
- 细金线与稀疏金色脊骨贯穿龙身，四肢采用两对关节细爪；外侧鬃流与少量纸金碎屑提供方向感。
- 龙头为一次构建的矢量轮廓：长吻、细眼、分叉金角、多层米白鬃毛、长须和小朱砂额纹。图标复用同一龙头。
- 行笔时半透明预览，松手后 1.5 秒沿路径展开，随后从尾端逐步收去并淡出。沿用原伤害时序、路径和数值。
- 不改变相机抖动设置，不添加满屏雾、泛光或新的背景贴图。AI 参考图用于构图与形体，运行时采用矢量绘制，纸纹复杂度按移动端画幅简化。

## 预算与生命周期

路径弧长及二分采样复用，正常最多 96 段，低画质最多 54 段；头部静态图形复用。渲染对象随最多八个现有技能效果加一份行笔预览复用，效果结束进入空闲池。

画灵逻辑回归用于确认路径命中与伤害去重继续保持；网页及微信构建另行检查。实体手机性能仍需真机验证。


## 第二轮：整龙游动与自然粗细（2026-10-24）

按用户反馈替换“龙头到终点停住、尾巴收短”的模式。运动模型以固定物理身长沿轨迹平移，头尾一起前进；超过笔迹终点后继续沿切线滑行并轻微向侧方转弯，随后全身统一淡出。短笔对应较短的龙，长笔身长封顶；沿用既有路径内伤害时机，离场动画不额外造成伤害。

躯干改为连续的解剖轮廓：尾尖→细长尾段→腰腹→肩部→收窄颈部。去掉贯穿全身的平行笔带，仅在颈鬃与尾端保留少量飞白。金色脊鳞与前后两对爪跟随固定的身体位置，不再随剩余路径挤在一起。

龙头使用本轮内置 image_gen 重新生成的透明贴图，原图为 `assets/vfx/ink-dragon/head-v2-source.png`，生产资源为 `public/art/ink-dragon-head-v2.png`。生产图缩至 512 方形并开启缩小滤波，减少手机显示时的碎亮噪点；同一贴图由网页和微信适配器加载、复用，微信打包显式复制。

动态预览：`screenshots/ink-dragon-v2/dragon-swim-v2.webm`；录制脚本 `scripts/record-dragon-preview.mjs`。`tests/dragon-motion.ts` 验证身长恒定、头尾同时移动、终点继续前行、整体淡出与肩颈尾的粗细关系，已接入画灵专项测试。


## 笔长一比一修订

按用户反馈去掉额外的 0.52 比例、115 最小值与 350 身长上限。龙身弧长直接等于这次有效笔迹的实际弧长；当前技能已有 1100 的笔长预算，继续由技能控制。整条龙在游动和离场过程中保持这个长度。长笔适当提高采样段数，正常最多 180 段、低画质最多 90 段；脊骨细节数量单独受控，不影响身长。
