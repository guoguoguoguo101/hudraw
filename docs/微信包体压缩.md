# 微信预览包体超限修复

原包约4748KB，超出开发者工具报出的4096KB限制。主要占用为三个章节的矢量场景数据，约2.6MB；运行代码约1.15MB。

`npm run build:wechat` 现在将场景JSON打成 gzip + base64 的JSON封装，微信资源适配器读取后同步解压，保留原有文件路径和全部轮廓数据。网页仍直接使用原始文件。使用 fflate 同步解压，无网络资源依赖，不删除章节或降低图片质量。

修复后完整 `wechat-game` 目录约3824KB（3.73MiB），余量约272KB；具体大小以每次构建输出为准。构建会递归统计整个目录，达到4MiB时失败，并列出最大的文件。现有项目AppID与开发者工具设置保留。

验证：`npm run test:wechat`，包含三个章节解压结果与源数据完全一致、整个目录小于4MiB，以及无unsafe-eval条件下的微信模拟启动、场景切换和战斗渲染检查。模拟检查不代替微信真机预览。

使用开发者工具重新编译已导入的 `wechat-game`，再执行预览。
