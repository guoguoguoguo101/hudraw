# 鲸梦浮海与星河天宫 · 参考图重制

2026-10-24。仅接入画灵试验场，正式章节的开放状态不变。

## 场景

- 鲸梦浮海：青碧浅湾 / 珊瑚绯潮 / 月下鲸歌。沿用用户参考图的鲸背山海、亭阁瀑布、两侧珊瑚与开放水面，增加动态水纹、游鱼、雾气与夜间海珠。
- 星河天宫：月白云庭 / 朱金日宫 / 靛金星阙。沿用用户参考图的星仪、主殿、云桥、悬岛与开阔庭院，增加云流、轨道微光、星芒与日宫余烬。
- 每章三个阶段使用同一张已确认构图的不同配色与环境动效，保留自动流转及手动预览；并非六张独立绘制的背景。
- 鲸海互动为潮纹、断缆、聚珠；天宫为星图、摘星、破轨。复用原有补画、路径切割、接触收集与符卡拖放规则。

## 实现与资源

两张用户原图及两张 ImageGen 小怪参考图保存在 `assets/concepts/chapter-reference-v02/`。离线将参考图减色、轮廓化，保留大轮廓和主要建筑，剔除细碎纹理。SVG 母版留在同目录供检查；运行数据是原生绘图路径，不包含内嵌图片。少量金线、鲸眼、云雾及水纹另行程序绘制。

运行时按需加载 `public/art/chapters/` 下两份路径数据，绘制后缓存静态层；不会加载参考 PNG 或使用 DOM / SVG 图片解析。路径以 1/8 像素精度、差分变长编码保存，减少数据体积。小怪共用矢量造型数据及几何缓存，保留浮动、呼吸、受击与攻击姿态。

美术重建：`python scripts/build-chapter-vectors.py`，离线依赖 Pillow、VTracer。运行游戏不需要 Python。重建操作不会替换用户原图。

## 小怪

当前版为折鳍游鲤、潮灯水母、朱纹纸蟹、折翼星鳐、云纹悬铃、逐星纸燕。参考 `assets/concepts/paper-spirits-v04/reference-v01.png` 的新设计，由原生 Graphics 部件手工绘制；不再使用旧版密集轮廓的小怪造型。以朱砂、青绿、靛蓝、米白和少量金线统一配色，保留折面、镂空剪纹和纸片结构，去掉腮红与圆润卡通笑脸。鳍、尾、伞带、钳、翼与铃穗分别摆动，眼睛有克制的眨动。

六种小怪各自保留摆游、脉动、横移、绕行、顿进和折线移动，生命与伤害不因外观修改变化。前两轮的复杂纸妖与圆润纸灵参考分别归档在 `chapter-reference-v02` 和 `cute-paper-spirits-v03`，均非当前运行造型。

新章节顶部使用紧凑标题和章节/阶段栏，画笔成长与自定义调级收进“试演”，右侧保留暂停，减少主景遮挡。第一章与其他游戏模式继续使用原界面。

## 分层动态

鲸鱼从场景轮廓中拆出为独立遮罩图层，原位以远景底色衔接，在缓存后缓慢浮动、轻摆。海面增加向下流动的多层波纹、扩散水环、鱼群与移动云雾。天宫的星仪三层环以不同方向和速度转动，背景云层横移、庭院边缘近云浮动。全部跟随画灵活动时钟，手动预览景色时仍有环境动画；暂停时冻结，切章清理图层。

`check-hualing-chapters.mjs` 比较实际画面，要求两个章节在两秒内都有可见变化，并检查暂停后的画面冻结（允许 GPU 两级色值舍入误差），同时采样缓存后的渲染耗时。结果只代表本机浏览器，不能作为实体手机帧率结论。

## 验证入口

- `npm run test:hualing`：玩法回归、章节切换、怪物、矢量数据与源轮廓精度检查。
- `npm run test:hualing-chapters:preview`：实际点击、挥笔、暂停、调级面板、切章、三阶段、375/390/430 画幅、重复重建及普通模式隔离。可通过 `LINGHU_PREVIEW_URL` 指定服务，默认端口 5177。
- `npm run build`、`npm run build:wechat`、`npm run test:wechat`。

画面及验证数据位于 `screenshots/hualing-chapters/`。浏览器检查不等于微信实体手机性能与触屏验收。
