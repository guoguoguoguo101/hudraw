# 画灵 · 雪眠巨兽

2026-10-24。沿用鲸梦浮海、星河天宫的章节切换、三阶段画卷、场景互动、符匣和独立纸妖机制。

## 入口与玩法

打开 `/?mode=hualing`，点击顶部第四项「雪眠巨兽」。支持自动展开，也可点击三个阶段手动预览。

| 阶段 | 场景互动 | 完成后的符 | 释放效果 |
| --- | --- | --- | --- |
| 霁雪初眠 | 分笔补亮眠山脊纹，沿山脊和角枝绘制 | 眠山符 | 半径 135 内 120 点范围伤害 |
| 风雪入梦 | 挥笔划断三道缚梦霜锁 | 裂霜符 | 左右 260、上下 65 范围内 160 点横斩伤害 |
| 月照苏灵 | 笔尖分别碰触五缕山灵息 | 灵息符 | 半径 205 内 210 点范围伤害 |

符凝成后拖出符匣、放到战场释放。手动预览与自动阶段切换保留已绘进度和未使用的符。收齐五缕灵息后，山兽眼睛变为金色睁眼，脊背亮起细金灵纹；用掉灵息符也保持苏醒，重现灵息或重置章节后清除。

三种章节纸妖：抱雪团貂、霜羽纸鸮、霜纹岩甲。使用纸片关节绘制，沿用真实敌人 AI、血量和受击机制，具有不同的接近节奏。当前章节初始布置四只纸妖，与最新的其他章节一致。

喷墨、阔锋、泼墨、留墨仍可在「试演」中自由设置关闭／Lv1–Lv4；原有画龙、画山、裁纸、画符、雷符均可使用。留墨保留落笔时的枫染／银电／共鸣样式和真实持续伤害。切换章节会清理旧符、墨痕、附符、召唤物和敌人，重新开始保留所选章节。

## 美术与资源

背景以之前选中的雪眠巨兽概念为参考，通过 OpenAI imagegen 生成干净原稿，再转换为原生矢量轮廓。原稿及完整提示词在 `assets/concepts/snow-chapter-reference/README.md`。

- 冷白雪峰、黑松、眠兽山脊和暗灰石坪；不加入寺庙建筑。
- 晴雪、风雪、月夜三套颜色，随画卷时间渐变。
- 巨兽头角独立缓存，小幅呼吸起伏；战斗石坪保持稳定。
- 程序绘制纸片落雪、鼻息白雾、山间薄雾、风线、月轮和睁眼细节。
- 动态增强：6.8 秒一轮呼吸带动胸颈伸展、头角抬落；到达吸气峰值后吐出分层白雾，角上碎雪间歇飘落，左侧远山有小纸鸟飞过。睡眠中眼皮轻颤，苏醒后每约 7.4 秒眨眼，脊背金纹脉动。眼睛、鼻息起点和金纹都跟随巨兽变换，战斗石坪不移动，暂停冻结全部动态。
- 霜锁、山灵息、灵息符与释放涟漪使用冰蓝、银白及少量古金。
- 运行时只加载 `public/art/chapters/snow-landscape.json`（2200 条路径，956435 字节）；PNG 和 SVG 仅用于制作，不加入运行时纹理。
- 可执行 `python scripts/build-snow-chapter.py` 重建雪章，不会覆盖鲸海、天宫资源。微信构建也包含雪章轮廓。

章节配置集中在 `src/gameplay/hualing-chapters.ts`；互动规则在 `scene-seal.ts`；背景动画在 `src/rendering/chapter-landscape.ts`；雪系敌人形象在 `paper-chapter-spirit.ts`。
