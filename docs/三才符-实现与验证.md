# 三才符：操作原型实现与验证

2026-10-15。以用户最新确认与[方案核对稿第0节](./三才符-方案核对稿.md)为准。

## 已实现的行为

保留现有开放尖角追踪符箭，新增独立 `sancai` 技能；闭合三角识别后按几何面积与周长分成小飞刃、大阵法。两形态共享 Lv1–Lv4。

小飞刃从狐狸位置飞到所画三角的重心，途中碰敌不提前分裂；在落点旋转，再分裂出左、中、右三枚子刃。主刃抵达与旋转时长均确定，子刃使用线段扫掠碰撞、独立接触记录与固定射程结束，不递归分裂。

大阵法使用拟合的实际三顶点，超限时围绕重心等比例封顶。松手后的首个模拟步选择阵内离重心最近的存活敌人；聚势时更新该目标位置，出剑时锁定终点。目标在出剑前死亡或出阵则朝阵心聚斩；原本无目标时不重新远处索敌。

根据后续试玩反馈，大阵聚斩后持续保留：朱砂底纹、三顶点剑印、双层内边、沿边流光、缓慢转动的阵心符纹；Lv4 还保留低透明度狐灵和剑门。四级总持续时间为4／4.5／5／6秒，包含起阵、首次聚斩、持续阶段、收尾和淡出。Lv3、Lv4 的裁切在结束前发生，不再在起阵后立即结束。沿用战斗时间，暂停冻结，画符慢动作照常影响阵法；当前不增加周期攻击或伤害。

当前没有生命伤害、破甲、易伤、失衡、打断或裂锋印。新技能不触发灵笔副笔或尾羽额外攻击，不因古印留持续阵、不因古镜复制另一组攻击；原技能法宝行为保留。墨水与慢动作继续由原有系统处理。

### 四级差异

- Lv1“三才初成”：到点旋转两圈、三向分裂；三剑阵持续4秒。
- Lv2“三锋展势”：到点旋转三圈、子刃射程增加，可穿过首个敌人；剑路加宽，阵法持续4.5秒。
- Lv3“裂影裁卷”：更大的分层符锋和多重尾迹；阵法持续5秒，结束前追加一次短促裁切。
- Lv4“山海三才”：更大的朱砂符锋、落点四圈旋转；三座剑门、狐灵虚影持续6秒，结束前裁卷收尾。

等级切换会改变真实行为配置和程序化表现，不只改名字。当前正式战斗手绘可用 Lv1，Lv1–Lv4 通过练习场切换验证。正式局内获取/升级、永久解锁与存档接入尚未完成，仍是后续需求；不能将练习场四级切换当作正式成长系统。

## 游戏里怎么试

打开开发预览，进入练习场。底部第二行最右为“三才符”；点击名称选择 Lv1–Lv4，再点“飞刃”或“阵法”分别试放。也可以在战场自由画一笔闭合三角，右下角画小三角就会往右下落点投掷。

两个按钮都经过真实示例轨迹识别，不强改识别结果；手绘同样走原有输入控制器、墨水账本与统一施法工厂。临近闭合、已满足识别条件时，金色小三角/朱砂大三角候选轮廓提供预览。未满足结构时不提前显示成阵成功。

## 文件与参数

- `src/input/triangle-geometry.ts`：循环闭合轮廓、凸包上的最大面积三角拟合、三边误差、面积质量、长度/周长比与大小分类；`TRIANGLE_GESTURE` 集中配置。最大面积拟合替代原先逐点删除的算法，避免圆角样本丢失真正顶点。支持任意顶点、边中起笔、旋转与反向。
- `src/input/recognizer.ts`：在既有清理/分析之后、开放进阶返回之前验证闭合三角；保留其他结构识别规则，不修改圆阵模式。
- `src/gameplay/sancai-config.ts`：四级速度、大小、旋转圈数/时长、子刃射程/穿透、剑路宽度、裁切阶段与时间。
- `src/gameplay/sancai.ts`：两形态状态与生命周期、落点移动、一次分裂、子刃扫掠、阵内选敌及锁定，不调用伤害接口。
- `src/rendering/sancai.ts`：单次施法一个可复用 Graphics，符纸刃、旋刃弧线、剑印、剑门、狐灵与裁卷，使用现有战斗时间。
- `types.ts`、`config.ts`、`spells.ts`、`game.ts`、`skill-levels.ts`：共享技能状态、配置、行为入口、等级及无伤害法宝隔离。
- `glyph-samples.ts`、`practice-cast.ts`、`ui/practice.ts`：两形态真实示例及共用等级选择。
- `rendering/view.ts`：渲染接入、重开清理和候选轮廓；`progress/catalog.ts`：独立技能身份与四级描述，标记解锁待接入。
- `tests/sancai.ts`：识别、动作时序、无伤害、资源、等级及清理测试；已加入 `npm test`。
- `scripts/check-sancai.mjs`：真实浏览器鼠标画符、两形态四级及按钮验证。

试玩反馈后的识别参数：最短边30、最低周长180、最低面积900；同时达到面积14500及周长600才为大阵。闭合缺口允许绘图区宽度14%和有效笔迹长度16%两者中的较小值；平均/最大边缘误差允许最长边7.5%／14%，拟合三角至少覆盖凸包面积60%。因此自然圆角、弯边、小缺口和较小三角更容易触发；圆/正方形仍需被排除，重复描画不能刷尺寸。最大重心到顶点距离300、最大面积60000，二者取更严格的等比例缩放，不增加第三种形态。以上均为逻辑单位，与设备物理像素无关，仍需手机调参。

主刃不按固定攻击射程提前分裂，而是到实际画符重心；当前绘制区域本身限定可选落点。旋转时间、速度、分裂角度35°、子刃射程和阵法节奏均可在配置中调整。

- 三才符10组自动测试通过：含486组圆角/弯边/缺口/抖动/尺寸/采样组合及反向，共972个自然三角样本；两规模、任意接缝/顶点/边中起笔、其他符形区分、双门槛与封顶、四级抵达/旋转/一次分裂、穿透、无伤害/法宝隔离、阵内目标锁定/出阵/空阵、持续时间/收尾/暂停/到期清理、真实输入扣费/超时/干笔、30/60/120 FPS、对象复用和连续施法清理。
- 浏览器重跑通过：430×932视窗下8次真实鼠标闭合三角、24张阶段画面、3条圆角/缺口/抖动自然笔迹、8种等级与形态按钮组合；持续阶段状态与剩余秒数提示正确，敌人血量不变，页面/WebGL报错为0。已目视检查Lv1与Lv4持续阵法截图。截图与实际验证结果在 `screenshots/sancai/verification.json`。
- 现有进阶符8组、月刃9组、核心战斗28组及追加划斩、灵笔7组、进度、画符9组、墨水14组、练习场测试通过。
- TypeScript 检查、生产构建、平台边界检查与微信小游戏构建通过；生成微信测试包不等于微信真机验收。
