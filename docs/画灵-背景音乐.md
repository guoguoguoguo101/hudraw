# 山河轻吟 · 画灵背景音乐

2026-10-24。原创八小节五声音阶小曲，72 BPM，约 26.67 秒循环；拨弦主旋律、低音与极轻的五度和声，短反射提供空间感。代码离线合成为 22.05kHz 双声道缓冲，首次播放生成一次，复用循环；尾音跨循环首尾写入，避免截断。

只在画灵活动时播放。背景音乐使用独立音量，接入现有声音开关；暂停、失焦、切后台和返回菜单淡出，恢复时从已播放位置续播，反复重开不叠加。浏览器首次需点按激活音频。微信沿用现有 Web Audio 支持，无音频能力时保留原有容错。

验证：`node scripts/check-hualing-music.mjs`，包括实际浏览器单一循环源、暂停/继续、静音/恢复、重开、返回菜单、旧模式隔离与失焦；离线生成检查有声、余量和循环接缝。样本及数据在 `screenshots/hualing-music/`。合成音色为拨弦风格，不是古琴实录。
