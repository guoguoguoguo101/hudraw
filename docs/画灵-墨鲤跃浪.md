# 喷墨四级 · 墨鲤内置冷却版

当前方案已移除“喷中蓄势、下一笔释放”。所有等级均为冷却转好后，轻轻挥笔就喷鱼；持续画同一笔也会按内置冷却再次触发。不要求命中，不要求松手，不按画线长度蓄力。停笔不会自动连喷，冷却照常恢复；下次动笔即可触发。

| 等级 | 形态 | 内置冷却 | 基础伤害 |
|---|---|---:|---|
| Lv1 游墨 | 一条小墨鲤 | 0.85秒 | 飞行35 |
| Lv2 双鲤 | 两条分流墨鲤 | 0.8秒 | 每条40 |
| Lv3 领游 | 一条大鲤领两条小鲤 | 0.95秒 | 大鲤90、小鲤各24 |
| Lv4 跃浪 | 巨鲤穿敌，末端拍成大墨浪 | 1.4秒 | 飞行145、墨浪110 |

实际碰撞随鱼的体型变化，飞行扫掠路径内所有目标，每条鱼对每个目标只命中一次。Lv4墨浪为独立的一次前方范围攻击。松手重画不能绕过内置冷却；暂停和升级面板同时冻结冷却、飞行与伤害；重开、调级或切换章节清理活动墨鲤。

## 测试入口

画灵任意场景 → 自定义等级 → 喷墨Lv1至Lv4 → 继续试画。面板底部「墨鲤试喷」可直接切到Lv4并清零冷却。

## 美术与音效

保留参考图 `assets/concepts/spray-ink-creatures/three-evolutions-v01.png` 的黑墨鱼身、朱砂鳍尾、骨白腹部与金色鳞纹，运行时使用分层绘制与可复用角色池。低等级小鱼到高等级巨鲤有明确尺寸差异，Lv3小鱼向两侧分流，Lv4独有末端墨浪。出鱼音效随等级变重，墨浪有单独拍击声。概念图不进入微信资源包。

最多保留6条活动鱼，正常冷却下同时至多3条；角色池重复使用，轻盈画质减少装饰碎片。
