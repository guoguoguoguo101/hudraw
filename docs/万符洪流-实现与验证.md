# 万符洪流 · 试验画境大招

实现方向：采用 `assets/concepts/talisman-barrage-2026-10-21/01-万符洪流.png` 的连续纸符洪流，使用程序化纸符、朱砂纹、翻卷流带与命中印记；未把整张概念图覆盖在游戏上。

## 入口与操作

主菜单 →「符术交互 · 试验画境」→ 右下「万符洪流 · 定向」。普通关卡和旧练习场不开放。

1. 点按钮进入瞄准，显示浅扇形方向预览。
2. 在地面按住/拖动调整方向；方向从狐狸指向触点，松手锁定。距离狐狸小于32逻辑单位的点按或在画境外松手不发射；再次点按钮取消瞄准。
3. 蓄势0.35秒后，沿固定方向持续连射4秒。期间可正常画符，普通符术不改变已锁定方向。
4. 发射停止后，已飞出的符纸继续飞行，最后一张结束后可再次试放。测试场不消耗墨水，不要求能量或冷却充能。

与焚山煮海互斥，避免两个大招抢占绘制输入；「清空残痕」会同时取消两个大招。暂停/切后台/回魂冻结时间，沙漏冻结敌人但不延长连射。重开或退出清除瞄准、飞行纸符、待结算命中和演出。

## 伤害与边界

参数位于 `src/gameplay/talisman-barrage.ts`：七路、总夹角约24°、间隔0.08秒、共50轮/350张逻辑纸符，速度1050、射程820、单张基础伤害5、最多穿透3个目标。同一纸符对同一敌人只结算一次；同一轮对单敌最多两次伤害，因此单次大招基础伤害上限500，避免近身或体积大的目标同时吃满七路。实际伤害受命中数、目标移动和原有Boss护甲/破甲影响。

逻辑使用1/120秒固定步长和沿运动路径扫掠碰撞，帧率或长帧不会漏发、重复发射或越过敌人。纸符只沿发射方向飞行，不索敌转弯，也不触发直线残痕、折射、朱砂副笔或再次生成洪流。

运行时伤害纸符数量上限128，实际飞行峰值约70；视觉使用共享几何和固定池。当前最多显示170个装饰纸符，低画质仅保留其中64个并减少卷云与碎片；装饰不额外伤害，逻辑保持一致。

## 第二版视觉迭代

根据「符纸太均匀、缺少万符齐发感」的反馈，2026-10-21改为：

- 六种长短、切角、残边、拖尾各异的符纸，混合黄纸朱砂、红底金字与金箔符。
- 按纸符身份固定随机种子，大小、间距、翻转、摆角与折叠独立变化；不再整排等大、同角度飞行。
- 前后分层的装饰符群采用650–1500逻辑单位/秒的不同速度，分批聚散、交错绕流。真实伤害纸符仍沿原方向飞行，攻击规则不变。
- 五股朱砂/金色流带、两条外侧长符带、卷云回旋、移动敕令印、细墨线与火星；部分卷云位于符群前景，避免完全被纸符遮挡。
- 起手收符旋涡、狐狸脚下旋转符印与墨色飘带；起手冲击、收尾压力波，以及按命中位置合并的朱砂撕裂与飞纸碎片。
- 演出完全读取大招自身时间，因此暂停、回魂与清空继续保持原语义。共享静态符纸几何，固定实例池，不逐帧新建符纸对象。

第一版对照截图：`screenshots/talisman-barrage/v1-stream-430.png`。最新截图沿用同目录 `stream-*`、`sustain-*`、`charge-*` 与 `low-*` 文件名。

### 视觉收简

后续根据「丝带太长、遮挡且杂乱」反馈：移除两条贯穿攻击路径的外侧长丝带，以及五股连续填充流带；仅保留65–120单位长、低透明度的断续风痕。卷云从11处减至3处，移动符印从3枚减至1枚；火星减少，纸符附带的双条长尾改为12单位短尾。装饰符群适当减量、缩小前景大符并降低背景符透明度，保留大小错落和翻转感。伤害、方向和持续时间不变。

## 验证

- `npm run test:talisman-barrage`：九组专项检查，覆盖入口、瞄准与单指取消、无墨水副作用、持续发射与清理、方向范围、每轮伤害上限、30/60/120FPS与长帧一致、穿透顺序、暂停/回魂/停时及正常绘符共存。
- `npm run test:talisman-barrage:preview`：真实浏览器菜单和按钮操作，430×932、375×667、390×844三种画幅，瞄准、蓄势、连续伤害、正常画符、暂停、停时、重复试放、低画质和模式隔离。
- 全量 `npm test`、浏览器构建 `npm run build`；画面与验收记录保存在 `screenshots/talisman-barrage/`。浏览器记录单独保留原站点缺失favicon的提示，不当成游戏脚本/WebGL错误。
