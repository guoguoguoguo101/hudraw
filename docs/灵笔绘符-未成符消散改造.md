# 未成符反馈 · 断符消散

2026-10-14。此规则覆盖前期“散墨化焰、流焰笔痕、散墨狐焰”的设计与实现。

## 当前行为

成功识别直线、圆、箭头、Z等正式符术：沿用现有技能，原始手绘轨迹及时退场；技能释放不以命中敌人为条件。圆阵、高级斩击、追踪箭及雷符没有重做。

有效但未成符：只有原笔迹约0.12秒的快速淡出。无曲线火焰、自由笔痕、地面印记、爆散技能、碰撞体、直接或持续伤害。不会创建技能实例、发出施法事件、触发法宝或记录成符。

灵墨继续使用现有按绘制长度即时扣费的规则：未成符结算保留已经消耗的灵墨，不获得成符返还、不加失败惩罚。极短误触立即清除轨迹，结算为零消耗。系统取消及后台恢复等既有规则保持原样。超时仍只结算一次，按住期间不能再次释放。

绘制过程的笔迹保持现有表现。未成符不凝亮、不生成新的曲线特效；成功成符的原迹退场参数限制在0.08～0.15秒。调节区删除流焰、爆散、沿曲线攻击及散墨命中范围参数，仅保留画笔、笔迹、起收与配色。

## 清理与防护

- 删除`src/input/free-stroke.ts`和`src/gameplay/free-stroke.ts`，移除轨迹拟合、散墨几何与攻击解析。
- 移除`FreeStrokeRenderer`、它的渲染层与对象池，以及输入／技能中的`freeStroke`字段。
- 输入缓冲在松手后0.15秒清理，包括原始轨迹、干笔尾迹、采样时间及累计长度记录。调试状态也不保留已退场的轨迹图形。
- 未成符不会进入技能工厂；直接尝试创建失败符术会被工厂拒绝。
- 对旧`ink`技能增加防御处理：停止生命周期、不执行伤害；正式符形渲染器拒绝它，旧施法事件也不触发狐狸施法、环境动效或施法音效。
- 未新增消散对象、延迟攻击队列或定时器；消散仅使用已有画笔Graphics并逐帧清空／复用。

`ink`内部标识现在仅代表“未成符结果”，不是可释放技能。其旧攻击配置已清零。
