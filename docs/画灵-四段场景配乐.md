# 四段场景配乐

2026-10-24。当前界面的四个入口为自动、落日、起风、夜色；自动是串联景色的演示模式。

- 自动《山河流转》：约 81 秒，依次采用落日、起风、夜色的八小节段落。
- 落日《丹霞归舟》：72 BPM，约 53 秒。温暖拨弦、低音、五度和声及笛感对答。
- 起风《风过千山》：86 BPM，约 45 秒。较流动的旋律、分解伴奏、轻鼓和短对答。
- 夜色《月下听溪》：60 BPM，约 64 秒。缓慢笛感主旋律、稀疏钟音、柔和和声。

三段独立曲各有十六小节，后半段以低八度乐句和钟音收尾变化增加呼吸；音色为程序合成，不是真实乐器录音。各曲双声道、尾音循环，输出留出打击音效余量。

界面切换自动或三个阶段时切换曲目，约 0.9 秒淡入淡出；每曲保存播放位置。暂停、静音、离开、失焦停止，恢复续播。反复切换及时回收淡出源，最多缓存两首缓冲，减少移动端内存驻留。

验证：`node scripts/check-hualing-music.mjs`，覆盖四首离线样本、输出余量、接缝、实际阶段切曲、重复启动、暂停/静音/返回菜单/失焦及旧模式隔离。试听文件与数据位于 `screenshots/hualing-music/`。微信真机扬声器听感尚需实际试玩确认。
