# 功能灵宝 · 符术交互试验原型

2026-10-20。依据 `docs/design/三件功能灵宝-效果与交互方案.md` 接入三件原型；本轮已实现代码、界面、绘制与微信构建。

## 入口与操作

主菜单进入「符术交互 · 试验画境」，技能栏上方新增灵宝栏。三件全部直接可用，无需装备、卸下或选择槽位。「强化」可直接选择三种培养阶段进行效果验证。

- 引路灯笼：按住灯笼图标，拖到指定地面后松手放置；拖动时显示灯笼和范围预览。拖回栏内、无效落点或触摸取消都不消耗次数，也不会误画普通符。默认每局三次，五秒或三次攻击后熄灭。普通怪在范围内改变接近和攻击目标；精英、鬼王与已经开始的攻击不被强行改向。Lv2 范围 180→220；Lv3 熄灭后短暂减速。
- 停时沙漏：点图标，敌人、攻击蓄力与刷怪停止三秒，玩家攻击继续。默认每局两次；Lv2 为 3.5 秒，Lv3 结束后短暂缓速。灯笼的有效寿命在停时内保留，普通画符减速不能延长停时。
- 回魂灯：致命伤自动进入回魂，三秒内先横后竖描完两笔，恢复 30% 生命并保护两秒；Lv2 恢复 40%，Lv3 再给四秒护盾。每局一次。允许抬手、补画，失败才结算死亡。

「重置」清除灵宝临时状态、恢复次数与生命，保留阶段。「致命受击测试」通过同一致命伤流程触发回魂，只有此测试会绕过演武免伤；用尽机会时会正常失败，可从结算页重开。

为联测时间功能，自由试符的原有操作区补了「焚山煮海」按钮。仍为四秒随笔、两秒后统一爆炸。沙漏不延长大招；回魂时整个大招暂停，成功后从剩余时间继续。

当前不接入正式关卡的开局选装、掉落和培养存档；灵宝只在「符术交互 · 试验画境」启用，原自由试符和正式试炼不显示灵宝栏。

## 逻辑与界面

- `src/gameplay/functional-relics.ts`：培养参数、次数、放置、诱敌、停时与回魂描画。
- `src/gameplay/game.ts`：致命伤拦截、回魂状态、敌我时间分离、己方技能时钟、练习受击与重置接口。
- `src/gameplay/ai.ts`：实际接近和攻击灯笼、一次攻击只扣一次耐久；冻结时仍结算己方施加的感电伤害。
- `src/ui/functional-relics.ts`：全量灵宝、拖放、阶段切换、主动图标、倒数和回魂卡片。
- `src/rendering/functional-relics.ts`：参考 AI 设计图的程序化灯笼、沙漏、莲灯、吸引范围、停时印记和冷色罩层。
- `src/bootstrap.ts` 与 `src/rendering/view.ts`：输入路由、切后台、暂停与时钟衔接。

进入回魂不先产生失败事件或结算收益。暂停、切后台和回魂不会在后台偷耗时间。回魂输入独立于普通符形识别、不扣墨、不推进连击。隐藏的灵宝栏不会拦截失败页或暂停页按钮。

## 验证

- `npm run test:functional-relics`：十三组逻辑测试，覆盖入口隔离、全部可用与次数、放置取消、诱敌与耐久、纸鸦单次攻击、精英/鬼王抗性、停时与刷怪、长帧边界、减速、自然回墨边界、大招配合、回魂成功/失败/暂停/退出和培养参数。
- `npm run test:functional-relics:preview`：真实鼠标进入符术交互、强化预览、拖放灯笼、停时中画符、回魂两笔、失败重开、窄屏菜单，覆盖 430×932、375×667、390×844；截图与记录位于 `screenshots/functional-relics/`。
- `npm test`：新功能和现有技能、几何交互、进度、朱砂副笔、画笔及灵墨回归测试。
- `npm run test:wechat`：生产微信包的原生触摸模拟，检查灵宝拖放、三件直接可用、蓝色停时倒数、进入回魂、暂停继续与成功后回到 playing，继续检查旧技能、其他测试场和存档隔离。
- `npm run build`、`npm run build:wechat`：网页和微信构建。

微信模拟基于浏览器 wx 接口替身，尚不能代表实体手机的帧率、触摸舒适度和微信真机验收。
