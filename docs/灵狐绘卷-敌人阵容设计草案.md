# 《灵狐绘卷》敌人阵容设计草案

> 讨论稿。以下“新增”怪物只是设计，尚未进入游戏、图鉴或正式关卡。具体数值和名称需通过试玩确认。

## 1. 目前真正做出来的敌人

| 定位 | 名称 | 现有行为 |
| --- | --- | --- |
| 普通怪 | 墨团妖 | 缓慢接近灵狐，近距离预警后攻击；生命低，作为基础目标。 |
| 普通怪 | 纸鸦 | 较快地绕行，到一定距离后预警、直线俯冲；生命低。 |
| 精英怪 | 赤面鬼 | 慢速接近，生命较高，蓄力后近身重击；蓄力可被打断。 |
| 章节 Boss | 赤面鬼王 | 固定在场上，三阶段攻击；开场有护甲，第二阶段召唤墨团与纸鸦，第三阶段使用血月重击。 |

目前没有其他可正常遭遇的敌人。现有 180 秒试炼约在 90 秒召出鬼王；打败鬼王且守到结束才算通关。赤面鬼和鬼王不能只靠放大缩小同一张立绘来长期区分，后续应给鬼王独立的剪纸轮廓与阶段变化。

## 2. 战斗设计前提

灵狐目前固定在画面中央，玩家的主要操作是选择画符方向与时机。新怪不能要求走位躲避。每种攻击都要有清楚的预警，并至少提供一种稳定的应对方式：提前击杀、打断蓄力、用圆符护盾承受，或用合适方向的符术清除威胁。

同一关不要同时第一次介绍两种新怪；先单独认识，再混合出场。普通怪要靠行为而非单纯血量区分，精英怪要有可辨认的蓄力、恢复窗口和明显的击败反馈。画符轨迹、敌人预警与伤害提示在手机屏幕上必须分层清楚。

## 3. 第一章新增建议：三种普通怪、两种精英怪

加上现有阵容，第一章可形成 **5 种普通怪 + 3 种精英怪 + 1 个 Boss** 的基础怪物池。以下名字均可调整。

### 普通怪

| 暂名 | 战场职责 | 行为与玩家应对 | 首次建议出现 |
| --- | --- | --- | --- |
| 折纸蝠 | 成群的脆弱威胁 | 三只左右错位入场，先聚合再分批俯冲。单只容易击倒，观察入场方向后用一字斩横扫更有效。与纸鸦的单体绕行俯冲形成区别。 | 1-3 |
| 山灯灵 | 远处施压 | 在外围短暂停留，灯火逐渐变亮后对灵狐发出慢速咒火。可在蓄力时击杀或打断，也可用圆符护盾承受；预警线不与画符笔迹混淆。 | 1-4 |
| 墨甲虫 | 厚重的优先目标 | 缓慢推进，短时间缩进墨甲减少正面伤害，出甲后有恢复窗口。三角破甲特别有效，但其他符术仍能伤害它，避免强制玩家只画一种符。 | 1-6 |

### 精英怪

| 暂名 | 战场职责 | 行为与玩家应对 | 首次建议出现 |
| --- | --- | --- | --- |
| 裂面山魈 | 节奏欺骗 | 第一段短蓄力是佯攻，第二段红色蓄力才发动重击。两段有不同剪纸姿态；玩家可用三角破招，或在间隙清理小怪并补盾。不能做成没有提示的突然二连击。 | 1-7 |
| 祠灯咒师 | 目标取舍 | 停在远处给两只山灯灵增亮，并准备一次较长的中央咒印。优先击破咒师可解除增幅；也能清掉山灯灵后用圆符防守。召唤和咒印都有限次，防止无限堆怪。 | 1-9 |

现有赤面鬼仍是第一章第一个精英，安排在 1-5。三种精英分别考验“识别蓄力并破招”“看清真假攻击节奏”“在首领和随从间选择目标”。

## 4. 第一章十关的怪物推进

| 关卡 | 新认识的威胁 | 主要组合 |
| --- | --- | --- |
| 1-1 | 墨团妖 | 单种普通怪，学习画符与护盾节奏 |
| 1-2 | 纸鸦 | 墨团在前、纸鸦绕行 |
| 1-3 | 折纸蝠 | 纸鸦与蝠群的速度差 |
| 1-4 | 山灯灵 | 近身怪与远处蓄力怪，练习目标优先级 |
| 1-5 | 赤面鬼 | 首次精英，练习破甲或打断 |
| 1-6 | 墨甲虫 | 厚重目标与符纸时机选择 |
| 1-7 | 裂面山魈 | 佯攻、真蓄力与恢复窗口 |
| 1-8 | 无 | 已见普通怪组成妖潮，不再加入新规则 |
| 1-9 | 祠灯咒师 | 咒师、山灯灵与少量近身怪 |
| 1-10 | 赤面鬼王 | 现有三阶段 Boss 为基础，分波带回本章已学怪物 |

同一屏幕应限制精英和特殊预警的并发数量，具体上限通过手机试玩决定。Boss 战原则上不再同时放另一只精英；鬼王召唤的小怪要有上限和明确的清理窗口。

## 5. 后续三章的怪物方向

| 章节 | 普通怪的方向 | 精英与 Boss 的方向 |
| --- | --- | --- |
| 幽篁竹海 | 竹叶妖的扇形来袭、雾萤的延时显形、竹节卫的节奏性防护 | 竹影刺客考验预警判断；古竹守卫考验连续破招；终关守关者待具体剧情确定 |
| 血月妖祠 | 祭纸童的结队推进、骨灯妖的远处蓄力、血影蝠的阶段性俯冲 | 月蚀祭司改变咒印节奏；赤纹禁卫守护祭阵；终关围绕血月机制收束 |
| 星河天宫 | 星屑灵的散聚、云鹤影的多方向俯冲、星轨傀的定时防护 | 巡星使考验目标切换；镇宫石将考验破甲时机；终关整合星轨与云海规则 |

这些只是剪纸轮廓和战斗角色方向，不代表已经拥有相应美术、AI 或关卡。正式制作每一章时，再为每种敌人定义唯一 ID、攻击预警、被打断条件、数值、掉落经验、图鉴描述和测试场景。

## 6. 建议制作顺序

1. 先完成第一章三种普通怪的最小可玩行为与矢量剪纸轮廓，分别在单怪关验证可读性。
2. 再做两种精英，并和现有赤面鬼比较节奏，确保三者玩法不同。
3. 最后按十关配置出怪、检查符纸恢复和圆符护盾是否足以应对伤害。通过试玩调整预警时间、上限与波次，而非先填高生命值。
4. 每种敌人真正进入可玩关卡后，才接入百妖图鉴的真实发现、击杀与资料解锁。
