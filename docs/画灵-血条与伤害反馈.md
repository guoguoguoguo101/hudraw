# 画灵血条与伤害反馈

普通怪物显示骨金色细血条，受击时短暂提亮，朱砂色掉血残影稍后收缩。精英沿用原有专属血条。

伤害数字使用实际 strike.amount（含减伤、破绽增伤），普通命中为米白色，击杀为较大的金色；不把高伤害伪标为暴击。数字错位上浮，0.82秒内消失，同时最多32个，重复使用文字对象。暂停时停止数字与血条残影动画，退出或重新开始时清理。

实现：`src/rendering/combat-feedback.ts`，由 `GameView` 接收真实命中事件并驱动。未改变伤害计算、敌人血量、命中冷却及战斗速度。

验证：`node scripts/check-combat-feedback.mjs`。覆盖真实指针一笔多目标、每个目标的血条和30点伤害数字、25.5点精英减伤、48点破绽伤害、击杀配色、暂停、消退、对象数量上限和菜单清理。截图在 `screenshots/combat-feedback/`，包含375与430宽度。
