# 一笔多杀与连续击杀

2026-10-24。

## 规则

- 一笔从普通画笔实际落笔起到抬笔结束，记录该笔直接击杀数和活动游戏用时；无单笔时限。行笔中显示“一笔 ×N”，收笔后显示“一笔六斩 · 2.4秒”等结算，保留 2.6 秒。
- 延迟绘物、山虎和场景符卡等击杀可以续连斩，但不算当前普通画笔的一笔击杀。普通命中不计数，同一敌人不能重复计杀。
- 所有画灵击杀刷新 2 秒连斩窗口，从第二杀开始显示“连斩 ×N”和剩余时间。超时结算保留 1.6 秒，之后的新击杀从一重新开始。
- 3/5/8/12 杀提升字效档位，依次使用“锋芒初露 / 笔走游龙 / 一气破阵 / 一笔诛群妖”。每次跨档播放递进音阶，一帧跨多档仅播放最高档，避免声音堆叠。
- 暂停冻结全部计时；暂停/取消/越界会结束当前笔，保留已经实际造成的击杀及结算。定格妖潮不冻结计时。重开、重置和返回菜单清空记录。
- 当前仅画灵启用，不改变伤害、掉落、普通模式、墨量和正式成长。

## 视觉

参考 `assets/concepts/hualing-combo/reference-v01.png` 的 AI 设计图，运行时用矢量实现飞白墨底、朱砂印记、金色挑笔、米白题字、数字弹动和短暂纸屑。提示位于战场右上，两个统计分行；不接收输入，避免抢占画笔和符卡拖放。

## 验证

- `npm run test:hualing`：原画灵专项加六组连斩测试，覆盖两秒边界、跨笔/跨窗口、来源归属、重复击杀、真实输入、取消、暂停、定格、重置和旧模式隔离。
- `node scripts/check-hualing-combo.mjs`：真实鼠标一笔斩十二只、各档截图、抬笔用时、倒计时、暂停、重开、375/390/430 画幅边界与旧模式隔离。离线音频渲染验证四档音高递进、有声且单次不削波。
- 验证截图与数据位于 `screenshots/hualing-combo/`。这些是浏览器验证，未代替微信真机扬声器听感和触屏体验验收。
