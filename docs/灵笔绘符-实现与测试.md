# 灵笔绘符 · 实现与测试

**历史实现记录：未成符的流焰、散墨攻击及相关调节项已经取消。当前规则、清理范围和测试见[未成符消散改造](灵笔绘符-未成符消散改造.md)。下文保留前期实现过程，不作为当前未成符行为说明。**

2026-10-14。依据《灵狐绘卷-灵笔绘符系统改造核对稿》v0.2及用户确认实施。此次重点为特效、流程和可操作的测试入口，数值仍是临时测试值。

## 使用入口

- 主菜单 → 万象符录 → 灵笔收藏：四笔直接选用，选择保存到设备；完整画笔仅在收藏页展示。
- 主菜单 → 演武画境／自由试符 → 右下「画笔 / 特效」：切换画笔，调节笔迹、起收、流焰、爆散、灵墨预算和配色。用加减按钮修改，收起后画下一笔查看；提供恢复默认。
- 参数在当前游戏会话内保留，不单独持久化；已释放技能保存参数快照，不被后续修改影响。
- 配色提供预设色块。命中宽度、半径和灵墨范围的修改同步碰撞，其余调节为外观。
- 自由试符下方显示收笔倒计时与结果；重新打开调节区可查看上次结果、超时状态与散墨有效长度。
- 调节区可显示散墨命中范围。开发页按D，或通过已有手势调试入口，可查看原始点、分析点、识别结果、置信度、累计长度、有效灵墨、重描与结算状态；没有完美度或品质评分。

## 已实现行为

四笔均使用现有Pixi Graphics程序化剪纸几何，含收藏用完整笔身、山纹、符纸、飘带及云纹。战场为小型笔锋，笔迹由主体与亮芯两层组成，遵循各笔配色；皮肤差异集中于笔锋造型与配色，沿线装饰默认关闭。没有新增运行时SVG DOM或图片下载依赖。

起笔为小落点和涟漪，行笔统一为细实线与少量亮芯，旧迹保留可辨认轮廓；默认关闭沿线碎屑，去掉额外连接线和收笔符印／碎焰，保留短促提笔。松手后整笔短暂凝亮，再交给技能，原始轨迹默认0.10秒退场。普通直线从手绘短线中心向两端延展，在原有命中时刻前达到定长；曲线流焰去掉火舌和闪光，默认0.32秒消散。乱涂不整团凝亮，暗痕约0.06秒退场，收成两片小型爆散，默认0.35秒消散。

绘制上限3秒，战斗为50%速度；超时仅结算一次，等待原指针抬起。单指、UI隔离、取消及暂停沿用现有平台接入。长输入有界采样，同时记录累计移动和时间；散墨预算前缀单独保留，超额尾部不能转移攻击位置。

正式符形仍优先，整笔结束再释放。保留现有圆阵、技能等级和高级演出；一字斩复用已有中点定长路径，最低有效长度调为50逻辑单位。识别器额外校验平滑前后长度，避免来回涂抹被平滑成正式直线。

流焰使用12个控制点进行平滑、重采样为48点；宽度和弯曲受限，最终48点路径共用于绘制与碰撞。散墨爆散使用去重覆盖中心与有限半径。单敌单笔一次直接伤害、最多3敌，不随折返次数叠加；临时伤害为基础斩击的30%／20%。不升级、不复制正式法宝攻击，不推进正式施法连击与成就。

没有新增品质、完美度、评分或伤害奖惩系统；已有正式技能工厂的品质系数保持原实现。
