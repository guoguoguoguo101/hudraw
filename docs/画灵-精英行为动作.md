# 画灵精英行为动作

20 只精英沿用已认可的简洁剪纸造型与章节配色，按解剖部位绑定关节。每只使用 25 × 25 网格，在同一张缓存图片上进行平滑变形，不增加图片包体。

动作由战斗状态驱动：入场展开、待机呼吸、蓄力预备、实际释放时发力、反制后回弹、受击反馈、破招失衡、收势恢复，以及死亡折落淡出。暂停时沿用模拟时钟，重复绘制不会继续动作或累积变形。

- 赤骨伞姬：伞面先收后张，手臂与裙摆随释放回弹。
- 灯主、纸偶、负碑山魈、螟母：灯体鼓缩与流苏摆动、双臂牵线、背碑蓄力、上下翅独立拍动。
- 海章：蟹钳先抬后挥、水母伞盖收缩带动触须、蚌壳开合托珠、帆船摇摆、双鳐展翼。
- 天宫：举镜转镜、双袖牵织、钟身和钟舌错拍、举印落印、双刃蓄势挥斩。
- 雪章：猿身蹲起发力、灯笼摆荡、松树摇落、双鹿点头迈腿、骨甲张合。

场上的飞蛾、鳐、双鹿、帆船等攻击物也有翅膀、腿和帆的动态。碰撞、判定范围与反制规则沿用全卷交锋实现。

验证：`tests/elite-motion.ts` 验证全部关节、事件触发、暂停及变形边界；`scripts/check-elite-motion.mjs` 在浏览器逐只检查七种行为姿态、重复绘制、资源销毁与 WebGL 错误。底部原有五只精英召唤按钮可直接测试当前章节。
