# 画灵 Boss · 身体即招式

2026-10-26。本版取代固定标记解题：身体部位各自拥有招式、前摇、真实发射点、攻击轨迹和反制条件。来源定义在 `boss-anatomy.ts`，游戏生成攻击和画面显示都读取同一套部位坐标与关节变形。尾巴／手掌／鹿角等处的光效不是独立漂浮的装饰。

## 九尾焚天

狐王有九个独立尾关节和九个发射点，每轮按 1/4/7 → 2/5/8 → 3/6/9 三叠轮攻，各组内部间隔 0.23 秒，组间起始间隔 1.8 秒。共六枚金火和三道尾鞭，九尾都会出招。

金火必须在飞行亮环中横截弹道，沿着弹道追擦无效。尾鞭伸展后出现结点，必须沿箭头横断结点；提前擦尾巴无效。一笔有效跨度至少 42，判定只用实际笔尖中心线。每轮至少反制六个不同尾部，且断掉至少一道尾鞭；至少等九个尾部都完成蓄势，才能触发露心。可容忍少量漏招。

## 其余三章

| 章节 | 部位连招 | 必须完成的不同操作 |
| --- | --- | --- |
| 鲸梦浮海 | 左右蜃口交错掀潮、吐珠，潮心按节奏开合 | 横笔穿过亮色潮缝至少两次；抓住真实吐出的海珠，按住拖回张开的潮眼至少两次。任意划过浪墙或对闭眼送珠都不结算 |
| 星河天宫 | 双掌交替织出横纵金丝、放出星束，星盘补刀 | 至少两次沿垂直方向断丝、两次将同色双星用较直的一笔连成反射。半途或绕圈不能成镜，每束星光有各自的星点组合 |
| 雪眠巨兽 | 左右鹿角轮流吐霜，前后蹄交错震出裂结 | 至少两次横断蹄震裂结、两次挡住角霜。围住下方暖火的一笔闭环可生成 1.6 秒结界，必须算准吐息落下的时机；也可取火拖向霜域主动融冰 |

## 节奏与收益

入场 0.65 秒，观察间隔 0.22 秒；每轮连招时限依次为 8.6 / 10.2 / 9.2 / 10.0 秒，半血后加速至 88%。达标后露心 3.1 秒，恢复间隔 0.25 秒，不再长时间等 Boss 再出手。

金火／尾鞭／蹄震的有效反制区间为飞行进度 18%–91%，中段 42%–72% 为妙笔窗口。多数攻击命中护卷扣 5，尾鞭和蹄震扣 7；错过整套连招再扣 6，狂化扣 9。每个攻击独立只结算一次。日火坠地留下短时余烬，碰到余烬仍有伤害冷却。

普通反制恢复 1 护卷，妙笔恢复 2；相邻反制间隔不超过 1.45 秒积累连破，3 / 6 / 9 连破有递进音效与提示。妙笔数量会提高破招反噬伤害。单次露心仍有 36% 生命上限，升级技能不能跳过拆招；高质量反制可以直接结束残血 Boss。

发射音跟着身体部位的真实释放时点，尾部蓄势使用短促提示音，避免九尾前摇叠满低频。原有静音和并发保护保留。
