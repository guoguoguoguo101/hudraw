# 《灵狐绘符》一字斩四级资源包

## 包内容
- `references/`：之前生成的四张完整场景效果示意（**AI概念图，不是可以直接播放的透明特效贴图**）。对应 LV1薄金刀芒、Lv2双阶段、Lv3符纸斩裂、Lv4爆发。
- `svg/slash_lv1..4.svg`：四个**真正可编辑**、由矢量路径构成的分层静态特效原型（不是照搬概念图，复杂度低于概念图，可供 Codex 作为程序化基础组件）。坐标局部 640×260，默认向右。
- `preview/`：上述 SVG 的光栅预览（不用于直接嵌进正式战斗）。
- `slash_config.json`：初始四级参数和预期命中时间。
- `CODEX_TASK.md`：详细的实施说明。

## 重要
概念参考图不是原生矢量源；本包里的SVG是**重新编写的基础几何特效**，不是从参考图逐元素抠出来的。实际游戏里应从代码绘制/组合核心刀刃、外刃、符纸、火星、墨迹等，并随玩家画线方向旋转、伸缩。场景图里狐狸有位移只是概念演出，真实角色必须保持固定站位。

## 颜色
白芯 `#fffdf3` / 奶金 `#f5d595` / 金色 `#e7ba68` / 朱砂 `#b73f37` / 背景深墨 `#242326`。

## 命中原则
所有等级以一条胶囊形或者沿线扫掠矩形作为碰撞基础。技能中心轴取从画符轨迹起点到终点的方向 `dir=normalize(end-start)`；从狐狸附近施法锚点发射。判定与视觉解耦，单次主斩每目标仅伤害一次，穿透数量以敌人去重计数。符境绘制时间与技能命中时序分别使用 realTime/gameTime 时钟。
