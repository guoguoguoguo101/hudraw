### 历史缺失说明

- 同名旧版手机预览被覆盖，无法恢复：原角色尺寸及第一次缩小的早期截图未独立保存。

### 后续保存

运行 `node scripts/archive-chat-images.mjs` 可追加现存图片。相同内容不会重复保存；同用途文件变化后生成新版本，绝不覆盖旧版。

当前归档只写入工作区；尚未提交或推送。提交这些目录后，其他电脑通过 Git 拉取即可获取原图。
