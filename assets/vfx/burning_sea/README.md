# 焚山煮海 · 四笔外观

当前已实现四套独立配色和轮廓，并绑定现有画笔选择：

- 朱砂灵笔 → 朱砂金焰：朱红笔带、金色卷云与碎火。
- 狐火灵笔 → 青碧狐焰：青碧分叉长尾、暖白焰芯与浮动狐火。
- 金纹御笔 → 白金御焰：白金锋焰、菱形碎金和细小御纹。
- 山海墨笔 → 山海墨焰：墨色山脊、飞白金边与流动山岚。

四张新 AI 参考图使用内置 image_gen 生成，保存在 `references/four-brushes/01-cinnabar.png`、`02-fox.png`、`03-gold.png`、`04-mountain.png`，完整提示词见同目录 `prompts.md`。实际效果参考这些方向绘制，未把完整概念图作为场景贴图。

测试场点击「画笔 / 特效」，在原有四笔按钮中切换；收起后开启「焚山煮海」即可绘制对应效果。仍在燃烧的火痕也会随当前画笔切换，方便比较。当前节奏为四秒自由绘制、两秒共同蓄势、沿全部笔迹统一爆炸；四笔伤害相同。技能栏和换笔面板都显示当前效果名。

外观配置位于 `src/gameplay/burning-sea-styles.ts`，造型在 `src/rendering/burning-sea.ts`；GameView 每帧传入当前画笔编号。四套外观不参与游戏伤害计算。

验证包含九组逻辑测试、三种浏览器画幅、真实点击四个换笔按钮、同一轨迹的四种截图和微信模拟中的四套配色。实际截图位于 `screenshots/burning-sea/brush-*.png` 和 `wechat-*.png`，微信模拟记录为 `wechat-four-brushes.json`。

## 首轮设计记录

三张参考方案由内置 image_gen 生成，原图与完整提示词保存在 `references/`：

- `01-cinnabar-gold.png`：朱砂金焰。朱红长焰、米金焰芯与卷云笔势，主方向。
- `02-ink-gold.png`：墨焰流金。暗红墨底、断续金线与飞白，补充细节参考。
- `03-jade-foxfire.png`：青碧狐焰首轮构想；后续已在四笔版落地。

实际效果在 `src/rendering/burning-sea.ts` 中重做，沿玩家每次落笔的连续轨迹形成渐细的朱砂墨带，金线带有断续飞白，按路径距离分布不对称卷云焰，配少量碎金余烬。火焰随真实时间摆动、逐段渐隐，低画质减少金线和卷焰密度。未把含角色/UI的参考图作为游戏贴图。

运行时使用分层图形，适配任意自由笔迹；连续笔画保留独立编号，避免松手后两笔被误连接。路径遍历按每层单次顺序采样，避免长涂鸦产生平方级查找。首轮采用五秒绘制与三秒逐段留焰，当前已改为四秒绘制、两秒后统一爆炸。

色板：墨朱 `#681c29`、朱砂 `#af292d`、绯红 `#df4635`、旧金 `#dca95c`、暖白 `#ffdf9b`。火痕在人物下方，强化笔势并保留敌人可读性。

验证：`npm run test:burning-sea`、`npm run test:burning-sea:preview`、`npm run build:wechat`、`npm run test:wechat`。浏览器与微信模拟截图保存在 `screenshots/burning-sea/`，手机性能和实际颜色仍需真机试玩。
