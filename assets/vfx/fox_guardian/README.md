# 灵狐降灵 · 对话图片归档

沿用现有 fox_guardian 资源目录。保存灵狐守护降临、尾卷化法衣方案的参考图、四张矢量关键帧、实机截图与动画预览。当前方案待用户评审，未标记为已认可。根目录 01-ritual 等文件是可重生成的工作输出，本清单中的文件是独立归档快照。

所有归档均保留源文件字节、原始清晰度与格式，不是外部临时链接。PNG/GIF 用于记录和评审，SVG 可编辑；图片归档不改变技能运行方式。
