## 六阶段动效

1. **起符，0–0.45 秒**：本体是稳定中心，核心与内圈点亮。
2. **成阵，0.45–0.82 秒**：三层圆环沿圆周生长，封印节点依次点亮。
3. **封印，0.82–1.12 秒**：符纸从中心向外分布；光弧连接各圈。
4. **展卷，1.12–2.13 秒**：卷头沿单一圆周推进，绘卷逐段显现，七幅画面仍属于一条连续带。完整闭环在 2.28 秒形成，与狐灵起势短暂重叠。
5. **天狐降临，2.13–2.82 秒**：先轮廓，后面部和胸毛；九尾从不同方向呼应圆阵，尾端半透明并飘散碎片。
6. **山海守护，2.82–6.35 秒**：进入慢速持续运动；6.35–7 秒整体淡出并恢复背景。

全屏深墨演出底从 0.12 秒起逐渐覆盖原背景，0.62 秒达到完整强度，结束前 0.65 秒退出。UI 和中心角色保留，敌人保持低透明度。演出不暂停战斗、不改变碰撞半径或其他技能的逻辑。

## 为什么这样拆层

内圈、外圈分别控制出现、旋转和透明度，避免整个法阵一起转造成拥挤。十二张符纸是独立实例，既能统一排布，也能逐张动画。绘卷用一个极坐标基线连接七幅不同图案，只保留一对卷头，读起来是一条展开的画卷。

九尾使用两段连续曲线和沿程法线构造轮廓。根部稳定，波动向尾端传播；毛束使用简洁块面和线条，局部渐隐保留灵体感。尾巴先在绘卷后方渲染，面部与胸口在前方渲染，下方少量尾段和碎屑可越过前景，既能穿插也能保持圆环可读。

神社、鸟居和灯笼保持静态几何路径，程序只控制位置、尺度和轻微摆动。云和仙鹤可以独立使用；光效由描边、块面、透明度控制，不依赖大型模糊滤镜。

SVG 是 **3.2 秒完整状态的静态矢量快照**。连续展卷、实时尾巴形变、仙鹤振翅和透明度动画保留在游戏模块中；SVG 本身没有嵌入这套动画。`fox_center.svg` 使用现有角色的矢量原稿，运行时角色继续使用原有角色动画系统。

## 坐标与程序模块

- 游戏画布：720 × 1280；施法中心：`(360, 665)`。
- 分层与组合资产默认局部坐标：中心为 `(0, 0)`；导出视窗 `-400 -550 800 1100`。
- 小资产有独立紧凑视窗；导入时以 SVG viewBox 保持比例。
- `circle-ascendant.ts`：八层组合及时间控制。
- `circle-scroll-ring.ts`：连续极坐标绘卷、卷头和拖影。
- `ascendant-spirit.ts`：九尾曲线、毛束、守护灵面部与碎屑。
- `ascendant-scroll.ts`：七幅不同的静态山水纹样。
- `vector-export.ts`：从实际路径导出 SVG。
- `scripts/export-circle-five.mjs`：重新导出主图、拆层图与独立资产。

Lv1–Lv4 的视觉保留。Lv5 的伤害、护盾、持续时间和实际作用范围沿用已有参数，本次调整集中在演出结构与矢量资产。
