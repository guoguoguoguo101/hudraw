## 当前设计要求

- 国风剪纸、山海绘卷、2D扁平精致；统一米白、朱红、古金、墨黑。
- 中央小狐狸固定站位、清楚可见；高阶天狐是额外神灵演出。
- 上层完整威严九尾天狐与天幕；中层强烈的纵向白金雷枪；下层封印爆裂、扩散雷潮、敌人雷链。
- 九尾错开生长和独立摆动；云卷、符纸跟随力量流动，不做整块刚性旋转。
- 起势、显现、凝雷、劈落、余韵分别演出；雷网在命中时短暂出现，避免持续堆满战场。
- 游戏内使用分层矢量路径和程序动画。这些生成概念图都是PNG参考，不是SVG源文件，也不是整张图播放的特效资源。
