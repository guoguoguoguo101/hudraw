## 本次建议，待讨论

- 起点与攻击方向由落笔位置和书写顺序决定；角色依旧在中央。雷从落笔处起，不额外从角色画一条会造成伤害的连接线。
- 画符时沿用已有慢动作，松手锁定路线。可接受旋转、倾斜与轻微手抖，不把手绘路线强制重排为标准Z。
- 逐段释放建议总共约0.6–0.9秒，两处电爆各有短促拍点。过慢容易让玩家感觉画准却落空，过快又看不出折转。
- 判定使用有一定宽度的路径走廊，发光闪烁可超出走廊，但不能暗中自动弯向路径外敌人。
- 路径总长度设预算并实时提示，避免随手铺满整场；不要松手才悄悄缩短路线。
- 初期建议同一敌人三段主雷只命中一次；折点电爆可以作为独立、受限的追加伤害，避免擦同一处变成重复伤害漏洞。
- 等级提升强化雷宽、两个折点和沿途演出；高阶天狐也服务同一笔路线。
