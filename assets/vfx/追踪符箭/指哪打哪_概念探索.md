# 箭头符 · 指哪打哪概念探索

2026-10-14；仅讨论，不修改技能代码。以下为候选方案，待评审。

箭尾提供凝聚位置，箭杆提供初始方向与攻击走廊，箭尖指定附近的优先目标。收益来自沿线穿透与点名高价值目标；不以绘制长度或工整程度奖励伤害。适度容错识别、落笔反馈、箭尖局部吸附和受限追踪是待验证的交互方向。没有箭尖目标时仍沿线飞行，不跨屏转向找怪。

| 等级 | 候选收益 |
| --- | --- |
| Lv1 破阵 | 一箭沿线穿透，再攻击箭尖附近的指定目标 |
| Lv2 留印 | 狐印确认点名，沿同一路线追加回响 |
| Lv3 合围 | 三箭由同一起点展开，收拢至主目标；主目标消失后仅在落点附近补选 |
| Lv4 护送 | 保留灵狐守护法衣，尾卷沿指定路线开道并打击落点；守护灵仍留在身边 |
