## Git 与版本

当前归档 23 个独立文件。文件清单记录原文件名、用途、版本和 SHA-256，见[归档清单](chat-images.manifest.json)。以后同一工作文件发生变化时追加 v02、v03；相同内容共用归档文件，不覆盖旧版。
