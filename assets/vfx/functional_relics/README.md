# 三件功能灵宝 · 美术与原型

使用内置 image_gen 生成 `concept-v1.png`，输入参考为本项目自由绘符截图。实际代码参考其中的朱金方灯、蓝金沙漏、青白莲灯和独立两笔回魂卡片；未把整张设计图作为游戏贴图。

游戏原型入口是主菜单「演武画境 · 自由试符」。默认携带引路灯笼和回魂灯；在灵宝栏右侧点「装备」可卸下、换装或切换 Lv1–Lv3，最多两件。换装不自动补次数，「重置」明确恢复资源。右侧「致命受击测试」用于验证回魂；普通练习依然免伤。

参考图来源为 AI 概念，实际截图在 `screenshots/functional-relics/`，包括三种手机画幅和 `wechat-*.png` 微信模拟截图。
