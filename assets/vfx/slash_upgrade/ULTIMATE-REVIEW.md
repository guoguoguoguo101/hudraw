# Lv4纸符斩妖斩 · A/B评审稿

本稿取代上一版Lv4“直线＋起点扇形”的实现说明。最新结构为：沿手势方向射出宽纸符主斩，在路径中后段或第二个主命中目标附近，爆出相对主斩交叉的月牙副斩。没有头顶法阵或固定方向光柱。

## 试玩

打开 http://127.0.0.1:5173/?lab=1&ultimate=1 。这是原游戏背景上的独立终极技能测试入口，默认斜向右下预览。

- 「A · 锋利月牙」：较收敛的100宽主斩、28张飞符、150副斩范围。
- 「B · 华丽纸符」：150宽主斩、48张飞符、185副斩范围，更多撕裂、云纹和爆裂。
- 点击版本会切换并重播。施法方向可选8个方向；手画时沿起点到终点向量释放。
- 时间条可逐帧检查蓄力、主斩、副斩与残影；时间条是战斗动画时间，实时播放另有短促命中停顿。
- 展开「Lv4可调参数」修改参数，再点「预览 Lv4」重播生效。退出预览后回到持续刷怪测试场。

## 动画与判定

1. 0–0.08秒：身体压低、向释放方向前倾；尾巴和围巾往后拉，少量飞符聚拢。狐狸世界锚点不变。
2. 0.08–0.18秒：宽白金主斩伸长，朱砂撕裂边、飞符沿路径冲出。0.13秒主伤害结算。
3. 0.18秒起：交叉月牙副斩展开，不在狐狸头顶生成。副斩对局部圆形范围结算一次伤害。
4. 真正命中位置产生黑妖气碎屑、红白碎片、符纸、金色尖闪；存活小怪沿方向强击退，死亡怪物分成两片飞出、旋转并淡出。
5. 最后红金尾迹、飞符与白云纹衰减，全招约0.58/0.62秒结束。

主斩沿用145基础伤害和7目标穿透，并叠加既有质量、法宝、修行。宽度和长度由当前版本参数决定。副斩60独立固定伤害，按范围选取敌人，可伤到主斩未命中的附近目标。每个敌人主斩最多一次、副斩最多一次；以独立Set去重，粒子与伤害无关。鬼王不会被斩飞。

## 参数

默认值在 ultimate_config.json，施法时复制配置，调整不会改变已释放的技能。

| 参数 | 作用 |
|---|---|
| slashWidth | 主斩视觉宽度与碰撞宽度 |
| slashLength | 主斩视觉长度与射程 |
| coreBrightness | 白色刀芯亮度 |
| outerGlow | 金色外缘强度 |
| paperCount | 主路径飞符数量，最多80 |
| paperScatter | 飞符横向散射范围 |
| burstCount | 每个真实命中点的碎片数量，最多48 |
| hitStop | 命中停顿秒数，测试控件上限0.08秒 |
| knockbackForce | 存活小怪定向击退、死亡残影飞出力度 |
| trailDuration | 尾迹衰减时间 |
| secondaryRadius | 副斩范围 |
| secondaryDamage | 副斩独立伤害 |

飞符、残影均有数量上限；图层组复用。静态图来自真实程序渲染；单独预览隐藏场景并扩大画布以看清全长，没有使用AI生成的概念图充当实机结果。
