## 四级美术表现

**Lv1 一字斩**：最薄的金色刀线（刀身中心 2–3px 高亮白芯，外刃带尖锐两端的金色细菱形），仅少量1–3枚火星。以 0–0.05s 出现一条指向目标的金色预切线；0.06s 主要命中；0.06–0.20s 光线急速拉长、锐利消失。不要大片发光圆柱。参考 `references/Lv1_参考_细线与锋芒.png`。

**Lv2 金芒横斩**：先极细白芯切穿，随后外侧金色刀刃变宽，追加**宽幅弧形贴刀气（视觉贴线、不改变核心判定方向）**和淡金尾流；核心从0.07s命中，0.07–0.20s展出第二层残影，0.20–0.28s淡出；命中生成4–8片细碎剪纸和短十字闪光。参考 `references/Lv2_参考_双层瞬斩.png`（画中多格分镜分别是同招时间演变，不是多种独立技能）。

**Lv3 破阵符斩**：在Lv2基础上加朱砂剪纸撕裂边缘和5–8张顺刀线方向飞舞的短符纸，产生片状法纹；命中第一目标0.09s，沿线依次触发尖裂光；局部出现一次小型二段裂伤（伤害25，必须有独立命中ID、限每个主斩命中目标最多一次）。主要劈砍仍保持白金刀芯可见。0.25–0.38s纸屑与墨迹逐渐散开。参考 `references/Lv3_参考_符纸破阵.png`。

**Lv4 天罡诛邪斩**：稀有终极：0–0.08s 狐狸附近的符印短暂收束、场景周边略暗；0.08–0.13s 白金斩芯出现并高速伸长；0.13s 主斩命中；0.13–0.30s 斩线周围层叠2道金色锋纹与朱砂撕裂纸带，沿线生成短促的星形光爆；0.30–0.45s 最多在前三个命中目标附近触发局部额外40伤害（独立hitId，不能无限连锁）；0.45–0.65s 纸符、碎墨、余光衰退。仍然是一道由绘制方向控制的线形斩击，不是全屏随机爆炸。参考 `references/Lv4_参考_爆发终极.png`。

## 坐标与判定

归一化指向向量 `dir=normalize(p_last-p_first)`，太短的线拒绝/降级（沿用当前触摸识别容错）。在角色固定施法锚点放置效果，以 `atan2(dir.y,dir.x)` 旋转整组局部图形，以 range 缩放刀线主体；击中特效使用每个实际命中敌人的世界坐标。中途穿透的敌人按投影到线段上的距离排列，去重命中。用线段 vs 圆形/胶囊/敌人碰撞半径实现稳定穿透，不许按发光贴图面积判定。穿透第 N 个后，后续目标不可再伤害，即使视觉尾流扫过。

遵循 `slash_config.json` 的基础伤害、宽度、射程、穿透和命中时点；以上数值是调试初稿，要求配置化并允许小范围调整。额外效果和主斩分开记账。伤害/碰撞不依赖SVG粒子数量。

## 性能与表现

核心刀刃用动态 Graphics / Path / Mesh 绘制，粒子由对象池回收，随级别增加剪纸粒子总量但限制预算（Lv1 3, Lv2 12, Lv3 25, Lv4 50 上限）。白芯锐利不能被大面积模糊Glow覆盖。VFX视觉时间使用游戏时钟；UI/触摸计时使用真实时钟。遇到暂停/慢动作时不得产生不同步。

## 需要验收

1. 四级视觉能显著区分；可配置强制预览Lv1–Lv4，跳过概率系统单独检查。
2. 0°、45°、90°、180° 绘制后攻击方向正确，不出现坐标镜像和倒转。
3. 测试对一只/三只/五只/八只敌人的穿透上限和伤害去重。
4. 检查在手机实际角色尺寸下，Lv1不显得太粗、Lv4不遮挡全部怪物和UI。
5. 只运行必要的build/test并生成四级独立截图与4级同框对照；无法自动截图则说明限制。
6. 保持原有项目接口、其他五系符术与局内局外数值正常。
